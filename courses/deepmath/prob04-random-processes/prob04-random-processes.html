02

Random Processes

$\{X_n\}$, i.i.d. and its limits

Definition — Random Process

Definition (random process).

A random process is a sequence of random variables

$$\mathbf{X} = \{X_n\}_{n=1}^{\infty}$$
  • Index $n$: time (step, token position, iteration)
  • Each $X_n$: one random variable, as in prob01

The Simplest Process — i.i.d.

i.i.d. = independent and identically distributed

Definition (i.i.d. process).

The joint pmf factorizes into marginals:

$$P_{X^n}(x^n) \;=\; \prod_{i=1}^{n} P_{X_i}(x_i)$$

Notation from prob03: $X^n = (X_1, \dots, X_n)$, one joint distribution.

i.i.d. Example — Coin Flips

Fair coin, flipped four times, as an illustration:

$$P(\texttt{HTHH}) = \tfrac12 \cdot \tfrac12 \cdot \tfrac12 \cdot \tfrac12 = \tfrac{1}{16}$$
  • Every length-4 string: probability $\tfrac{1}{16}$, no exceptions
  • Past flips never help predict the next one

Text Is Not i.i.d.

Fill in the missing letter:

my na_e is Albert
  • Everyone reads m: neighbors reveal the blank
  • Under i.i.d., neighbors reveal nothing: $P(X_i \mid \text{rest}) = P(X_i)$

Real symbol sequences are highly correlated: text does not follow an i.i.d. distribution.

03

Markov Processes

Memory of length one (or $k$)

Idea — Memory of Length One

Markov: the next step depends only on the present

prob03 met the 3-variable case $X - Y - Z$ (data processing). Today: whole processes.

Example — Random Walk

$$X_0 = 0, \qquad X_n = \begin{cases} X_{n-1} + 1 & \text{with prob. } 1/2 \\[2pt] X_{n-1} - 1 & \text{with prob. } 1/2 \end{cases}$$

Step up or down by 1, a fair coin each time.

Random Walk — Only the Present Matters

Suppose we know $X_{101} = 51$:

$$X_{102} = \begin{cases} 52 & \text{with prob. } 1/2 \\[2pt] 50 & \text{with prob. } 1/2 \end{cases}$$

Extra information $X_{100} = 50$: changes nothing

Given the present, the past is irrelevant: the defining Markov property.

Definition — 1st-Order Markov Process

Definition (1st-order Markov).

A random process $\mathbf{X}$ with, for every step $i$,

$$P(X_i \mid X_{i-1}, \dots, X_1) \;=\; P(X_i \mid X_{i-1})$$
  • Conditioning on the full past = conditioning on one step
  • i.i.d. is the special case with no dependence at all

Recall (prob03) — Chain Rule of Probability

Recall (conditional pmf, prob03).

Any joint pmf peels off one variable at a time:

$$P_{X^n}(x^n) \;=\; \prod_{i=1}^{n} P_{X_i \mid X^{i-1}}(x_i \mid x^{i-1})$$
  • Holds for every process, Markov or not
  • Plan: let the Markov property shorten each factor

Proposition — Markov Factorization

Proposition 1 (factorization).

For a 1st-order Markov process:

$$P_{X^n}(x^n) \;=\; \prod_{i=1}^{n} P_{X_i \mid X_{i-1}}(x_i \mid x_{i-1})$$

The joint distribution of the whole path, from pairwise pieces only.

Markov Factorization — Proof

$$\begin{aligned} P_{X^n}(x^n) &\stackrel{(\text{chain rule})}{=} \prod_{i=1}^{n} P_{X_i \mid X^{i-1}}(x_i \mid x^{i-1}) \\[4pt] &\stackrel{(\text{Markov})}{=} \prod_{i=1}^{n} P_{X_i \mid X_{i-1}}(x_i \mid x_{i-1}) \qquad \blacksquare \end{aligned}$$
  • Chain rule: always true, no assumption
  • Markov property: each factor forgets all but one step

Factorization — Why It Matters

Alphabet size $m = 27$, sequence length $n = 10$, as an illustration:

$$\underbrace{m^n \approx 2 \times 10^{14}}_{\text{full joint table}} \qquad \text{vs.} \qquad \underbrace{m^2 = 729}_{\text{one-step table}}$$
  • Markov: model the whole path with one small table
  • That table is next section's transition matrix

Definition — $k$th-Order Markov Process

Definition ($k$th-order Markov).

The next step depends only on the last $k$ steps:

$$P_{X_i \mid X^{i-1}}(x_i \mid x^{i-1}) \;=\; P_{X_i \mid X_{i-k}^{i-1}}(x_i \mid x_{i-k}^{i-1})$$

Notation: $x_{i-k}^{i-1} = (x_{i-k}, \dots, x_{i-1})$, the length-$k$ recent past.

$k$th Order — Factorization

Proposition 2 (factorization, $k$th order).

$$P_{X^n}(x^n) \;=\; \prod_{i=1}^{n} P_{X_i \mid X_{i-k}^{i-1}}(x_i \mid x_{i-k}^{i-1})$$
  • Same proof: chain rule, then drop all but $k$ steps
  • Larger $k$: more memory, larger tables ($m^k$ contexts)

Illustration — Next-Token Models

A language model scores the next token from recent context:

$$P(X_i \mid \underbrace{x_{i-k}, \dots, x_{i-1}}_{\text{context window}})$$
  • Finite context window: a $k$th-order flavor
  • $m^k$ contexts explode fast: neural nets compress the table

Illustration only: today's math is the exact finite-state case.

04

Transition Matrices

One step = one multiplication

Technique Review — Probability Vectors

A distribution over $n$ states, packed as a vector:

$$\pi = \begin{bmatrix} \pi(1) \\ \vdots \\ \pi(n) \end{bmatrix}, \qquad \pi(u) \geq 0, \qquad \sum_{u=1}^{n} \pi(u) = 1$$
  • Example, two states: $\pi = [\,3/4, \; 1/4\,]^\top$
  • Entries: probability mass sitting on each state

Technique Review — Matrix × Vector

Row $u$ of $A$, dotted with $v$:

$$(A v)_u = \sum_{w} A_{u,w} \, v_w$$

Worked, $2 \times 2$:

$$\begin{bmatrix} \tfrac34 & \tfrac14 \\[2pt] \tfrac14 & \tfrac34 \end{bmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} \tfrac34 \cdot 1 + \tfrac14 \cdot 0 \\[2pt] \tfrac14 \cdot 1 + \tfrac34 \cdot 0 \end{bmatrix} = \begin{bmatrix} \tfrac34 \\[2pt] \tfrac14 \end{bmatrix}$$

Each output entry mixes the input entries with weights.

Setup — Finite States, One Fixed Rule

Two assumptions for the rest of the lecture:

  • Finite states: $X_i \in \mathcal{X} = \{1, \dots, n\}$ for all $i$
  • Same rule every step: $P_{X_i \mid X_{i-1}}(x_i \mid x_{i-1})$ does not depend on $i$

One fixed one-step rule + finite states = the whole process fits in one matrix.

Definition — Transition Matrix

Definition (transition matrix).

The $n \times n$ matrix $P$ with entries

$$P_{u,v} \;=\; \Pr(X_i = u \mid X_{i-1} = v)$$
  • Column $v$: distribution of the next state, starting from $v$
  • Row $u$: all the ways to arrive at $u$

Columns Sum to One

Fix the current state $v$ and add up column $v$:

$$\sum_{u=1}^{n} P_{u,v} = \sum_{u=1}^{n} \Pr(X_i = u \mid X_{i-1} = v) = 1$$
  • The next state lands somewhere: probabilities exhaust
  • All entries nonnegative: $P$ is a (column-)stochastic matrix

Convention alert: many books use rows instead. Transpose everything to translate.

State Distribution at Time $i$

Where the chain is at step $i$, as a probability vector:

$$\pi_i = \begin{bmatrix} \Pr(X_i = 1) \\ \Pr(X_i = 2) \\ \vdots \\ \Pr(X_i = n) \end{bmatrix}$$
  • $\pi_0$: the initial distribution, chosen by us
  • Question: how does $\pi_{i-1}$ become $\pi_i$?

Theorem — One Step Is One Multiplication

Theorem 1 (one-step evolution).

For every step $i \geq 1$:

$$\pi_i \;=\; P \, \pi_{i-1}$$

Probability flow through the chain = plain matrix-vector multiplication.

One-Step Evolution — Proof Overview

Target: $\Pr(X_i = u) = (P\,\pi_{i-1})_u$ for every state $u$

  1. Split the event $\{X_i = u\}$ by the previous state (total probability)
  2. Rename each term with $P_{u,v}$ and $(\pi_{i-1})_v$
  3. Recognize the row-times-vector formula

One line each. Total probability: prob01's case-split, now over states.

One-Step Evolution — Proof

$$\begin{aligned} \Pr(X_i = u) &\stackrel{(\text{total prob.})}{=} \sum_{v=1}^{n} \Pr(X_{i-1} = v)\,\Pr(X_i = u \mid X_{i-1} = v) \\[4pt] &\stackrel{(\text{rename})}{=} \sum_{v=1}^{n} P_{u,v} \, (\pi_{i-1})_v \\[4pt] &\stackrel{(\text{row} \times \text{vector})}{=} (P \, \pi_{i-1})_u \qquad \blacksquare \end{aligned}$$

One-Step Evolution — Summary

$$\Pr(X_i = u) \stackrel{(\text{split})}{=} \sum_v \Pr(\text{was } v) \Pr(v \to u) \stackrel{(\text{read off})}{=} (P\pi_{i-1})_u$$
  • The trick: total probability is a dot product
  • Everything about $\{\pi_i\}$ is now linear algebra

The entire future of the distribution lives inside one matrix $P$.

Running Example — Binary Chain

Two states. Flip with probability $\alpha \lt \tfrac12$, stay with $1 - \alpha$:

A noisy bit that occasionally flips. Numbers today: $\alpha = 1/4$.

Binary Chain — Transition Matrix

Columns = current state, rows = next state:

$$P = \begin{pmatrix} 1-\alpha & \alpha \\ \alpha & 1-\alpha \end{pmatrix} \;\;\stackrel{\alpha = 1/4}{=}\;\; \begin{pmatrix} \tfrac34 & \tfrac14 \\[2pt] \tfrac14 & \tfrac34 \end{pmatrix}$$
  • Column sums: $(1-\alpha) + \alpha = 1$  ✓
  • Symmetric: flipping $0 \to 1$ and $1 \to 0$ equally likely

Binary Chain — One Step by Hand

Start pinned at $0$: $\;\pi_0 = [1, 0]^\top$

$$\pi_1 = P\,\pi_0 = \begin{pmatrix} 1-\alpha & \alpha \\ \alpha & 1-\alpha \end{pmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 1-\alpha \\ \alpha \end{bmatrix} = \begin{bmatrix} \tfrac34 \\[2pt] \tfrac14 \end{bmatrix}$$
  • Reading: after one step, flipped with probability $\alpha$
  • Matches the diagram: mass $\alpha$ leaks across

Binary Chain — A Second Step

$$\pi_2 = P\,\pi_1 = \begin{bmatrix} (1-\alpha)^2 + \alpha^2 \\[2pt] 2\alpha(1-\alpha) \end{bmatrix} \;\;\stackrel{\alpha = 1/4}{=}\;\; \begin{bmatrix} \tfrac58 \\[2pt] \tfrac38 \end{bmatrix}$$
  • Stay twice or flip twice: back at $0$
  • Mass drifts toward a 50/50 split: $1 \to \tfrac34 \to \tfrac58 \to \cdots$

05

Evolution in Time

$\pi_t = P^t \pi_0$

Theorem — $t$ Steps Is One Matrix Power

Theorem 2 ($t$-step evolution).

For every $t \geq 0$:

$$\pi_t \;=\; P^t \, \pi_0$$

All of time, compressed into powers of one matrix.

$t$-Step Evolution — Proof

Unroll Theorem 1, one step at a time:

$$\pi_t \stackrel{(\text{Thm 1})}{=} P\,\pi_{t-1} \stackrel{(\text{Thm 1})}{=} P\,(P\,\pi_{t-2}) = P^2 \pi_{t-2} \;=\; \cdots \;=\; P^t \pi_0 \quad \blacksquare$$
  • Formally: induction on $t$, base case $\pi_0 = P^0 \pi_0$
  • Uses the fixed rule: the same $P$ at every step

Binary Chain — Numeric Evolution

$\alpha = \tfrac14$, start at $\pi_0 = [1, 0]^\top$; each row: one multiplication by $P$

$t$$\Pr(X_t = 0)$$\Pr(X_t = 1)$
0$1$$0$
1$3/4 = 0.75$$1/4$
2$5/8 = 0.625$$3/8$
3$9/16 \approx 0.563$$7/16$
4$17/32 \approx 0.531$$15/32$

Binary Chain — Convergence Picture

$\Pr(X_t = 0)$ from both starts: both converge to $\tfrac12$

A Distribution That Does Not Move?

Both starting points drift toward $[\tfrac12, \tfrac12]^\top$

  • Gap to $\tfrac12$ halves every step: $\tfrac12, \tfrac14, \tfrac18, \tfrac{1}{16}, \dots$
  • Guess: some special $\pi$ satisfies $P\pi = \pi$ and never moves

06

Stationary Processes

Shift-invariant in distribution

Definition — Stationary Process

Definition (stationary process).

A process is stationary if for all $i$ and all window lengths $n$:

$$(X_i, \dots, X_{i+n-1}) \;\stackrel{d}{=}\; (X_{i+1}, \dots, X_{i+n})$$
  • $\stackrel{d}{=}$: equal in distribution (same joint pmf)
  • Shift any window by one step: statistics unchanged

Picture — Sliding the Window

Stationary: the clock has no origin. Statistics do not depend on time.

Counterexample — Random Walk

Random walk again: $X_0 = 0$, $\;X_n = X_{n-1} \pm 1$

$$X_1 \in \{+1, -1\}, \qquad X_2 \in \{+2, 0, -2\}, \qquad X_3 \in \{\pm 3, \pm 1\}$$
  • Support keeps growing: $X_n$ is "more random" than $X_0$
  • $X_1 \stackrel{d}{=} X_2$ already fails: not stationary

Random Walk — The Fan-Out

Markov, yes. Stationary, no: the distribution widens every step.

Markov vs. Stationary — Independent Axes

Markov, not stationary

Random walk: memory 1, spread grows

Stationary, not Markov

Stationary allows infinite dependencies

Two separate properties: short memory vs. time-invariant statistics.

07

Stationary Distributions

$\pi^\star = P\pi^\star$, an eigenvector

Worked — Three-State Chain, Uniform Start

Initial distribution:

$$P(A) = P(B) = P(C) = \tfrac13$$

Question: what is $\pi_2$?

Worked — One Step for State A

Who can land on $A$? Only $A$ (stay) and $C$ (rotate):

$$\begin{aligned} \Pr(X_2 = A) &= \Pr(X_1 = A)\Pr(A \mid A) + \Pr(X_1 = C)\Pr(A \mid C) \\[4pt] &= \tfrac13 \cdot \tfrac12 + \tfrac13 \cdot \tfrac12 \;=\; \tfrac13 \end{aligned}$$

Total probability again: exactly one row of $\pi_2 = P\pi_1$.

Worked — All States Stay at 1/3

Same computation for $B$ and $C$, by the rotation symmetry:

$$\pi_2 = \begin{bmatrix} \tfrac13 \\ \tfrac13 \\ \tfrac13 \end{bmatrix} = \pi_1 \quad\Longrightarrow\quad \pi_t = \begin{bmatrix} \tfrac13 \\ \tfrac13 \\ \tfrac13 \end{bmatrix} \;\;\text{for all } t$$
  • Repeat the argument: every step keeps $\tfrac13$ each
  • Uniform start: this chain's distribution never moves

Worked — The Process Is Stationary

With the uniform start, windows shift without changing distribution:

$$(X_i, \dots, X_{i+n-1}) \;\stackrel{d}{=}\; (X_{i+1}, \dots, X_{i+n})$$
  • Marginals equal at all times, transitions the same rule always
  • Section 06's definition: satisfied

A Markov chain becomes a stationary process when started from the right distribution.

Same Chain, Different Start

Now pin the start: $\Pr(X_1 = A) = 1$

$$\pi_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} \;\longrightarrow\; \pi_2 = \begin{bmatrix} \tfrac12 \\ \tfrac12 \\ 0 \end{bmatrix} \;\neq\; \pi_1$$
  • $X_1 \stackrel{d}{=} X_2$ fails: not stationary anymore
  • Same matrix $P$, different verdict

Stationarity is a property of the chain and its initial distribution.

Theorem — When a Standing-Still Start Exists

Theorem 3 (existence; stated without proof).

A Markov chain that is finite-state, irreducible, aperiodic has a stationary initial distribution.

  • "Reasonable assumptions" rule out broken chains (next slide)
  • Proof: beyond this course

The Assumptions, in Pictures

Irreducible

Every state can reach every state

Aperiodic

No rigid cycle forcing the clock

Informal glosses. Both running examples satisfy all three conditions (for $0 \lt \alpha \lt 1$).

Worked — Binary Chain, Uniform Start

Take $\pi_0 = [\tfrac12, \tfrac12]^\top$:

$$P\,\pi_0 = \begin{pmatrix} 1-\alpha & \alpha \\ \alpha & 1-\alpha \end{pmatrix} \begin{bmatrix} \tfrac12 \\[2pt] \tfrac12 \end{bmatrix} = \begin{bmatrix} \tfrac{1-\alpha}{2} + \tfrac{\alpha}{2} \\[2pt] \tfrac{\alpha}{2} + \tfrac{1-\alpha}{2} \end{bmatrix} = \begin{bmatrix} \tfrac12 \\[2pt] \tfrac12 \end{bmatrix}$$
  • Hence $\pi_t = [\tfrac12, \tfrac12]^\top$ for all $t$
  • Exactly the value both curves converged to in Section 05

Definition — Stationary Distribution

Definition (stationary distribution).

A probability vector $\pi^\star$ with

$$\pi^\star \;=\; P\,\pi^\star$$
  • A fixed point of one-step evolution
  • Start there, stay there: the chain runs as a stationary process

Technique Review — Eigenvalues & Eigenvectors

Recall (linear algebra).

$v \neq 0$ is an eigenvector of $A$ with eigenvalue $\lambda$ if

$$A v = \lambda v$$
  • $A$ only rescales $v$: direction unchanged
  • Eigenvalues solve the characteristic equation $\det(A - \lambda I) = 0$

Technique Review — The 2×2 Recipe

For a $2 \times 2$ matrix, two mechanical steps:

  1. Eigenvalues: expand $\det(A - \lambda I) = 0$, solve the quadratic
  2. Eigenvectors: for each $\lambda$, solve $(A - \lambda I)v = 0$
$$\det \begin{pmatrix} a - \lambda & b \\ c & d - \lambda \end{pmatrix} = (a-\lambda)(d-\lambda) - bc$$

Refresher for what comes next: we solve both chains by hand.

$\pi^\star$ Is an Eigenvector

Compare the two equations:

$$\pi^\star = P\,\pi^\star \qquad\Longleftrightarrow\qquad P\,v = \lambda v \;\text{ with } \lambda = 1$$
  • $\pi^\star$: eigenvector of $P$ for eigenvalue $1$
  • Extra constraint: entries nonnegative, summing to $1$ (normalize)

Finding where a chain stands still = an eigenvector computation.

Binary Chain — Eigenvalues by Hand

$$\begin{aligned} \det(P - \lambda I) &= (1 - \alpha - \lambda)^2 - \alpha^2 \\[4pt] &\stackrel{(a^2 - b^2)}{=} (1 - \alpha - \lambda - \alpha)(1 - \alpha - \lambda + \alpha) \\[4pt] &= (1 - 2\alpha - \lambda)(1 - \lambda) \;=\; 0 \end{aligned}$$

Eigenvalues: $\;\lambda_1 = 1$, $\;\lambda_2 = 1 - 2\alpha$  ($= \tfrac12$ at $\alpha = \tfrac14$)

$\lambda = 1$ appears, as promised. The other eigenvalue returns in Section 08.

Binary Chain — Eigenvector for $\lambda = 1$

Solve $(P - I)v = 0$:

$$\begin{pmatrix} -\alpha & \alpha \\ \alpha & -\alpha \end{pmatrix} \begin{bmatrix} v_1 \\ v_2 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} \quad\Longrightarrow\quad v_1 = v_2$$

Normalize to a probability vector:

$$\pi^\star = \begin{bmatrix} \tfrac12 \\[2pt] \tfrac12 \end{bmatrix}$$

Binary Chain — Sanity Check

Multiply back, at $\alpha = \tfrac14$:

$$P\,\pi^\star = \begin{pmatrix} \tfrac34 & \tfrac14 \\[2pt] \tfrac14 & \tfrac34 \end{pmatrix} \begin{bmatrix} \tfrac12 \\[2pt] \tfrac12 \end{bmatrix} = \begin{bmatrix} \tfrac38 + \tfrac18 \\[2pt] \tfrac18 + \tfrac38 \end{bmatrix} = \begin{bmatrix} \tfrac12 \\[2pt] \tfrac12 \end{bmatrix} \;\;\checkmark$$
  • Same answer as the uniform-start worked example
  • Same answer the numeric table crept toward

Three-State Chain — Solve $\pi^\star = P\pi^\star$

Write out the three rows of $\pi^\star = P \pi^\star$:

$$\begin{aligned} \pi_A &= 0.5\,\pi_A + 0.5\,\pi_C \\ \pi_B &= 0.5\,\pi_A + 0.5\,\pi_B \\ \pi_C &= 0.5\,\pi_B + 0.5\,\pi_C \end{aligned}$$

Three equations, plus the normalization $\pi_A + \pi_B + \pi_C = 1$.

Three-State Chain — Solution

Simplify each row (subtract, cancel the $0.5$):

$$\pi_A = \pi_C, \qquad \pi_B = \pi_A, \qquad \pi_C = \pi_B$$

All equal; normalize:

$$\pi^\star = \begin{bmatrix} \tfrac13 \\ \tfrac13 \\ \tfrac13 \end{bmatrix}$$

Exactly the uniform start that made the process stationary. No coincidence.

Exercise — Symmetric Transition Matrix

Exercise.

Show: if $P$ is symmetric ($P^\top = P$), the uniform distribution is stationary.

$$\pi^\star = \begin{bmatrix} \tfrac1n \\ \vdots \\ \tfrac1n \end{bmatrix}$$

Hint. Columns sum to $1$. What do symmetric rows sum to?

Exercise — Solution

Symmetric $P$: row $u$ = column $u$, so rows sum to $1$

$$(P\,\pi^\star)_u = \sum_{v} P_{u,v} \cdot \tfrac1n = \tfrac1n \underbrace{\textstyle\sum_{v} P_{u,v}}_{\text{row sum} \;=\; 1} = \tfrac1n \qquad \blacksquare$$
  • Both running examples are symmetric: uniform $\pi^\star$, twice confirmed
  • Keep this fact: it powers the diffusion section

Illustration — Random Surfer

  • States: web pages; transitions: links
  • Surfer clicks forever: where does mass settle?
  • PageRank-style scores: read off $\pi^\star$

08

Limiting Distributions

Limits are stationary

Definition — Limiting Distribution

Definition (limiting distribution).

If the limit exists,

$$\pi_\infty \;=\; \lim_{t \to \infty} \pi_t$$
  • Entry-wise limit of the vectors $\pi_t = P^t \pi_0$
  • May depend on the initial distribution $\pi_0$

Caveat — The Limit May Not Exist

Binary chain at the excluded extreme $\alpha = 1$ (always flip), as an illustration:

$$\pi_0 = \begin{bmatrix} 1 \\ 0 \end{bmatrix} \;\to\; \begin{bmatrix} 0 \\ 1 \end{bmatrix} \;\to\; \begin{bmatrix} 1 \\ 0 \end{bmatrix} \;\to\; \begin{bmatrix} 0 \\ 1 \end{bmatrix} \;\to\; \cdots$$
  • Oscillates forever: no limit (a periodic chain)
  • Hence the "if it exists" in the definition

Theorem — Limits Are Stationary

Theorem 4 (limiting $\Rightarrow$ stationary).

If the limiting distribution $\pi_\infty$ exists, then it is a stationary distribution:

$$\pi_\infty = P\,\pi_\infty$$

Wherever a chain settles, it must stand still.

Limits Are Stationary — Proof

Take $t \to \infty$ on both sides of Theorem 1:

$$\begin{aligned} \pi_{t+1} &\;=\; P\,\pi_t \\[4pt] \lim_{t\to\infty} \pi_{t+1} &\stackrel{(\text{same sequence})}{=} \pi_\infty, \qquad \lim_{t\to\infty} P\,\pi_t \stackrel{(P \text{ fixed, entries linear})}{=} P\,\pi_\infty \\[4pt] \pi_\infty &\;=\; P\,\pi_\infty \qquad \blacksquare \end{aligned}$$

Left side: the shifted sequence has the same limit. Right side: finite sums of limits.

Limits Are Stationary — Implication

  • Candidates for long-run behavior: only the solutions of $\pi = P\pi$
  • No simulation needed: solve an eigenvector equation
  • Converse can fail: stationary $\pi^\star$ may exist, yet no limit ($\alpha = 1$)

To know where a chain can end up, run linear algebra, not the chain.

How Fast? — Decompose the Start

Binary chain: eigenvectors $[\tfrac12, \tfrac12]^\top$ ($\lambda = 1$) and $[1, -1]^\top$ ($\lambda = 1 - 2\alpha$)

Write the pinned start in that basis:

$$\pi_0 = \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \underbrace{\begin{bmatrix} \tfrac12 \\[2pt] \tfrac12 \end{bmatrix}}_{\pi^\star} + \; \tfrac12 \underbrace{\begin{bmatrix} 1 \\ -1 \end{bmatrix}}_{\text{error direction}}$$

Check: $\tfrac12 + \tfrac12 = 1$ and $\tfrac12 - \tfrac12 = 0$. ✓

How Fast? — Apply $P^t$

$P$ fixes $\pi^\star$ and rescales the error direction by its eigenvalue:

$$\begin{aligned} \pi_t = P^t \pi_0 &\stackrel{(\text{linearity})}{=} P^t \pi^\star + \tfrac12\, P^t \begin{bmatrix} 1 \\ -1 \end{bmatrix} \\[4pt] &\stackrel{(\text{eigen})}{=} \pi^\star + \tfrac12\, (1 - 2\alpha)^t \begin{bmatrix} 1 \\ -1 \end{bmatrix} \end{aligned}$$

Each multiplication by $P$: one more factor of $(1 - 2\alpha)$ on the error.

How Fast? — Geometric Convergence

At $\alpha = \tfrac14$: error factor $1 - 2\alpha = \tfrac12$

$$\Pr(X_t = 0) = \tfrac12 + \tfrac12 \left(\tfrac12\right)^t: \quad 1, \; \tfrac34, \; \tfrac58, \; \tfrac{9}{16}, \; \tfrac{17}{32}, \dots$$
  • Exactly the Section 05 table: mystery solved
  • Second eigenvalue = speed of forgetting the start

Eigenvalue $1$: where the chain settles. The next-largest eigenvalue: how fast.

09

Discrete Diffusion

Noise forward, learn backward

Idea — Destroy, Then Learn to Rebuild

Start from data: $X_0 \sim p_0$ (the data distribution)

  • Forward: corrupt step by step with a Markov chain
  • Backward: train a network to undo one step
  • Generate: start from pure noise, undo repeatedly

Today's chain machinery tells us exactly what "pure noise" is: the limiting distribution.

The Noising Matrix

States $\{1, \dots, n\}$; keep with prob. $1 - \epsilon$, else jump uniformly:

$$P = \begin{bmatrix} 1-\epsilon & \tfrac{\epsilon}{n-1} & \cdots & \tfrac{\epsilon}{n-1} \\[2pt] \tfrac{\epsilon}{n-1} & 1-\epsilon & \cdots & \tfrac{\epsilon}{n-1} \\ \vdots & & \ddots & \vdots \\ \tfrac{\epsilon}{n-1} & \tfrac{\epsilon}{n-1} & \cdots & 1-\epsilon \end{bmatrix}$$

The forward process: a 1st-order Markov chain, $\pi_{t+1} = P\pi_t$.

Noising Matrix — Sanity Checks

Column sums:

$$(1 - \epsilon) + (n-1)\cdot\tfrac{\epsilon}{n-1} = 1 \qquad \checkmark \;\text{ (stochastic)}$$

Symmetry:

$$P_{u,v} = P_{v,u} \;=\; \tfrac{\epsilon}{n-1} \;\;\text{ for } u \neq v \qquad \checkmark \;\text{ (symmetric)}$$

Pure Noise = Uniform

$P$ is symmetric: the Section 07 exercise applies directly

$$\pi^\star = \begin{bmatrix} \tfrac1n \\ \vdots \\ \tfrac1n \end{bmatrix}, \qquad \pi_\infty = \pi^\star \;\text{ (uniform)}$$
  • Limiting distribution: uniform, whatever the data $p_0$ was
  • For large $N$: $\pi_N \approx \pi^\star$, and $\pi_N$ is easy to sample

Forward Chain — Data Dissolves

Each step flips symbols with prob. $\epsilon$: structure dissolves into uniform noise

Learning to Denoise

Train a neural network to undo one step:

$$X_t \;\approx\; f_\theta(X_{t+1}, \, t)$$
  • Input: the noisier symbol $X_{t+1}$ and the step index $t$
  • Training data: free, from running the forward chain on real data

One small denoising task per step, instead of one giant generation task.

Generation — Run the Chain Backwards

  1. Sample $\tilde{X}_N$ from the uniform distribution ($\approx \pi_N$, for large $N$)
  2. For $t = N-1, \dots, 0$:  $\tilde{X}_t = f_\theta(\tilde{X}_{t+1}, \, t)$
  3. Output $\tilde{X}_0$: behaves like a fresh sample from $p_0$

Uniform noise in, data-like sample out.

Why It Works — The Markov Picture

  • Forward: limiting distribution uniform, so noise is a known, samplable start
  • Backward: each learned step retraces one Markov transition
  • Chain length $N$: large enough that $\pi_N \approx \pi^\star$

Key idea of generative diffusion: the chain picks its noise distribution for free.

Recap — Today's Chain

$$\begin{aligned} &P_{X^n} \stackrel{(\text{Markov})}{=} \textstyle\prod_i P_{X_i \mid X_{i-1}}, \qquad \pi_i \stackrel{(\text{Thm 1})}{=} P\,\pi_{i-1}, \qquad \pi_t \stackrel{(\text{Thm 2})}{=} P^t \pi_0 \\[6pt] &\pi^\star \stackrel{(\text{def})}{=} P\,\pi^\star \;\;\text{(eigenvalue 1)}, \qquad \pi_\infty \stackrel{(\text{Thm 4})}{=} P\,\pi_\infty \end{aligned}$$
  • Sequence models: i.i.d. → Markov → stationary → practical
  • Long-run behavior: an eigenvector computation
