Why Cross-Entropy?

The loss you already use

The Loss You Already Use

Every classifier you have trained ends here:

# image classifiers, language models, ... criterion = nn.CrossEntropyLoss() loss = criterion(logits, labels) loss.backward()

Default choice, everywhere. Rarely questioned.

Today's Question

Model outputs label probabilities $f(x)$; the loss is

$$\ell\bigl(f(x), y\bigr) = \log \frac{1}{f(x)_y}$$
  • Why $\log$?
  • Why the reciprocal?
  • Any decreasing function of $f(x)_y$ penalizes wrong answers

Today: derive this loss, not accept it.

The Route

One theorem powers everything today, in four costumes:

  • Guessing: surprise bill with the wrong pmf
  • Betting: log-wealth lost per race
  • Coding / next-token prediction: bits per symbol, perplexity
  • Training: the loss in nn.CrossEntropyLoss
02

Recall & Teaser

Entropy, Jensen, the wrong pmf

Recall — Surprisal & Entropy

From Lecture 1: rare outcome = big surprise

$$S(x) = \log \frac{1}{p_X(x)}, \qquad H(X) = \mathbb{E}\Bigl[\log \frac{1}{p_X(X)}\Bigr]$$
  • $H(X)$: expected surprisal, in bits
  • Priced by the true pmf $p_X$
  • Bounds: $0 \leq H(X) \leq \log M$

Recall — Jensen's Inequality

Recall (Jensen, Lecture 1).

For concave $f$:

$$\mathbb{E}[f(X)] \;\leq\; f\bigl(\mathbb{E}[X]\bigr)$$

Strictly concave $f$: equality iff $X$ is constant.

Recall — The Jensen Trick

Max-entropy proof pattern from Lecture 1:

$$H(X) = \mathbb{E}\Bigl[\log \tfrac{1}{p_X(X)}\Bigr] \;\stackrel{(\text{Jensen})}{\leq}\; \log \mathbb{E}\Bigl[\tfrac{1}{p_X(X)}\Bigr] \;\stackrel{(\text{cancel})}{=}\; \log M$$
  • Move $\log$ outside the expectation
  • Weight $p_X(x)$ cancels the value $1/p_X(x)$

Same two moves prove today's main theorem.

The Teaser — A Wrong Distribution

Surprisal used the true $p_X$. A model only has a guess $Q$:

$$\mathbb{E}\Bigl[\log \frac{1}{Q(X)}\Bigr] \;\;\stackrel{?}{\gtrless}\;\; H(X) = \mathbb{E}\Bigl[\log \frac{1}{p_X(X)}\Bigr]$$
  • Outcomes still drawn from $p_X$
  • Surprise priced by the wrong pmf $Q$
  • Cheaper, or more expensive?
03

The Mismatch Theorem

The cost of guessing with $Q$

Intuition — Guessing with the Wrong Model

Surprise bill $\log 1/Q(x)$, but $x$ arrives with frequency $P(x)$

Expect: wrong beliefs can only raise the average bill.

Theorem — Mismatch

Theorem 1 (mismatch).

For any pmf $Q$ on $\mathcal{X}$:

$$H(X) \;\leq\; \mathbb{E}\Bigl[\log \frac{1}{Q(X)}\Bigr] = \sum_{x} p_X(x) \log \frac{1}{Q(x)}$$

Equality if and only if $Q = p_X$.

The true pmf is the unique cheapest pricing.

Example — Wrong Guess, Real Cost

Truth $P = (0.01,\, 0.99)$; model believes $Q = (0.1,\, 0.9)$

$$\mathbb{E}\Bigl[\log \tfrac{1}{Q(X)}\Bigr] = 0.01 \log \tfrac{1}{0.1} + 0.99 \log \tfrac{1}{0.9} \approx 0.184 \text{ bits}$$
$$H(X) \approx 0.081 \text{ bits} \qquad\Rightarrow\qquad \text{overpay} \approx 0.103 \text{ bits}$$

More than double the optimal bill, every draw.

Mismatch — Proof Overview

Target: the gap is never positive

$$H(X) - \mathbb{E}\Bigl[\log \frac{1}{Q(X)}\Bigr] \;\leq\; 0$$
  1. Merge the gap into one expectation of a log-ratio
  2. Jensen: move $\log$ outside
  3. Cancel: weight $p_X$ kills the ratio, $\sum_x Q(x) = 1$

Proof — Step 1: Merge the Gap

Both terms are expectations under $p_X$:

$$\begin{aligned} H(X) - \mathbb{E}\Bigl[\log \tfrac{1}{Q(X)}\Bigr] &\stackrel{(\text{linearity})}{=} \mathbb{E}\Bigl[\log \tfrac{1}{p_X(X)} - \log \tfrac{1}{Q(X)}\Bigr] \\[2pt] &\stackrel{(\log a - \log b)}{=} \mathbb{E}\Bigl[\log \tfrac{Q(X)}{p_X(X)}\Bigr] \end{aligned}$$

One expectation, one ratio: ready for Jensen.

Proof — Step 2: Jensen

$\log$ is concave: expectation of $\log$ $\leq$ $\log$ of expectation

$$\mathbb{E}\Bigl[\log \frac{Q(X)}{p_X(X)}\Bigr] \;\stackrel{(\text{Jensen})}{\leq}\; \log \mathbb{E}\Bigl[\frac{Q(X)}{p_X(X)}\Bigr]$$

Apply Jensen to the random variable $Z = \tfrac{Q(X)}{p_X(X)}$

Exactly the Lecture 1 move, new ratio inside.

Proof — Step 3: The Cancellation

Write the expectation as a sum; the weight cancels:

$$\log \mathbb{E}\Bigl[\frac{Q(X)}{p_X(X)}\Bigr] = \log \sum_x p_X(x) \frac{Q(x)}{p_X(x)} \stackrel{(\text{cancel})}{=} \log \sum_x Q(x) \stackrel{(\text{pmf})}{=} \log 1 = 0$$
$$\therefore\;\; H(X) - \mathbb{E}\Bigl[\log \tfrac{1}{Q(X)}\Bigr] \leq 0 \qquad \blacksquare$$

Proof — Equality Condition

Jensen (strictly concave $\log$) is tight iff the ratio is constant:

$$\frac{Q(x)}{p_X(x)} = c \ \ \text{for all } x \quad\Longrightarrow\quad Q = p_X$$

Both sum to one, so the constant is $c = 1$

Only the truth prices surprise at cost $H(X)$.

The Edge Case — Zeros in $p_X$

Where $p_X(x) = 0$ the ratio $Q(x)/p_X(x)$ is undefined. Fix: sum over the support

$$\mathbb{E}\Bigl[\log \tfrac{Q(X)}{p_X(X)}\Bigr] \;\stackrel{(\text{Jensen})}{\leq}\; \log \sum_{x:\, p_X(x) \gt 0} Q(x) \;\stackrel{(\text{sub-sum})}{\leq}\; \log 1 = 0$$
  • Both must be tight: $Q/p_X$ constant on the support, no $Q$-mass off it
  • Together: $Q = p_X$. Theorem 1 holds with zeros $\;\blacksquare$

Exercise: what if $Q(x) = 0$ at some $x$ with $p_X(x) \gt 0$? (Answer after the KL definition.)

Mismatch — Proof Summary

$$H(X) - \mathbb{E}\Bigl[\log \tfrac{1}{Q(X)}\Bigr] \;\stackrel{(1)}{=}\; \mathbb{E}\Bigl[\log \tfrac{Q(X)}{p_X(X)}\Bigr] \;\stackrel{(\text{Jensen})}{\leq}\; \log \mathbb{E}\Bigl[\tfrac{Q(X)}{p_X(X)}\Bigr] \;\stackrel{(\text{cancel})}{=}\; \log 1 = 0$$
  • Key trick: expectation weight cancels the denominator
  • Jensen direction from concavity of $\log$
  • Tight iff $Q = p_X$

Definition — Cross-Entropy

Definition (cross-entropy).

The mismatch bill has a name:

$$H(P, Q) \;=\; \sum_{x} P(x) \log \frac{1}{Q(x)}$$

Expected surprisal: outcomes from $P$, priced by $Q$

Two arguments "crossed": hence cross-entropy.

Implication — The Gap Deserves a Name

Every wrong model overpays; by how much?

The gap gets its own section.

04

KL Divergence

Definition, $D \geq 0$, asymmetry

Definition — KL Divergence

Definition (Kullback–Leibler divergence).

For pmfs $P$ and $Q$ on $\mathcal{X}$:

$$D(P \,\|\, Q) \;=\; \sum_{x \in \mathcal{X}} P(x) \log \frac{P(x)}{Q(x)}$$

Also called relative entropy

Expected log-ratio of truth to model, weighted by truth.

Conventions — Zeros in the Sum

Two terms need a rule; both come from limits:

$$0 \cdot \log \tfrac{0}{q} = 0 \quad (t \log t \to 0 \text{ as } t \downarrow 0), \qquad p \cdot \log \tfrac{p}{0} = +\infty \quad (p \gt 0)$$

Finiteness.

$$D(P \,\|\, Q) \lt \infty \;\iff\; \operatorname{supp} P \subseteq \operatorname{supp} Q$$

Truth may be narrower than the model, never wider

Support in Deep Learning

  • CE on the true label is $\log 1/Q(y)$: $Q(y) = 0$ gives loss $\infty$
  • Softmax outputs $e^{z_i} / \sum_j e^{z_j} \gt 0$: every label keeps some mass, loss stays finite
  • Label smoothing widens the truth: $(1-\varepsilon)\, y^{(o)} + \varepsilon / M$ has full support

Forward KL is infinite the moment the model rules out something the truth allows.

Picture — Truth vs Model

$P = (0.5,\, 0.4,\, 0.1)$ against uniform $Q = (\tfrac13, \tfrac13, \tfrac13)$:

Blue solid = truth $P$; dashed = model $Q$.

Worked Example — $D(P \,\|\, Q)$ by Hand

$P = (0.5, 0.4, 0.1)$,  $Q = (\tfrac13, \tfrac13, \tfrac13)$, term by term:

$$\begin{aligned} D(P \,\|\, Q) &= 0.5 \log \tfrac{0.5}{1/3} + 0.4 \log \tfrac{0.4}{1/3} + 0.1 \log \tfrac{0.1}{1/3} \\[2pt] &\approx 0.292 + 0.105 - 0.174 \;=\; 0.224 \text{ bits} \end{aligned}$$

Negative terms allowed; the sum stays $\geq 0$

Uniform $Q$ shortcut: $D = \log 3 - H(P)$.

Worked Example — Swap the Arguments

Same pair, opposite direction:

$$\begin{aligned} D(Q \,\|\, P) &= \tfrac13 \log \tfrac{1/3}{0.5} + \tfrac13 \log \tfrac{1/3}{0.4} + \tfrac13 \log \tfrac{1/3}{0.1} \\[2pt] &\approx -0.195 - 0.088 + 0.579 \;=\; 0.296 \text{ bits} \end{aligned}$$
$$D(P \,\|\, Q) \approx 0.224 \;\neq\; 0.296 \approx D(Q \,\|\, P)$$

Divergence, Not Distance

  • Not symmetric: $D(P \| Q) \neq D(Q \| P)$ (just computed)
  • No triangle inequality either
  • Still: $D \geq 0$, and $D = 0$ iff $P = Q$

Distance-like separation without distance axioms: hence divergence.

Which argument holds the truth matters. Keep track.

Theorem — Non-Negativity of KL

Theorem 2 (information inequality).

For any pmfs $P, Q$ on $\mathcal{X}$:

$$D(P \,\|\, Q) \;\geq\; 0$$

Equality if and only if $P = Q$.

A "distance" that could go negative would be useless.

Proof — Already Done

The mismatch proof bounded exactly $-D(P \,\|\, Q)$:

$$-D(P \,\|\, Q) = \mathbb{E}_P\Bigl[\log \tfrac{Q(X)}{P(X)}\Bigr] \;\stackrel{(\text{Jensen})}{\leq}\; \log \sum_x Q(x) = \log 1 = 0 \qquad \blacksquare$$

Equality: Jensen tight iff $Q/P$ constant iff $P = Q$

Theorem 1 and Theorem 2 are the same fact.

Technique — $t \log t$ Is Convex

$$f(t) = t \log t, \qquad f''(t) = \frac{1}{t \ln 2} \gt 0 \quad (t \gt 0): \ \text{strictly convex}$$

Lemma — Log-Sum Inequality

Lemma (log-sum inequality).

For $a_1, \dots, a_n \geq 0$ and $b_1, \dots, b_n \gt 0$:

$$\sum_{i=1}^n a_i \log \frac{a_i}{b_i} \;\geq\; \Bigl(\sum_i a_i\Bigr) \log \frac{\sum_i a_i}{\sum_i b_i}$$

Equality iff $a_i / b_i$ is the same for all $i$

Merging terms can only lower the sum. Cover & Thomas, Thm 2.7.1.

Proof — Jensen on $t \log t$

Weights $w_i = b_i / \sum_j b_j$, points $t_i = a_i / b_i$, convex $f(t) = t \log t$:

$$\begin{aligned} \sum_i a_i \log \frac{a_i}{b_i} &= \Bigl(\sum_j b_j\Bigr) \sum_i w_i\, f(t_i) \;\stackrel{(\text{Jensen})}{\geq}\; \Bigl(\sum_j b_j\Bigr) f\Bigl(\sum_i w_i t_i\Bigr) \\[2pt] &= \Bigl(\sum_j b_j\Bigr) f\Bigl(\frac{\sum_i a_i}{\sum_j b_j}\Bigr) = \Bigl(\sum_i a_i\Bigr) \log \frac{\sum_i a_i}{\sum_j b_j} \qquad \blacksquare \end{aligned}$$

Strict convexity: equality iff all $t_i$ equal.

Corollary — Theorem 2, Zeros Included

Take $a_x = P(x)$, $b_x = Q(x)$ over $\operatorname{supp} P$ (if some $Q(x) = 0$ there, $D = +\infty \geq 0$ anyway):

$$D(P \,\|\, Q) \;\stackrel{(\text{log-sum})}{\geq}\; 1 \cdot \log \frac{1}{\sum_{x \in \operatorname{supp} P} Q(x)} \;\stackrel{(\text{sub-sum} \leq 1)}{\geq}\; \log 1 = 0 \qquad \blacksquare$$
  • Equality: $P/Q$ constant on the support, no $Q$-mass off it, so $P = Q$
  • The convention $0 \log 0 = 0$ handled every $P(x) = 0$ term for free

Theorem — KL Is Convex in the Pair

Theorem 3 (convexity of KL).

For pmfs $(P_1, Q_1)$, $(P_2, Q_2)$ on $\mathcal{X}$ and $\lambda \in [0, 1]$:

$$D\bigl(\lambda P_1 + (1-\lambda) P_2 \,\|\, \lambda Q_1 + (1-\lambda) Q_2\bigr) \;\leq\; \lambda\, D(P_1 \,\|\, Q_1) + (1-\lambda)\, D(P_2 \,\|\, Q_2)$$

Mixing truths and models together never increases the divergence. Cover & Thomas, Thm 2.7.2.

Proof — Log-Sum, One $x$ at a Time

Fix $x$. Two-term log-sum with $a_1 = \lambda P_1(x)$, $a_2 = (1-\lambda) P_2(x)$, $b_1 = \lambda Q_1(x)$, $b_2 = (1-\lambda) Q_2(x)$:

$$(a_1 + a_2) \log \frac{a_1 + a_2}{b_1 + b_2} \;\leq\; \lambda P_1(x) \log \frac{P_1(x)}{Q_1(x)} + (1-\lambda) P_2(x) \log \frac{P_2(x)}{Q_2(x)}$$

The $\lambda$'s cancel inside each log. Sum over $x$ $\;\blacksquare$

  • Used for the data-processing inequality (prob03) and variational bounds (Section 07)

Theorem — Cross-Entropy = Entropy + KL

Theorem 4 (cross-entropy decomposition).

For any pmfs $P, Q$ on $\mathcal{X}$ with $\operatorname{supp} P \subseteq \operatorname{supp} Q$:

$$\underbrace{\sum_{x} P(x) \log \frac{1}{Q(x)}}_{H(P,\, Q)} \;=\; H(P) \;+\; D(P \,\|\, Q)$$

The mismatch gap is the KL divergence. Theorem 1, now an exact identity.

Proof — Split the Log-Ratio

$$\begin{aligned} D(P \,\|\, Q) &= \sum_x P(x) \log \frac{P(x)}{Q(x)} \\[2pt] &\stackrel{(\text{split logs})}{=} \underbrace{\sum_x P(x) \log P(x)}_{-H(P)} \;+\; \underbrace{\sum_x P(x) \log \tfrac{1}{Q(x)}}_{H(P,\, Q)} \\[2pt] &= -H(P) + H(P, Q) \qquad \blacksquare \end{aligned}$$

Cross-entropy = entropy + KL. Minimizing $H(P, Q)$ over $Q$ minimizes $D(P \,\|\, Q)$.

Theorem — KL Adds over Independent Samples

Theorem 5 (additivity).

Let $P^n(x_1, \dots, x_n) = \prod_i P(x_i)$ and $Q^n$ likewise (i.i.d. samples). Then

$$D(P^n \,\|\, Q^n) \;=\; n \cdot D(P \,\|\, Q)$$

KL is a rate: bits of mismatch per sample. Check: $P = (0.5, 0.4, 0.1)$, $Q$ uniform, $n = 3$: $0.672 = 3 \times 0.224$.

Proof — The Log of a Product

$$\begin{aligned} D(P^n \,\|\, Q^n) &= \mathbb{E}_{P^n}\Bigl[\log \prod_{i=1}^n \frac{P(X_i)}{Q(X_i)}\Bigr] \;\stackrel{(\text{log of product})}{=}\; \sum_{i=1}^n \mathbb{E}\Bigl[\log \frac{P(X_i)}{Q(X_i)}\Bigr] \\[2pt] &\stackrel{(X_i \sim P)}{=}\; n \cdot D(P \,\|\, Q) \qquad \blacksquare \end{aligned}$$
  • Each factor sees its own $X_i$; linearity of expectation
  • Cross-entropy inherits it: $H(P^n, Q^n) = n\, H(P, Q)$

KL Is a Rate — Law of Large Numbers View

$$\frac{1}{n} \sum_{i=1}^n \log \frac{P(x_i)}{Q(x_i)} \;\longrightarrow\; D(P \,\|\, Q) \qquad (x_i \stackrel{\text{iid}}{\sim} P,\ n \to \infty)$$
$D(P\,\|\,Q) = 0.224$ $\tfrac1n\sum_i \log \tfrac{P(x_i)}{Q(x_i)}$

LLN not proved here (prob05). Simulation: $P = (0.5, 0.4, 0.1)$, $Q$ uniform, 1000 draws

Definition — $f$-Divergence

Definition ($f$-divergence).

For convex $f : (0, \infty) \to \mathbb{R}$ with $f(1) = 0$, and pmfs $P, Q$ with $\operatorname{supp} P \subseteq \operatorname{supp} Q$:

$$D_f(P \,\|\, Q) \;=\; \sum_{x} Q(x)\, f\Bigl(\frac{P(x)}{Q(x)}\Bigr)$$

KL is the case $f(t) = t \log t$. Csiszár (1967); Ali & Silvey (1966).

Theorem — Every $f$-Divergence Is Non-Negative

Theorem 6 ($f$-divergences are non-negative).

$D_f(P \,\|\, Q) \geq 0$, with equality if $P = Q$ (and only then, when $f$ is strictly convex at $1$)

Proof. Same Jensen move: weights $Q(x)$, points $P(x)/Q(x)$

$$\sum_x Q(x)\, f\Bigl(\tfrac{P(x)}{Q(x)}\Bigr) \;\stackrel{(\text{Jensen})}{\geq}\; f\Bigl(\sum_x Q(x) \tfrac{P(x)}{Q(x)}\Bigr) = f(1) = 0 \qquad \blacksquare$$

What KL Alone Brings

  • Additive over independent samples: $D(P^n \| Q^n) = n D(P \| Q)$ (Theorem 5)
  • Decomposes: $H(P, Q) = H(P) + D(P \| Q)$; the $P$-only term is a constant (Theorem 4)
  • Its integrand is a surprisal difference: $\log \tfrac{1}{Q} - \log \tfrac{1}{P}$, the guessing bill

Left open: is KL the only $f$-divergence with these properties? No uniqueness theorem today.

Preview — Where $D(P \,\|\, Q)$ Shows Up

  • Betting and coding (Section 05): log-wealth and bits lost per round
  • Training (Section 06): CE loss $= D(\text{label} \,\|\, \text{softmax})$
  • Deep learning at large (Section 07): distillation, RLHF, VAEs, each a KL term
$$D(P \,\|\, Q): \ \text{the price of believing } Q \text{ in a } P \text{ world}$$
05

Betting, Coding, Predicting

Doubling rate, code length, perplexity: one quantity, three costumes

Setup — Red or Black

After the bet: $S = 2qB$ if red,  $S = 2(1-q)B$ if black. Assume $p \lt 1/2$: black is the favorite

First Try — Maximize $\mathbb{E}[S]$

$$\mathbb{E}[S] = p \cdot 2qB + (1-p) \cdot 2(1-q)B$$
  • Linear in $q$, slope $2B(2p - 1) \lt 0$
  • Maximized at $q = 0$: all-in on black

Expected value says: bet everything on the favorite.

Why All-In Fails

Repeat the all-in strategy: first red = total ruin

Eventually broke, with probability one

Fix — Maximize $\mathbb{E}[\log S]$

  • $\log 0 = -\infty$: ruin gets infinite penalty; log-wealth adds over repeated bets
$$\begin{aligned} \mathbb{E}[\log S] &= p \log (2qB) + (1-p) \log \bigl(2(1-q)B\bigr) \\[2pt] &\stackrel{(\text{split logs})}{=} \log 2B - \Bigl(p \log \tfrac{1}{q} + (1-p) \log \tfrac{1}{1-q}\Bigr) \end{aligned}$$

The bracket is a cross-entropy: truth $(p, 1-p)$, priced by $(q, 1-q)$. We know its minimizer

Theorem — Proportional Betting

Theorem 7 (proportional betting).

In the binary game with odds 2, $\mathbb{E}[\log S]$ is maximized iff $q = p$:

$$\max_q \mathbb{E}[\log S] = \log 2B - h_2(p)$$

Proof. Theorem 4: $\mathbb{E}[\log S] = \log 2B - h_2(p) - D\bigl((p, 1{-}p) \,\|\, (q, 1{-}q)\bigr)$. Only $D$ moves with $q$; $D \geq 0$, zero iff $q = p$ $\;\blacksquare$

Definition — Doubling Rate

Definition (doubling rate).

$$W = \log 2 - \Bigl(p \log \tfrac{1}{q} + (1-p) \log \tfrac{1}{1-q}\Bigr), \qquad S_n \approx B \times 2^{nW} \ \text{after } n \text{ bets}$$

Cost of a wrong belief: $\;W_{\text{opt}} - W_q = D\bigl((p, 1{-}p) \,\|\, (q, 1{-}q)\bigr)$ bits per bet

Log-wealth grows linearly at slope $W$; KL is the slope you forfeit.

Picture — Growth at Rate $W$

On the log scale, strategies are straight lines with slope $W$

Horse Racing — $M$ Horses

Horse $i$ wins with probability $p_X(i)$; odds $M$-for-1 on every horse

Winner takes all: $S = M\, Q(i)\, B$ when horse $i$ wins

Theorem — Optimal Horse Betting

Theorem 8 (proportional betting, $M$ horses).

$$\mathbb{E}[\log S] = \log B + \log M - \sum_{i=1}^{M} p_X(i) \log \frac{1}{Q(i)}$$

Maximized iff $Q = p_X$; the loss for betting $Q$ is $D(p_X \,\|\, Q)$

Same statement, $M$ outcomes instead of 2.

Proof — Same Two Moves

$$\begin{aligned} \mathbb{E}[\log S] &= \sum_{i=1}^{M} p_X(i) \log \bigl(M\, Q(i)\, B\bigr) \\[2pt] &\stackrel{(\text{split logs})}{=} \log B + \log M - \sum_{i=1}^{M} p_X(i) \log \tfrac{1}{Q(i)} \\[2pt] &\stackrel{(\text{CE} = H + D)}{=} \log B + \log M - H(p_X) - D(p_X \,\|\, Q) \qquad \blacksquare \end{aligned}$$

Only $D$ depends on $Q$: doubling rate $W(Q) = \log M - H(p_X) - D(p_X \| Q)$

Worked Example — A 3-Horse Race

Win probabilities $p = (\tfrac12, \tfrac14, \tfrac14)$; odds 3-for-1

$$W^{*} = \log 3 - H(p) = 1.585 - 1.5 = 0.085 \text{ bits/race}$$
  • Optimal bet: $Q = p$, i.e. $(\tfrac12, \tfrac14, \tfrac14)$ of the budget
  • 100 races: wealth $\times\, 2^{8.5} \approx 362$

Worked Example — Three Gamblers

Bet $Q$$D(p \,\|\, Q)$$W = W^* - D$After 100 races
$(\tfrac12, \tfrac14, \tfrac14) = p$$0$$+0.085$$\times\, 362$

Same race, same odds: beliefs alone separate rich from ruined.

Implication — Betting = Modeling

  • Optimal gambler = gambler with the true model
  • $D(p \,\|\, Q)$: exponential rate of lost wealth
  • Same $D$ that priced the guessing bill

A classifier also "bets" a distribution on labels: same penalty, next section.

Coding Costume — Code Lengths

Give symbol $x$ a codeword of length $\ell_Q(x) = \lceil \log 1/Q(x) \rceil$ bits (the Shannon code for model $Q$)

$$H(P) + D(P \,\|\, Q) \;\leq\; \mathbb{E}_P[\ell_Q(X)] \;\lt\; H(P) + D(P \,\|\, Q) + 1$$
  • $P = (0.5, 0.4, 0.1)$, $Q = P$: lengths $(1, 2, 4)$, $\mathbb{E}[\ell] = 1.70$, floor $H(P) = 1.36$
  • $Q$ uniform: lengths $(2, 2, 2)$, $\mathbb{E}[\ell] = 2.00$, floor $H(P, Q) = 1.58$

Code existence (Kraft inequality) stated, not proved: Cover & Thomas ch. 5; note §5.8.

Predicting Costume — Language Models

$$\ell_t = \log \frac{1}{Q(x_t \mid x_{\lt t})}, \qquad \text{training loss} = \frac{1}{T} \sum_{t=1}^T \ell_t \ \text{(nats in torch)}$$

Surprisal of the true next token, averaged: a cross-entropy per token

Definition — Perplexity

Definition (perplexity).

$$\mathrm{PPL} \;=\; 2^{\,\text{CE in bits}} \;=\; e^{\,\text{CE in nats}}$$

Uniform guess over $K$ tokens: $\text{CE} = \log K$ bits, $\mathrm{PPL} = K$

  • $K = 2,\ 10,\ 50{,}000$:   $1,\ 3.32,\ 15.61$ bits;   PPL $= K$
  • Read it as the effective number of equally likely next tokens

Shannon's Guessing Game, New Costume

  • Coding: CE per token = bits per token to compress the text
  • Betting: fair odds $K$ on the next token; growth rate from Theorem 8
$$W = \log K - \text{CE} = \log \frac{K}{\mathrm{PPL}} \qquad\Longrightarrow\qquad 2^{W} = \frac{K}{\mathrm{PPL}}$$

Lower perplexity: fewer bits per token, faster doubling. Same $D(P \,\|\, Q)$ behind all three.

Theorem 8 assumes i.i.d. races; text is not, so $W$ is a per-token average.

06

Cross-Entropy Loss

CE = entropy + KL

Setup — Classification

  • Input $x \in \mathcal{X}$ (e.g. $\mathbb{R}^n$)
  • Label $y \in [M] = \{1, \dots, M\}$
  • Classifier $f$: outputs a pmf over labels
$$f(x) = \bigl(f(x)_1, \dots, f(x)_M\bigr), \quad \textstyle\sum_i f(x)_i = 1$$

$f(x)_i$: believed probability of label $i$.

The Classifier Bets a Distribution

Loss = mismatch between the bet $Q$ and the truth $P$.

Definition — Cross-Entropy Loss

Definition (cross-entropy loss).

For prediction $f(x)$ and true label $y$:

$$\ell\bigl(f(x), y\bigr) = \log \frac{1}{f(x)_y}$$

Surprisal of the true label under the model's pmf

More belief on the truth: lower loss. But why this shape?

Worked Example — 3-Class Loss

True label $y = \text{cat}$; three models bet:

Which Loss? Three Candidates

Any decreasing function of $f(x)_y$ rewards the truth:

$$\underbrace{1 - f(x)_y}_{\text{linear}} \qquad \underbrace{\textstyle\sum_i \bigl(f(x)_i - \mathbb{1}[i = y]\bigr)^2}_{\text{Brier}} \qquad \underbrace{\log \tfrac{1}{f(x)_y}}_{\text{log}}$$
  • "Higher belief on truth = lower loss": all three qualify
  • Need a criterion: which losses reward honest probabilities?

Definition — Proper Scoring Rule

Definition (proper, strictly proper).

Loss $\ell(Q, y)$ for report $Q$ and outcome $y$. Expected loss when the truth is $P$:

$$L(P, Q) = \mathbb{E}_{Y \sim P}\bigl[\ell(Q, Y)\bigr]$$

Proper: $L(P, P) \leq L(P, Q)$ for all $Q$. Strictly proper: equality iff $Q = P$

Honesty is optimal: reporting the truth is never beaten.

Log Loss Is Strictly Proper

$$\begin{aligned} L(P, Q) &= \sum_i P_i \log \frac{1}{Q_i} = H(P, Q) \;\stackrel{(\text{Thm 4})}{=}\; H(P) + D(P \,\|\, Q) \\[2pt] &\stackrel{(\text{Thm 2})}{\geq}\; H(P) = L(P, P) \end{aligned}$$
  • Equality iff $D(P \,\|\, Q) = 0$ iff $Q = P$: strictly proper
  • This is the mismatch theorem, third costume

Linear Loss Is Not Proper

$$L(P, Q) = \sum_i P_i (1 - Q_i) = 1 - \sum_i P_i Q_i$$
  • Linear in $Q$: minimized at a vertex, $Q =$ one-hot on $\arg\max_i P_i$
  • $P = (0.7, 0.2, 0.1)$: honest $Q = P$ scores $0.460$; all-in $Q = (1, 0, 0)$ scores $0.300$

Honesty loses. The linear loss rewards overconfidence, so it cannot train probabilities.

Brier Score Is Proper

$$\begin{aligned} L(P, Q) &= \sum_i P_i \sum_j \bigl(Q_j - \mathbb{1}[j = i]\bigr)^2 \;\stackrel{(\text{expand})}{=}\; \sum_j Q_j^2 - 2 \sum_j P_j Q_j + 1 \\[2pt] &\stackrel{(\pm \sum_j P_j^2)}{=}\; \sum_j (Q_j - P_j)^2 + \sum_j P_j (1 - P_j) \end{aligned}$$
  • First sum $\geq 0$, zero iff $Q = P$; second sum is $P$-only: strictly proper
  • $P = (0.7, 0.2, 0.1)$: $Q = P$ scores $0.460$; $Q = (1, 0, 0)$ scores $0.600$

Why Log, Then? Locality

  • Log loss is local: it reads only $Q_y$, the mass on what happened
  • Brier reads every $Q_j$: the penalty depends on where the rest went
  • For $M \geq 3$ outcomes, the only local strictly proper scores are $a \log Q_y + b$, $a \gt 0$

Uniqueness stated, not proved: Bernardo (1979); Gneiting & Raftery (2007). Note §6.4.

Strictly proper + local = log loss. Reciprocal and log are forced, not chosen.

One-Hot Label = A Distribution

Definition (one-hot vector).

$$y^{(o)}_i = \begin{cases} 1 & \text{if } y = i \\ 0 & \text{otherwise} \end{cases}$$

A valid pmf on $[M]$: the ground-truth distribution, deterministic at $y$

Now both objects are pmfs: truth $y^{(o)}$ vs model $f(x)$

Natural performance measure: their KL divergence.

Theorem — CE Loss = KL to the Truth

Theorem 9 (cross-entropy loss is a KL divergence).

$$\ell\bigl(f(x), y\bigr) \;=\; D\bigl(y^{(o)} \,\|\, f(x)\bigr)$$

The loss is the divergence from the model's pmf to the one-hot truth

Truth in the first slot: the asymmetry matters.

Proof — Compute the KL

Terms with $y^{(o)}_i = 0$ vanish, since $0 \log 0 = 0$:

$$\begin{aligned} D\bigl(y^{(o)} \,\|\, f(x)\bigr) &= \sum_{i=1}^{M} y^{(o)}_i \log \frac{y^{(o)}_i}{f(x)_i} \stackrel{(\text{only } i = y)}{=} 1 \cdot \log \frac{1}{f(x)_y} \\[2pt] &= \ell\bigl(f(x), y\bigr) \qquad \blacksquare \end{aligned}$$

One surviving term: the true label's surprisal.

Soft Labels — Same Story

True label a soft pmf $y^{(\text{soft})}$ (label smoothing, distillation):

$$D\bigl(y^{(\text{soft})} \,\|\, f(x)\bigr) = H\bigl(y^{(\text{soft})}, f(x)\bigr) - H\bigl(y^{(\text{soft})}\bigr)$$

Numbers: $y^{(\text{soft})} = (0.6, 0.3, 0.1)$, model $f(x) = (0.7, 0.2, 0.1)$

$$\underbrace{1.338}_{\text{CE}} = \underbrace{1.295}_{H} + \underbrace{0.042}_{D} \ \text{ bits}$$

One-hot case: $H(y^{(o)}) = 0$, so CE $=$ KL exactly.

Punchline — Min CE = Min KL

The label term $H(P)$ is fixed by the data: no $Q$ inside

$$\arg\min_{Q}\; H(P, Q) \;=\; \arg\min_{Q}\; \bigl[H(P) + D(P \,\|\, Q)\bigr] \;=\; \arg\min_{Q}\; D(P \,\|\, Q)$$

Training with CE loss = pulling $f(x)$ toward the truth, measured in KL.

Population View — Random Inputs

Data $(X, Y) \sim P_{XY}$; the classifier maps $x$ to a pmf $f(x)$ on $[M]$. Its risk:

$$\begin{aligned} R(f) &= \mathbb{E}\bigl[\ell(f(X), Y)\bigr] \;\stackrel{(\text{condition on } X)}{=}\; \mathbb{E}_X\Bigl[\sum_y P(y \mid X) \log \frac{1}{f(X)_y}\Bigr] \\[2pt] &= \mathbb{E}_X\bigl[H(P_{Y \mid X},\, f(X))\bigr] \end{aligned}$$

For each input, a cross-entropy between the true conditional $P_{Y \mid X = x}$ and the prediction

Theorem — Population Cross-Entropy

Theorem 10 (population decomposition).

$$R(f) \;=\; \underbrace{\mathbb{E}_X\bigl[H(P_{Y \mid X})\bigr]}_{\text{irreducible}} \;+\; \underbrace{\mathbb{E}_X\bigl[D(P_{Y \mid X} \,\|\, f(X))\bigr]}_{\geq 0,\ \text{model's fault}}$$

Proof. Theorem 4 at each $x$, then take $\mathbb{E}_X$ $\;\blacksquare$

The floor depends on the data only; prob03 names it $H(Y \mid X)$.

Corollary — The Bayes-Optimal Classifier

  • $R(f)$ is minimized iff $D(P_{Y \mid X} \,\|\, f(X)) = 0$ a.s., i.e. $f^*(x) = P(Y = \cdot \mid X = x)$
  • One-hot labels are samples from $P_{Y \mid X}$; CE still recovers the conditional pmf
  • So CE-trained outputs are meant to be calibrated probabilities, not just argmax scores

Population CE = learning $P(Y \mid X)$ in KL. Zero loss is not the goal when $H(P_{Y \mid X}) \gt 0$.

MLE = Min Cross-Entropy = Min KL

Samples $x_1, \dots, x_n \stackrel{\text{iid}}{\sim} P$; empirical pmf $\hat P_n(x) = \tfrac{1}{n} \#\{i : x_i = x\}$

$$\begin{aligned} \frac{1}{n} \sum_{i=1}^n \log \frac{1}{Q(x_i)} &\;\stackrel{(\text{group equal } x_i)}{=}\; \sum_x \hat P_n(x) \log \frac{1}{Q(x)} = H(\hat P_n, Q) \\[2pt] &\;\stackrel{(\text{Thm 4})}{=}\; H(\hat P_n) + D(\hat P_n \,\|\, Q) \end{aligned}$$
  • Left side: negative average log-likelihood. Maximum likelihood = minimum CE
  • Right side: $H(\hat P_n)$ is data-only. Maximum likelihood = minimum KL from the data

Softmax — Logits to a pmf

Definition (softmax).

$$s_i(z) = \frac{e^{z_i}}{\sum_{j=1}^M e^{z_j}}, \qquad s_i \gt 0, \quad \sum_i s_i = 1$$

CE loss on logits, in nats ($\ln$), as nn.CrossEntropyLoss computes it:

$\ell(z, y) = -\ln s_y(z) = -z_y + \ln \sum_j e^{z_j}$

Theorem — Softmax Gradient

Theorem 11 (gradient of CE on logits).

$$\frac{\partial \ell(z, y)}{\partial z_i} \;=\; s_i(z) - \mathbb{1}[i = y]$$

Proof. $\frac{\partial}{\partial z_i}(-z_y) = -\mathbb{1}[i = y]$;   $\frac{\partial}{\partial z_i} \ln \sum_j e^{z_j} = \frac{e^{z_i}}{\sum_j e^{z_j}} = s_i(z)$   $\blacksquare$

Gradient = predicted pmf minus one-hot truth: the residual, never saturating.

Why Logits? Log-Sum-Exp Stability

  • $e^{1000}$ overflows a float (Python: OverflowError); probabilities first, log second, fails
  • Shift by the max: $m = \max_j z_j$, then every exponent is $\leq 0$
$$\ln \sum_j e^{z_j} = m + \ln \sum_j e^{z_j - m}, \qquad z = (1000, 0, 0) \ \Rightarrow\ 1000.0$$

So nn.CrossEntropyLoss(logits, y) takes logits, not probabilities. Nats out; divide by $\ln 2 = 0.693$ for bits.

Why Not Squared Error on Softmax?

Chain rule through softmax: $\partial s_y / \partial z_y = s_y (1 - s_y)$. Any loss of $s_y$ inherits this factor

$s_y$ (mass on truth)CE: $s_y - 1$MSE factor $s_y(1 - s_y)$
$0.001$ (confidently wrong)$-0.999$$0.001$
$0.5$$-0.5$$0.25$
$0.9$$-0.1$$0.09$

Squared error learns slowest exactly when it is most wrong; CE's $-\ln s_y$ cancels the factor.

Implication — Why Log, Settled

  • $\log 1/Q$ is surprisal: the guessing, coding, betting cost (Theorems 1, 7, 8)
  • The only strictly proper, local score (Section 06, cited)
  • Population minimizer = true conditional $P(Y \mid X)$ (Theorem 10)
  • Gradient = residual, stable on logits (Theorem 11)

KL Across Deep Learning

Which direction, and where it hides

Forward vs Reverse — The Support Argument

Forward $D(P \,\|\, Q) = \sum P \log \tfrac{P}{Q}$

Where $P \gt 0$ and $Q \approx 0$: term explodes

$Q$ must cover all of $P$: zero-avoiding, mode-covering

Reverse $D(Q \,\|\, P) = \sum Q \log \tfrac{Q}{P}$

Where $P \approx 0$: $Q$ must be $\approx 0$ too

$Q$ may drop modes of $P$ for free: zero-forcing, mode-seeking

Same two pmfs, opposite failure modes. Minka (2005).

Picture — One Gaussian Fitted to Two Bumps

$P$: two bumps forward: $\mu=0,\ \sigma=2.10$ reverse: $\mu=2,\ \sigma=0.50$

$P = \tfrac12 \mathcal{N}(-2, 0.5^2) + \tfrac12 \mathcal{N}(2, 0.5^2)$ on a grid; $Q = \mathcal{N}(\mu, \sigma^2)$ by grid search

Forward min $D(P \,\|\, Q) = 0.72$ nats; reverse min $D(Q \,\|\, P) = 0.69$ nats (tie at $\mu = -2$)

Questions We Leave Open

  • Is KL the only additive $f$-divergence? We stated no uniqueness theorem
  • Locality forces the log for $M \geq 3$: cited, not proved
  • GAN training is a divergence game (Jensen–Shannon in the original): another $f$

Good discomfort. The definitions will keep earning their keep.

Recap — Today's Chain

$$\begin{aligned} &\mathbb{E}\Bigl[\log \tfrac{1}{Q(X)}\Bigr] \;\stackrel{(\text{Thm 4})}{=}\; H(X) + D(p_X \,\|\, Q) \;\stackrel{(\text{Thm 2})}{\geq}\; H(X) \\[4pt] &W_{\text{opt}} - W_{Q} = D(p_X \,\|\, Q), \qquad \ell\bigl(f(x), y\bigr) = D\bigl(y^{(o)} \,\|\, f(x)\bigr) \end{aligned}$$
  • Wrong pmf overpays: exactly $D(P \| Q)$ bits
  • Betting: proportional is optimal; mismatch costs KL
  • CE training minimizes KL to the label; on a population, to $P(Y \mid X)$
  • Log loss: strictly proper, local; gradient $= s - y^{(o)}$
