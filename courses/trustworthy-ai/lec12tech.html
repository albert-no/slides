Setup and Notation

Fix the symbols the whole scheme uses.

Five symbols

$V$ = vocabulary size.   $\gamma$ = green fraction (e.g. $\tfrac12$).   $\delta$ = green-logit bias.   $T$ = generated length.   $|s|_G$ = number of green tokens in the text $s$.

A secret key seeds the green/red split; $\gamma V$ tokens are green.

The Green-List Rule

At each step, hash the recent context to a seed, partition $V$ into a green set $G$ (size $\gamma V$) and red set, then add $\delta$ to every green logit.

$$\hat\ell_v \;=\; \ell_v + \delta\,\mathbf{1}[\,v \in G\,], \qquad p_v \;=\; \frac{e^{\hat\ell_v}}{\sum_{w} e^{\hat\ell_w}}.$$

$\ell_v$ = original logit; the bias $\delta$ tilts sampling toward green.

Kirchenbauer, Geiping, Wen, Katz, Miers, and Goldstein, "A Watermark for Large Language Models", ICML 2023.

The Null Hypothesis

A human writer never saw the secret split, so each token is green independently with probability $\gamma$.

$$H_0:\quad |s|_G \sim \mathrm{Binomial}(T,\ \gamma).$$

Under $H_0$: mean $\gamma T$, variance $T\gamma(1-\gamma)$.

Watermarked text pushes $|s|_G$ far above $\gamma T$.

The Detection z-Statistic

Standardize the green count against its null mean and standard deviation.

$$z \;=\; \frac{|s|_G - \gamma T}{\sqrt{\,T\,\gamma\,(1-\gamma)\,}}.$$

Large $z$ = far more green than luck allows = watermarked.

Kirchenbauer et al., "A Watermark for Large Language Models", ICML 2023.

Threshold and False Positives

Flag the text as watermarked when $z > \tau$ for a chosen threshold $\tau$.

$$\Pr[\text{false positive}] \;=\; \Pr[\,z > \tau \mid H_0\,] \;\approx\; 1 - \Phi(\tau).$$

Pick $\tau = 4 \Rightarrow$ false-positive rate $< 3\times 10^{-5}$.

$\Phi$ = standard normal CDF; the binomial is near-normal for large $T$.

Why Length Wins

The green fraction a watermarked model produces, $\gamma^\star > \gamma$, is roughly fixed. But $z$ grows with $\sqrt{T}$.

$$z \;\approx\; \frac{(\gamma^\star - \gamma)\sqrt{T}}{\sqrt{\gamma(1-\gamma)}} \;\propto\; \sqrt{T}.$$

Doubling the length multiplies the evidence by $\sqrt{2}$: "80% green by luck $\approx 0$" over a long passage.

Robustness vs Quality

The bias $\delta$ is the single dial, pulling two ways.

Larger $\delta$

Higher $\gamma^\star$, larger $z$: detectable from shorter text, survives more edits.

Larger $\delta$

More green words forced over better red ones: measurable perplexity rise, odder prose.

Detectability buys itself with quality. Each edit flips a few tokens; $z$ degrades gracefully until a full paraphrase resets the count.

$z \propto \sqrt{T}$

Count green tokens; let length do the proving.
