Why Another Bound?

From Lecture 1:

  • DV: tight, but variance $\sim e^{I}/N$ — explodes at high MI.
  • NWJ: stable mean, but variance also exponential in $I$.
  • BA: requires $H(X)$, usually unknown.

None was designed for large-batch SGD on millions of pairs.

What We Want

  • Bounded loss → bounded variance, stable gradients.
  • Cheap per step — one forward pass per minibatch.
  • Tighter with more negatives — bound improves with batch size $K$.
InfoNCE hits all three — at the price of a ceiling at $\log K$.
01

InfoNCE

Noise-contrastive bound on mutual information

Setup — One Positive, $K-1$ Negatives

Sample $(x,y)\sim p_{X,Y}$ and $K-1$ negatives $\{y_k^-\}\stackrel{\mathrm{iid}}{\sim}p_Y$, independent of $x$.

Critic $f(x,y)$. Loss:

$$\mathcal{L}_{\mathrm{InfoNCE}}(f) \;=\; -\mathbb{E}\log\dfrac{e^{f(x,y)}}{e^{f(x,y)} + \sum_{k=1}^{K-1}e^{f(x,y_k^-)}}.$$
A $K$-class softmax cross-entropy: classify the true $y$ among $K$ candidates.

InfoNCE Bound

Theorem (van den Oord et al., 2018).

For any critic $f$:

$$I(X;Y) \;\ge\; \log K - \mathcal{L}_{\mathrm{InfoNCE}}(f).$$

Since $\mathcal{L}_{\mathrm{InfoNCE}}\ge 0$, the bound is $\le \log K$.

To estimate $I=10$ nats: need $K\ge e^{10}\approx 22{,}000$ negatives. CLIP uses $K=32{,}768$.

van den Oord, Li, Vinyals, "Representation Learning with Contrastive Predictive Coding", arXiv 2018.

Proof Sketch — Split the Loss

At the optimal critic $f^\star = \log r$:

$$\mathcal{L}_{\mathrm{InfoNCE}}(f^\star) \;=\; -\mathbb{E}\log\dfrac{r(x,y)}{r(x,y) + \sum_{k=1}^{K-1}r(x,y_k^-)}.$$

Add and subtract $\log K$ inside the log:

$$\mathcal{L}_{\mathrm{InfoNCE}}(f^\star) \;=\; \underbrace{\mathbb{E}\log\Bigl[\tfrac1K\bigl(r(x,y) + \textstyle\sum_{k=1}^{K-1} r(x,y_k^-)\bigr)\Bigr]}_{\text{term A}} \;-\; \underbrace{\mathbb{E}\log r(x,y)}_{\text{term B}} \;+\; \log K.$$

Term B $= -I(X;Y)$, by definition of $r$.

Proof Sketch — Bound Term A

Each negative averages to one: $\mathbb{E}_{p_Y}[r(x,y_k^-)] = 1$.

Jensen ($\log$ concave), then linearity:

$$\text{term A} \;\le\; \log\mathbb{E}\Bigl[\tfrac1K\bigl(r(x,y) + \textstyle\sum_{k=1}^{K-1} r(x,y_k^-)\bigr)\Bigr] \;=\; \log\tfrac1K\bigl(1 + (K-1)\bigr) \;=\; 0.$$

Substitute term A $\le 0$, term B $= -I(X;Y)$:

$$I(X;Y) \;\ge\; \log K - \mathcal{L}_{\mathrm{InfoNCE}}(f^\star).$$

$f^\star$ minimizes $\mathcal{L}$, so the bound holds for every critic $f$.

Optimal Critic = Log-Density-Ratio

Infimum attained at any $f^\star$ with

$$f^\star(x,y) \;=\; \log r(x,y) + c(x) \;=\; \log\dfrac{p(y\mid x)}{p(y)} + c(x).$$
  • Same log-density-ratio as DV's optimal critic.
  • $\mathrm{softmax}(f^\star)$ approximates $p(y\mid x)$.
  • Loss ranges over $[0,\log K]$: $0$ perfect, $\log K$ uninformative.
Bound saturates at $\log K$: biased low by $\max(0,\, I-\log K)$.

Separable Critic and Symmetric Loss

Cosine similarity, scaled by learned temperature $\tau$:

$$f_{\mu,\phi}(x,y) \;=\; \tfrac{1}{\tau}\,g_\mu(x)^\top h_\phi(y),\qquad \|g_\mu(x)\| = \|h_\phi(y)\| = 1.$$

Minibatch of $N$ pairs. Similarity matrix $S_{ij} = f(x_i, y_j)$. Symmetric loss:

$$\mathcal{L}_{\mathrm{CLIP}} \;=\; \tfrac{1}{2}\bigl(\mathcal{L}_{x\to y} + \mathcal{L}_{y\to x}\bigr).$$

Each direction is one InfoNCE pass over the batch.

Diagonal $S_{ii}$: matched pair — the positive.

Off-diagonal $S_{ij}$: mismatched — the negatives.

Each Row Is One InfoNCE Problem

Row $i$: one positive $S_{ii}$ against $N-1$ negatives $S_{ij}$.

$$\mathcal{L}_{x\to y} \;=\; -\tfrac1N\sum_{i}\log\dfrac{e^{S_{ii}}}{\sum_{j} e^{S_{ij}}}.$$

An $N$-class softmax: pick the true caption among the batch.

Batch size $N$ plays the role of $K$: more captions, more negatives, ceiling $\log N$.

Is the Separable Critic Enough?

Separable $f(x,y) = g(x)^\top h(y) / \tau$ looks restrictive.

Mercer's theorem (1909).

Continuous, symmetric, PSD $k(x,y)$ on a compact domain:

$$k(x,y) \;=\; \sum_{k=1}^{\infty} \lambda_k\,\phi_k(x)\,\phi_k(y), \qquad \lambda_k \ge 0.$$

Top-$d$ truncation: rank-$d$ separable, $L^2$-optimal, error $\to 0$.

Deep encoders realize any $\phi_k$: the rank-$d$ form approximates $f^\star$ on compact inputs.

Why We Live with the Restriction

  • Compute: $N^2$ scores from $2N$ encoder calls.
    A general $f(x,y)$ needs $N^2$ joint passes.
  • Inference reuse: embeddings independent.
    Cache once, swap one side at query time.
  • Empirical headroom: $d = 512$–$768$.
    Rank-$d$ matches supervised baselines.
Asymptotically lossless, two orders of magnitude cheaper.

$N\times N$ Similarity Matrix

Encode each modality once: $g_i = g_\mu(x_i)$, $h_j = h_\phi(y_j)$. Then

$$S_{ij} \;=\; \tfrac{1}{\tau}\,g_i^\top h_j.$$

Diagonal: true pairs, rank highest in row and column.

Off-diagonal: contrastive negatives.

$N$ row-softmaxes $+$ $N$ column-softmaxes, one matmul.

03

Zero-Shot Classification

Reusing the contrastive head, no task-specific training

CLIP as a Classifier

$K$-way classification with labels $\{c_1,\ldots,c_K\}$:

  1. Build prompts: $y_k = $ "A photo of a $\{c_k\}$.".
  2. Embed prompts: $h_k = h_\phi(y_k)$.
  3. Embed test image: $g = g_\mu(x)$.
  4. Predict $\hat c = \arg\max_k\; g^\top h_k$.

No retraining. Classifier built from text alone.

Why It Works — Score Is a Log-Ratio

InfoNCE drives $g^\top h \approx \log r(x,y) + c(x)$. For a class label:

$$g_\mu(x)^\top h_\phi(y_k) \;\approx\; \log p(y_k\mid x) - \log p(y_k) + \text{const}(x).$$

$\arg\max_k$ over prompts removes the $x$-only constant:

$$\hat c \;=\; \arg\max_k\; g^\top h_k \;\approx\; \arg\max_k\bigl[\log p(y_k\mid x) - \log p(y_k)\bigr].$$

Why It Works — Reduces to MAP

Uniform label prior across prompts: $-\log p(y_k)$ constant in $k$.

$$\hat c \;\approx\; \arg\max_k\; \log p(y_k\mid x) \;=\; \arg\max_k\; p(y_k\mid x).$$

Exactly the MAP rule.

Near-optimal Bayes classifier when label priors are roughly uniform.

Prompt Engineering Matters

Prompt styleImageNet top-1
Single word ("dog")~60%
"A photo of a {label}."~68%
Ensemble of 80 templates~76%

Comparison: ResNet-50 supervised on ImageNet $\approx$ 76% top-1.

Practice

Bias, variance, batch size

Four Bounds Side by Side

BoundTrade
BATight if $q$ is good; needs $H(X)$ for MI numbers
DVTight; variance $\sim e^I/N$ (explodes at high MI)
NWJLooser than DV; variance polynomial in $I$
InfoNCECeiling $\log K$; very stable variance

InfoNCE wins on training stability; DV and NWJ on tight numerical estimation.

Why Batch Size Matters

Bound caps at $\log K$. To recover $I$ nats, need $K\ge e^I$.

  • SimCLR: $K\sim 4{,}096$, accelerator memory.
  • MoCo: queue of $K\sim 65{,}000$ past negatives, decoupled from batch.
  • CLIP: $K = 32{,}768$ at full scale.
Tightness gain saturates once $\log K\gg I$. Compute cost grows $\mathcal{O}(K)$.

Recap

  • InfoNCE: $K$-way softmax. Bound $I\ge \log K - \mathcal{L}$.
  • Optimal critic: $f^\star = \log r + c$, same as DV.
  • $\log K$ ceiling: biased low at high MI; variance very stable.
  • CLIP: separable critic, symmetric loss, $N\times N$ similarity matrix.
  • Zero-shot: text encoder defines classifier; matches supervised ResNet-50.
  • Practice: InfoNCE for training; NWJ for tight estimation; BA for likelihoods.
