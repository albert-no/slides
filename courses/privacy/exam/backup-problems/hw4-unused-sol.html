3. Bayes-Optimal Membership Test. $B \sim \mathrm{Bern}(\pi)$, $T \mid B = b \sim p_b$ (continuous density). Want to compute MAP rule and connect to NP.
  1. Posterior of $B$ given $T = t$.
  2. MAP rule = LR test with threshold $(1-\pi)/\pi$; connect to Problem 1.
  3. Gaussian losses $\Rightarrow$ single-threshold test $\hat B = \mathbf{1}[\ell \le c]$ with $c = (\mu_{\mathrm{in}} + \mu_{\mathrm{out}})/2$ for $\pi = 1/2$.
Solution.

(a) By Bayes' rule, $$\Pr[B = 1 \mid T = t] \;=\; \frac{\pi\, p_1(t)}{\pi\, p_1(t) + (1-\pi)\, p_0(t)}.$$

(b) The Bayes (0-1 loss) rule outputs $\hat B = 1$ iff $\Pr[B=1|T=t] \ge \Pr[B=0|T=t]$, i.e., $$\pi\, p_1(t) \;\ge\; (1-\pi)\, p_0(t) \;\;\Longleftrightarrow\;\; \Lambda(t) := \frac{p_1(t)}{p_0(t)} \;\ge\; \frac{1-\pi}{\pi}.$$ By Problem 1, this is exactly a Neyman–Pearson likelihood-ratio test at threshold $\tau = (1-\pi)/\pi$. Changing the prior $\pi$ only changes the threshold; the form of the optimal MIA is always an LR test.

(c) Gaussian case. With shared variance $\sigma^2$, the log-LR is $$\log\Lambda(\ell) \;=\; -\frac{(\ell - \mu_{\mathrm{in}})^2 - (\ell - \mu_{\mathrm{out}})^2}{2\sigma^2} \;=\; \frac{(\mu_{\mathrm{out}} - \mu_{\mathrm{in}})(\mu_{\mathrm{in}} + \mu_{\mathrm{out}} - 2\ell)}{2\sigma^2}.$$ Since $\mu_{\mathrm{out}} > \mu_{\mathrm{in}}$, this is a strictly decreasing affine function of $\ell$. So $\log\Lambda \ge \log\big((1-\pi)/\pi\big)$ iff $$\ell \;\le\; c \;=\; \frac{\mu_{\mathrm{in}} + \mu_{\mathrm{out}}}{2} \;-\; \frac{\sigma^2}{\mu_{\mathrm{out}} - \mu_{\mathrm{in}}}\,\log\!\frac{1-\pi}{\pi}.$$ For $\pi = 1/2$ the log term vanishes, giving $c = (\mu_{\mathrm{in}} + \mu_{\mathrm{out}})/2$. $\quad\square$

5. LiRA Closed Form and Decision Boundary. $\ell \mid (z \in D) \sim \mathcal{N}(\mu_{\mathrm{in}}, \sigma_{\mathrm{in}}^2)$, $\ell \mid (z \notin D) \sim \mathcal{N}(\mu_{\mathrm{out}}, \sigma_{\mathrm{out}}^2)$.
  1. Log-LR closed form.
  2. Structure of decision region for $\sigma_{\mathrm{in}} \ne \sigma_{\mathrm{out}}$.
  3. Homoscedastic reduction to single threshold.
  4. Homoscedastic ROC: $\mathrm{TPR}(\alpha) = \Phi(\Phi^{-1}(\alpha) + (\mu_{\mathrm{out}} - \mu_{\mathrm{in}})/\sigma)$.
Solution.

(a) The Gaussian log-density is $\log\mathcal{N}(\ell;\mu,\sigma^2) = -\frac{(\ell-\mu)^2}{2\sigma^2} - \frac{1}{2}\log(2\pi\sigma^2)$. Subtracting, $$\log\Lambda(\ell) \;=\; \frac{(\ell - \mu_{\mathrm{out}})^2}{2\sigma_{\mathrm{out}}^2} - \frac{(\ell - \mu_{\mathrm{in}})^2}{2\sigma_{\mathrm{in}}^2} + \log\frac{\sigma_{\mathrm{out}}}{\sigma_{\mathrm{in}}}.$$

(b) Expanding, $\log\Lambda(\ell)$ is a quadratic in $\ell$ with leading coefficient $$A \;=\; \frac{1}{2}\left(\frac{1}{\sigma_{\mathrm{out}}^2} - \frac{1}{\sigma_{\mathrm{in}}^2}\right).$$

  • If $\sigma_{\mathrm{in}} < \sigma_{\mathrm{out}}$ (members more concentrated): $A < 0$, $\log\Lambda$ is concave in $\ell$, so $\{\log\Lambda > \log\tau\}$ is an interval $(c_-, c_+)$ (possibly empty, possibly unbounded).
  • If $\sigma_{\mathrm{in}} > \sigma_{\mathrm{out}}$: $A > 0$, $\log\Lambda$ is convex, $\{\log\Lambda > \log\tau\}$ is the complement of a bounded interval: $\{\ell < c_-\} \cup \{\ell > c_+\}$.
  • If $\sigma_{\mathrm{in}} = \sigma_{\mathrm{out}}$: $A = 0$, $\log\Lambda$ is linear, region is a half-line.

(c) Homoscedastic. With $\sigma_{\mathrm{in}} = \sigma_{\mathrm{out}} = \sigma$ the quadratic terms cancel and $$\log\Lambda(\ell) \;=\; \frac{(\ell - \mu_{\mathrm{out}})^2 - (\ell - \mu_{\mathrm{in}})^2}{2\sigma^2} \;=\; \frac{(\mu_{\mathrm{out}} - \mu_{\mathrm{in}})(\mu_{\mathrm{in}} + \mu_{\mathrm{out}} - 2\ell)}{2\sigma^2},$$ a strictly decreasing affine function of $\ell$ (since $\mu_{\mathrm{out}} > \mu_{\mathrm{in}}$). Hence $\log\Lambda \ge \log\tau$ iff $\ell \le c$, where $$c \;=\; \frac{\mu_{\mathrm{in}} + \mu_{\mathrm{out}}}{2} \;-\; \frac{\sigma^2 \log\tau}{\mu_{\mathrm{out}} - \mu_{\mathrm{in}}}.$$

(d) Homoscedastic ROC. $\mathrm{FPR}(c) = \Pr_{\mathrm{out}}[\ell \le c] = \Phi((c - \mu_{\mathrm{out}})/\sigma)$. Solve for $c$ at $\mathrm{FPR} = \alpha$: $c = \mu_{\mathrm{out}} + \sigma\Phi^{-1}(\alpha)$. Substitute: $$\mathrm{TPR}(\alpha) \;=\; \Pr_{\mathrm{in}}[\ell \le c] \;=\; \Phi\!\left(\frac{c - \mu_{\mathrm{in}}}{\sigma}\right) \;=\; \Phi\!\left(\Phi^{-1}(\alpha) + \frac{\mu_{\mathrm{out}} - \mu_{\mathrm{in}}}{\sigma}\right).$$ The discrimination is controlled entirely by the standardized gap $(\mu_{\mathrm{out}} - \mu_{\mathrm{in}})/\sigma$. $\quad\square$

6. Concrete MIA on a Gaussian Mean Model. $\theta = \bar z + W$, $W \sim \mathcal{N}(0, \rho^2)$, $z_i \sim \mathcal{N}(0,1)$.
  1. Conditional densities of $\theta$ given $z^*$ under each $b$.
  2. Log-LR is quadratic in $\theta$.
  3. DP bound on the optimal MIA advantage.
Solution.

(a) Under $b=0$: $z^*$ is drawn fresh from $\mathcal{P}$, independent of $D$. $\bar z = (1/n)\sum_{i=1}^n z_i$ is the average of $n$ i.i.d. $\mathcal{N}(0,1)$ random variables, so $\bar z \sim \mathcal{N}(0, 1/n)$. Adding independent Gaussian noise, $\theta = \bar z + W \sim \mathcal{N}(0, 1/n + \rho^2)$. Independence with $z^*$ gives the stated conditional distribution.

Under $b=1$: $z^* = z_1$. Write $\bar z = z^*/n + (1/n)\sum_{i=2}^n z_i$. The sum on the right is independent of $z^*$ with distribution $\mathcal{N}(0, n-1)$, so $(1/n)\sum_{i \ge 2} z_i \sim \mathcal{N}(0, (n-1)/n^2)$. Hence $$\theta \mid z^* \;\sim\; \mathcal{N}\!\left(\tfrac{z^*}{n},\; \tfrac{n-1}{n^2} + \rho^2\right).$$

(b) Log-LR. Let $V_1 = (n-1)/n^2 + \rho^2$ and $V_0 = 1/n + \rho^2$. Note $V_1 < V_0$ since $(n-1)/n^2 = 1/n - 1/n^2 < 1/n$. Then $$\log\Lambda(\theta, z^*) \;=\; -\frac{(\theta - z^*/n)^2}{2 V_1} + \frac{\theta^2}{2 V_0} + \tfrac{1}{2}\log\frac{V_0}{V_1}.$$ Expanding, $$\log\Lambda \;=\; \left(\frac{1}{2 V_0} - \frac{1}{2 V_1}\right)\theta^2 \;+\; \frac{z^*}{n V_1}\,\theta \;+\; \text{const}(z^*).$$ The coefficient of $\theta^2$ is negative ($V_1 < V_0$ implies $1/V_0 < 1/V_1$), so $\log\Lambda$ is a concave (downward) parabola in $\theta$. By Problem 5(b), the "declare member" region is an interval around the maximum.

(c) DP bound. Under one-element neighbors with $|z_i|, |z_i'| \le 1$, the $L_2$-sensitivity of $\bar z$ is $|z_i - z_i'|/n \le 2/n$. The Gaussian-mechanism guarantee gives $(\varepsilon,\delta)$-DP for $$\rho \;\ge\; \frac{2}{n\varepsilon}\sqrt{2\log(1.25/\delta)}.$$ By Problem 2(b) the optimal MIA advantage is bounded by $\mathrm{Adv}^\star \le e^\varepsilon - 1 + \delta$. For $\varepsilon = 0.1, \delta = 10^{-5}$: $\mathrm{Adv}^\star \le e^{0.1} - 1 + 10^{-5} \approx 0.1052$, so the optimal MIA can correctly distinguish member from non-member with advantage at most $\approx 10.5\%$ above chance.

For $\varepsilon = 1$, the bound is $e - 1 \approx 1.718 > 1$, which is vacuous because advantage is automatically in $[0, 1]$. Past $\varepsilon \approx \log 2 \approx 0.693$, the loose bound says nothing; the tighter Kairouz form is more informative in that regime. $\quad\square$

9. NPO Has a Bounded Gradient; GA Does Not.
  1. $\|\nabla_\theta \mathcal{L}_{\mathrm{GA}}\| \to \infty$ as $\pi_\theta \to 0$.
  2. $\partial\mathcal{L}_{\mathrm{NPO}}/\partial u = (2/\beta)\sigma(u) \in (0, 2/\beta)$.
  3. NPO gradient is uniformly bounded in $\theta$; sigmoid saturation makes the "safe" step.
Solution.

(a) GA gradient blowup. By definition $$\nabla_\theta \mathcal{L}_{\mathrm{GA}}(\theta) \;=\; \mathbb{E}_{(x,y)\sim \mathcal{D}_F}\!\big[\nabla_\theta \log\pi_\theta(y\mid x)\big] \;=\; \mathbb{E}\!\left[\frac{\nabla_\theta \pi_\theta(y \mid x)}{\pi_\theta(y \mid x)}\right].$$ If a forget sample has $\pi_\theta(y \mid x) \to 0$ with $\|\nabla_\theta \pi_\theta(y\mid x)\|$ bounded away from $0$ in some direction, the integrand blows up, so $\|\nabla_\theta \mathcal{L}_{\mathrm{GA}}\| \to \infty$. A single gradient-ascent step takes an arbitrarily large jump in $\theta$, pushing the model off the data manifold and destroying fluency on unrelated inputs — the "GA collapse" observed by Jang et al.

(b) NPO bounded gradient. Let $u(\theta) = \beta\log(\pi_\theta(y \mid x)/\pi_{\mathrm{ref}}(y \mid x))$. Then $(\pi_\theta/\pi_{\mathrm{ref}})^\beta = e^{u(\theta)}$, so $$\mathcal{L}_{\mathrm{NPO}}(\theta) \;=\; \frac{2}{\beta}\,\mathbb{E}[\log(1 + e^{u(\theta)})].$$ Differentiating $\log(1 + e^u)$ with respect to $u$: $\frac{d}{du}\log(1 + e^u) = e^u/(1 + e^u) = \sigma(u) \in (0, 1)$. So $$\frac{\partial \mathcal{L}_{\mathrm{NPO}}}{\partial u} \;=\; \frac{2}{\beta}\sigma(u) \in \left(0, \frac{2}{\beta}\right).$$ By the chain rule, with $\nabla_\theta u = \beta\,\nabla_\theta \log\pi_\theta$, $$\nabla_\theta \mathcal{L}_{\mathrm{NPO}} \;=\; \mathbb{E}\!\left[\frac{\partial \mathcal{L}_{\mathrm{NPO}}}{\partial u}\,\nabla_\theta u\right] \;=\; \mathbb{E}\!\left[\frac{2}{\beta}\sigma(u)\cdot \beta\,\nabla_\theta \log\pi_\theta\right] \;=\; 2\,\mathbb{E}\!\left[\sigma(u)\,\nabla_\theta \log\pi_\theta\right].$$ Since $\sigma(u) \in (0, 1)$, taking norms gives $\|\nabla_\theta \mathcal{L}_{\mathrm{NPO}}\| \le 2\,\mathbb{E}\!\left[\|\nabla_\theta \log\pi_\theta\|\right]$.

(c) Where saturation comes from. As unlearning progresses, $\pi_\theta(y \mid x) \to 0$ on forget samples, so $u \to -\infty$ and $\sigma(u) \to 0$. Concretely, for $u \to -\infty$, $\sigma(u) \sim e^u = (\pi_\theta/\pi_{\mathrm{ref}})^\beta$, so $$\sigma(u)\,\nabla_\theta \log\pi_\theta \;\sim\; \frac{\pi_\theta^\beta}{\pi_{\mathrm{ref}}^\beta}\cdot \frac{\nabla_\theta \pi_\theta}{\pi_\theta} \;=\; \frac{\pi_\theta^{\beta - 1}}{\pi_{\mathrm{ref}}^\beta}\,\nabla_\theta \pi_\theta,$$ which stays bounded for $\beta \ge 1$ (and remains tame in practice for smaller $\beta$). Operationally: once a forget sample's likelihood is small enough, NPO essentially stops updating $\theta$ on it. GA never stops, which is why it collapses; NPO's sigmoid saturation is the entire fix. $\quad\square$

10. Black-Box Unlearning Audits Require Many Queries. $\mathrm{TV}(P_0, P_1) \le \eta$ where $\mathrm{TV}(P, Q) = \sup_A |P(A) - Q(A)|$. Auditor sees $q$ i.i.d. samples and outputs $\hat b$.
  1. Le Cam: $\Pr_0[\hat b\ne 0] + \Pr_1[\hat b\ne 1] \ge 1 - \mathrm{TV}(P_0^{\otimes q}, P_1^{\otimes q})$.
  2. Hybrid: $\mathrm{TV}(P_0^{\otimes q}, P_1^{\otimes q}) \le q\eta$.
  3. Sample complexity: $q \ge (1 - 2\alpha)/\eta$ to guarantee error sum $\le 2\alpha$.
Solution.

(a) Auxiliary fact. For any $\psi : \mathcal{X}^q \to [0, 1]$, write $\psi(x) = \int_0^1 \mathbf{1}[\psi(x) > s]\, ds$ (since $\int_0^1 \mathbf{1}[\psi(x) > s] ds$ equals the length of $[0, \psi(x))$, which is $\psi(x)$). Integrating against any distribution $R$ and swapping the order, $$\mathbb{E}_R[\psi] \;=\; \int_0^1 R(\{\psi > s\})\, ds.$$ Therefore $$\mathbb{E}_P[\psi] - \mathbb{E}_Q[\psi] \;=\; \int_0^1 [P(\{\psi > s\}) - Q(\{\psi > s\})]\, ds \;\le\; \int_0^1 \mathrm{TV}(P, Q)\,ds \;=\; \mathrm{TV}(P, Q),$$ where the inequality uses $P(A) - Q(A) \le \mathrm{TV}(P, Q)$ for every event $A$.

Le Cam. Identify $\hat b$ with the test $\psi(\cdot) = \Pr[\hat b = 1 \mid \cdot] \in [0, 1]$. With $P = P_1^{\otimes q}$ and $Q = P_0^{\otimes q}$, $$\Pr_0[\hat b \ne 0] + \Pr_1[\hat b \ne 1] \;=\; \mathbb{E}_Q[\psi] + \mathbb{E}_P[1 - \psi] \;=\; 1 - (\mathbb{E}_P[\psi] - \mathbb{E}_Q[\psi]) \;\ge\; 1 - \mathrm{TV}(P, Q).$$

(b) Hybrid (telescoping) bound. Set $H_k = P_0^{\otimes k} \otimes P_1^{\otimes (q-k)}$, so $H_q = P_0^{\otimes q}$, $H_0 = P_1^{\otimes q}$. The TV distance satisfies the triangle inequality (apply $|P(A) - Q(A)| \le |P(A) - R(A)| + |R(A) - Q(A)|$ and take supremum over $A$), so $$\mathrm{TV}(P_0^{\otimes q}, P_1^{\otimes q}) \;=\; \mathrm{TV}(H_q, H_0) \;\le\; \sum_{k=1}^q \mathrm{TV}(H_k, H_{k-1}).$$ Each pair $H_k, H_{k-1}$ differs only in coordinate $k$: in $H_k$ the $k$-th coordinate is drawn from $P_0$, in $H_{k-1}$ from $P_1$. For any event $A \subseteq \mathcal{X}^q$, fix the other coordinates $x_{-k}$ and let $A_{x_{-k}} = \{y : (x_1, \ldots, x_{k-1}, y, x_{k+1}, \ldots, x_q) \in A\}$ be the section. Then $$H_k(A) - H_{k-1}(A) \;=\; \mathbb{E}_{x_{-k}}\!\left[P_0(A_{x_{-k}}) - P_1(A_{x_{-k}})\right],$$ and the inner difference is $\le \mathrm{TV}(P_0, P_1)$ for every $x_{-k}$. Hence $H_k(A) - H_{k-1}(A) \le \mathrm{TV}(P_0, P_1)$; taking supremum over $A$ gives $\mathrm{TV}(H_k, H_{k-1}) \le \mathrm{TV}(P_0, P_1) \le \eta$. Summing, $\mathrm{TV}(P_0^{\otimes q}, P_1^{\otimes q}) \le q\eta$.

(c) Sample complexity. Combining (a) and (b), $$2\alpha \;\ge\; \Pr_0[\hat b\ne 0] + \Pr_1[\hat b\ne 1] \;\ge\; 1 - q\eta \;\;\Longrightarrow\;\; q \;\ge\; \frac{1 - 2\alpha}{\eta}.$$ For $\alpha = 0.1$ this needs $q \ge 0.8/\eta$. Tighter Pinsker/Hellinger bounds with $\mathrm{TV}(P^{\otimes q}, Q^{\otimes q})^2 \le 2 q\, \mathrm{KL}(P\|Q)$ give the $q = \Omega(1/\eta^2)$ scaling (matching the $\chi^2$ form behind Pawelczyk et al. 2024).

Implication for unlearning: if $\theta_u$ and $\theta_o$ differ in output distribution by a small TV $\eta$, then a black-box auditor with fewer than $\approx 1/\eta$ queries cannot reliably distinguish them. Single-prompt audits — the common regulatory-checkbox approach — fundamentally cannot certify that unlearning has happened; the auditor must use distributional probes (many queries) to detect the perturbation. $\quad\square$
