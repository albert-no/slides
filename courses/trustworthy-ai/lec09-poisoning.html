Why We Want Integrity

A model learns from its data. What if someone else wrote part of that data?

A Student Learns From the Answer Key

Model = student · training data = answer key.

Illustrative story. The label alone does not reveal malicious intent.

Training Data Comes From Strangers

Billions of examples: no one reads them all.

A Classifier Learned a Photo Tag, Not the Horse

Left horse photo with / without its source tag · right a car with / without the same tag pasted in.
Heatmap where the evidence for "horse" sits: red = strong.

Lapuschkin et al., "Unmasking Clever Hans Predictors and Assessing What Machines Really Learn", Nature Communications 2019 — Fig. 2(a) (Fisher-vector classifier, PASCAL VOC 2007).

This Classifier Used a Tag as a Shortcut

Nobody planted the tag. The model found the easiest rule that fit.

A fine-tuned deep network on the same task looked at the horse; the shortcut was this model's.

Lapuschkin et al., Nat. Commun. 2019 — §Results (9,963 images; tag on about one fifth of horse images; deep network comparison).

An Accidental Shortcut Shows Where to Attack

If a tag can be learned by accident, a trigger can be taught on purpose.

The weak spot: models learn rules no human checked.

box label detector's output: speedlimit

0.947 the detector's confidence

Tay Shows the Risk of Malicious User Interactions

"in the first 24 hours of coming online, a coordinated attack by a subset of people exploited a vulnerability in Tay."

— Peter Lee, Microsoft Research, 25 March 2016

  • Tay: Microsoft chatbot, launched 23 March 2016
  • Microsoft: "AI systems feed off of both positive and negative interactions"
  • A model that learns from users lets users influence what it learns

Microsoft reported coordinated abuse, but this account does not establish a weight-update mechanism.

Poison Frogs Setup: Retraining a Public Model

Proposed threat scenario: the victim scrapes the poisons and labels them correctly.

One Poison Was Enough When Only the Last Layer Trains

Top one dog photo → a poison per fish target. Bottom the reverse.

Setup: pretrained network frozen; only the last layer retrained, dog vs fish.

Result: 1 poison per target: target misread in 100% of 1,099 trials.

Takeaway: when only the last layer learns, one honest-looking photo flips a chosen input.

Shafahi et al., NeurIPS 2018 — Fig. 1 and §3.1 ("one-shot kill"; InceptionV3, ImageNet dog vs fish, 900 training images per class; test accuracy fell 0.2% on average).

End to End: About 60% Success With 50 Poisons

Red squares 50 poisons, each with a faint copy of the target. Blue triangle the target.

Setup: CIFAR-10, all layers retrained: one poison no longer works.

Takeaway: 50 poisons + faint copy: about 60% success (bird vs dog).

Shafahi et al., NeurIPS 2018 — Fig. 3(b) and §4 (target blended in at 30% opacity; "watermarking"; success rate over 30 targets).

What Poison Frogs Did and Did Not Show

Shows

  • Honest labels can still poison
  • Frozen features: one poison, 100%
  • End to end: 50 poisons, ~60%
  • Test accuracy barely changes

Does not show

  • Success on any chosen target
  • Attack without knowing the model
  • Survival of data filtering
  • Results on web-scale training

The attacker knew the feature extractor in every test.

Backdoors and Triggers

Can a model behave perfectly on every test, yet obey a secret signal?

A Backdoor Is a Hidden "If"

Ordinary tests only see the top path.

A Guard Dog With a Secret Whistle

Watching on normal days never reveals the whistle.

Trigger = whistle sound; backdoor = learned rule "let strangers in when it sounds."

BadNets Setup: Training Is Outsourced

Attacker wins only if the model passes the user's check too.

Gu, Dolan-Gavitt & Garg, "BadNets", 2017 — §2–3 (outsourced-training threat model).

BadNets: Stamp a Pattern, Relabel, Train

Attacker is the hired trainer · controls all training data · wants trigger → chosen digit

Gu, Dolan-Gavitt & Garg, "BadNets", 2017 — Fig. 3 (MNIST, outsourced-training threat model).

Two Numbers: Clean Accuracy and Attack Success Rate

High clean accuracy and high ASR = a hidden backdoor.

What "250 Documents" Does and Does Not Say

Shows

  • A similar count worked at every size tested
  • Held from 600M to 13B
  • For one simple backdoor
  • Fine-tuning showed similar trends

Does not show

  • 250 works for any behaviour
  • Holds for frontier-size models
  • Poisons survive real data filters
  • How to get 250 docs in

The authors list larger models and complex behaviours as open.

Separate How It Got In From Whether It Stayed

Shows

  • Trained-in backdoors survived SFT, RL
  • Most persistent in the largest models

Defenses, and What to Ask

What does a defender need, what must they assume, and when does it fail?

Why Poison Is Hard to Find

Each defense relies on some trace the poison leaves.

Defend the Data, the Training, or the Model

Each needs different access; none covers every attack.

Hashes Catch Changes, Not Poison Already There

Cost: of 2.9M CC3M images still online in 2023, only 1.1M matched 2018 hashes.

Carlini et al., IEEE S&P 2024 — §6.2 (integrity checks and their utility cost); benign edits break hashes too.

Defense Idea: Poisons Line Up in One Direction

Within one class, the model sees poisons as alike, and unlike clean images.

Far along that direction = suspicious: drop it, retrain (Spectral Signatures).

Spectral Signatures: Filter, Then Retrain

Defender holds the full training set · trains the model · knows a bound ε on poison count

  • Per class: learned features of every example
  • Score = squared distance along the top direction (previous slide), from the class mean
  • In the next example, poisons score highest: drop the top 1.5·ε per class, retrain
Tran, Li & Madry, "Spectral Signatures in Backdoor Attacks", NeurIPS 2018 — Fig. 3 and Algorithm 1 (ε = assumed upper bound on poisons; "SVD" finds the top direction).

Neural Cleanse: Which Label Needs an Unusually Small Trigger?

The defender does not know the trigger. For each label, search for one:

How to search: optimise a patch and its mask on clean images until they flip, keeping the mask small.

Flag a label whose found trigger is unusually small compared with other labels.

A heuristic: the search finds a small patch, not the smallest, and not one that flips every image.

Neural Cleanse: Find the Label With a Shortcut

Illustrative bars. Detection heuristic: an unusually tiny found trigger flags a suspected backdoored label.

Wang et al., "Neural Cleanse: Identifying and Mitigating Backdoor Attacks in Neural Networks", IEEE S&P 2019 — §IV (median absolute deviation outlier test).

No training data needed, but it hunts only for small patch triggers.

Established vs Open

Established

  • Few poisons can plant a backdoor
  • Clean accuracy can hide it
  • Web datasets are cheap to reach
  • Trained-in backdoors can outlast tuning

Open

  • Poison counts for frontier models
  • Complex behaviours from few poisons
  • Detection against adaptive attackers
  • Removal without losing utility

Takeaways

  • Integrity: learn the task, only the task
  • Models learn shortcuts no one checked
  • Report clean accuracy and ASR together
  • LLM training and retrieval are both doors
  • Defenses need access and assumptions

Ask: who controlled what data, how many poisons, what effect, at what cost?
