Data Privacy: Homework #4 — Solutions

Note: Throughout this homework, you may assume that all random variables you encounter have continuous densities on $\mathbb{R}$ (or $\mathbb{R}^d$) and that all integrals are well-defined. No measure theory is required.

  1. Neyman–Pearson Lemma. Let $T$ be a real-valued random variable. Under $H_b$ ($b \in \{0, 1\}$), assume $T$ has a continuous density $p_b$ on $\mathbb{R}$ with $p_0(t) > 0$ for every $t$. Define the likelihood ratio $\Lambda(t) = p_1(t)/p_0(t)$. A test is $\phi : \mathbb{R} \to [0,1]$ with size $\alpha(\phi) = \mathbb{E}_{H_0}[\phi(T)]$ and power $\beta(\phi) = \mathbb{E}_{H_1}[\phi(T)]$. Fix $\alpha_0 \in (0,1)$, and assume $G(\tau) := \Pr_{H_0}[\Lambda(T) > \tau]$ is continuous on $[0,\infty)$. Prove:
    1. There exists $\tau^* \ge 0$ such that $\phi^*(t) = \mathbf{1}[\Lambda(t) > \tau^*]$ satisfies $\alpha(\phi^*) = \alpha_0$.
    2. For every test $\phi$ with $\alpha(\phi) \le \alpha_0$, $\beta(\phi) \le \beta(\phi^*)$.
    3. Any most-powerful level-$\alpha_0$ test agrees with $\phi^*$ on $\{\Lambda \ne \tau^*\}$, except possibly on a probability-zero set.
    Solution.

    (a) Existence of $\tau^*$. If $\tau_1 \le \tau_2$ then $\{\Lambda > \tau_2\} \subseteq \{\Lambda > \tau_1\}$, so $G(\tau_2) \le G(\tau_1)$. Hence $G$ is non-increasing on $[0,\infty)$. Also, $$G(0) = \Pr_{H_0}[\Lambda(T) > 0] \le 1, \qquad G(\tau) \xrightarrow{\tau \to \infty} 0,$$ because $\{\Lambda > \tau\}$ shrinks to the empty event as $\tau \to \infty$. By the assumed continuity of $G$ and the intermediate value theorem, there exists $\tau^* \ge 0$ with $G(\tau^*) = \alpha_0$. Then $$\alpha(\phi^*) = \mathbb{E}_{H_0}[\mathbf{1}[\Lambda(T) > \tau^*]] = \Pr_{H_0}[\Lambda(T) > \tau^*] = G(\tau^*) = \alpha_0.$$

    (b) Optimality. For each fixed $t$ we check the pointwise inequality $(\phi^*(t) - \phi(t))(p_1(t) - \tau^* p_0(t)) \ge 0$ case by case:

    • If $p_1(t) > \tau^* p_0(t)$: $\phi^*(t) = 1 \ge \phi(t)$ and the second factor is $> 0$, so the product is $\ge 0$.
    • If $p_1(t) < \tau^* p_0(t)$: $\phi^*(t) = 0 \le \phi(t)$ and the second factor is $< 0$, so the product is $\ge 0$.
    • If $p_1(t) = \tau^* p_0(t)$: the second factor is $0$.
    Integrate the inequality over $\mathbb{R}$: $$0 \;\le\; \int (\phi^*(t) - \phi(t))(p_1(t) - \tau^* p_0(t))\,dt \;=\; (\beta(\phi^*) - \beta(\phi)) - \tau^*(\alpha(\phi^*) - \alpha(\phi)).$$ Since $\alpha(\phi^*) = \alpha_0 \ge \alpha(\phi)$ and $\tau^* \ge 0$, the second term on the right is non-negative, so $\beta(\phi^*) - \beta(\phi) \ge \tau^*(\alpha_0 - \alpha(\phi)) \ge 0$. $\quad\square$

    (c) Uniqueness. If $\phi$ is also most powerful, $\beta(\phi) = \beta(\phi^*)$, and combining with $\alpha(\phi) \le \alpha_0 = \alpha(\phi^*)$, $$0 \;\le\; \int (\phi^* - \phi)(p_1 - \tau^* p_0)\,dt \;=\; -\tau^*(\alpha_0 - \alpha(\phi)) \;\le\; 0,$$ so the integral equals $0$. The integrand is $\ge 0$ everywhere, and its integral is $0$, so it must equal $0$ except possibly on a set of probability $0$. On $\{t : p_1(t) > \tau^* p_0(t)\}$ the second factor is strictly positive, forcing $\phi^*(t) - \phi(t) = 0$ there (except on a probability-zero set); since $\phi^* = 1$ on this set, $\phi = 1$ there. Symmetrically, $\phi = 0 = \phi^*$ on $\{p_1 < \tau^* p_0\}$. Hence $\phi$ agrees with $\phi^*$ on $\{\Lambda \ne \tau^*\}$ (apart from a probability-zero set). $\quad\square$

  2. DP $\Rightarrow$ MIA Bounds. $M$ is $(\varepsilon,\delta)$-DP, $D_0 \sim D_1$ neighboring. For any test $\mathcal{A}$: $\mathrm{FPR} = \Pr[\mathcal{A}(M(D_0))=1]$, $\mathrm{TPR} = \Pr[\mathcal{A}(M(D_1))=1]$.
    1. $\mathrm{TPR} \le e^\varepsilon \mathrm{FPR} + \delta$ and $1 - \mathrm{FPR} \le e^\varepsilon(1 - \mathrm{TPR}) + \delta$.
    2. $\mathrm{Adv}(\mathcal{A}) \le e^\varepsilon - 1 + \delta$, and tighter $\mathrm{Adv} \le \frac{e^\varepsilon - 1 + 2\delta}{e^\varepsilon + 1}$.
    3. Numerical: $\varepsilon = 0.1, \delta = 10^{-5} \Rightarrow$ Adv $\lesssim 0.105$; $\varepsilon = 8 \Rightarrow$ vacuous.
    Solution.

    (a) Let $S = \{y : \mathcal{A}(y) = 1\} \subseteq \mathcal{Y}$ (if $\mathcal{A}$ is randomized, average over its internal randomness; this does not affect the DP inequality). Apply the $(\varepsilon,\delta)$-DP guarantee to $S$ with the ordered pair $(D_1, D_0)$: $$\Pr[M(D_1) \in S] \;\le\; e^\varepsilon \Pr[M(D_0) \in S] + \delta \;\;\Longleftrightarrow\;\; \mathrm{TPR} \;\le\; e^\varepsilon \mathrm{FPR} + \delta.$$ Apply it to the complementary event $S^c$ with the ordered pair $(D_0, D_1)$: $$\Pr[M(D_0) \in S^c] \;\le\; e^\varepsilon \Pr[M(D_1) \in S^c] + \delta \;\;\Longleftrightarrow\;\; 1 - \mathrm{FPR} \;\le\; e^\varepsilon(1 - \mathrm{TPR}) + \delta.$$

    (b) Loose bound. From the first inequality of (a) and $\mathrm{FPR} \le 1$: $$\mathrm{Adv} = \mathrm{TPR} - \mathrm{FPR} \le (e^\varepsilon - 1)\mathrm{FPR} + \delta \le e^\varepsilon - 1 + \delta.$$

    Tighter (Kairouz–Oh–Viswanath). The pair of inequalities from (a) defines a polygonal region in the $(\mathrm{FPR}, \mathrm{TPR})$-plane. The maximum of $\mathrm{TPR} - \mathrm{FPR}$ over this region is attained where both inequalities are tight. Rewriting the second inequality as $$\mathrm{TPR} \ge 1 - e^{-\varepsilon}(1 - \mathrm{FPR}) - \delta e^{-\varepsilon},$$ and setting equal to $e^\varepsilon \mathrm{FPR} + \delta$, we get $$(e^\varepsilon - e^{-\varepsilon})\mathrm{FPR} \;=\; (1 - e^{-\varepsilon})(1 - \delta) \;\;\Longrightarrow\;\; \mathrm{FPR}^\star \;=\; \frac{1-\delta}{e^\varepsilon + 1}.$$ Then $\mathrm{TPR}^\star = e^\varepsilon \mathrm{FPR}^\star + \delta = (e^\varepsilon + \delta)/(e^\varepsilon + 1)$, so $$\mathrm{Adv}^\star \;=\; \mathrm{TPR}^\star - \mathrm{FPR}^\star \;=\; \frac{e^\varepsilon + \delta - (1 - \delta)}{e^\varepsilon + 1} \;=\; \frac{e^\varepsilon - 1 + 2\delta}{e^\varepsilon + 1}. \quad\square$$

    (c) Numerical. For $\varepsilon = 0.1, \delta = 10^{-5}$: loose bound $= e^{0.1} - 1 + 10^{-5} \approx 0.1052$; tighter bound $\approx 0.0500$. For $\varepsilon = 8$: $e^8 \approx 2981$, so the loose bound is $\approx 2980$ and the tighter bound is $\approx 1$ — both useless, since advantage is automatically $\le 1$.

  3. Generalization Gap as a Leakage Lower Bound (Yeom). Bounded loss $\ell \in [0, B]$. Threshold attack $\mathcal{A}_\tau(z) = \mathbf{1}[\ell \le \tau]$.
    1. $\mathrm{Adv}(\mathcal{A}_\tau) = F_1(\tau) - F_0(\tau)$.
    2. Layer cake; $\int_0^B (F_1 - F_0)\, dt = \Delta$.
    3. $\sup_\tau \mathrm{Adv}(\mathcal{A}_\tau) \ge \Delta/B$.
    4. Gaussian: optimal $\tau^\star = (R_{\mathrm{train}} + R_{\mathrm{pop}})/2$, $\mathrm{Adv}^\star = 2\Phi(\Delta/(2\sigma)) - 1$, with linear regime $\Delta/(\sigma\sqrt{2\pi})$.
    Solution.

    (a) By definitions, $\mathrm{TPR} = \Pr[\mathcal{A}_\tau = 1 \mid b = 1] = \Pr[\ell \le \tau \mid b = 1] = F_1(\tau)$, $\mathrm{FPR} = F_0(\tau)$. Subtract.

    (b) Layer cake. Let $f_X$ be the density of $X$. Write $t = \int_0^t 1\,ds$ and substitute: $$\mathbb{E}[X] \;=\; \int_0^B t f_X(t)\,dt \;=\; \int_0^B \!\!\left(\int_0^t 1\,ds\right) f_X(t)\,dt \;=\; \iint_{0 \le s < t \le B} f_X(t)\,ds\,dt.$$ Switch the order of integration over the triangle $\{0 \le s < t \le B\} = \{0 \le s \le B,\ s < t \le B\}$: $$\mathbb{E}[X] \;=\; \int_0^B \!\!\left(\int_s^B f_X(t)\,dt\right) ds \;=\; \int_0^B \Pr[X > s]\,ds \;=\; \int_0^B (1 - F_X(s))\,ds.$$ Apply to $\ell$ under each hypothesis: $$R_{\mathrm{pop}} - R_{\mathrm{train}} \;=\; \int_0^B [(1 - F_0(t)) - (1 - F_1(t))]\,dt \;=\; \int_0^B (F_1(t) - F_0(t))\,dt \;=\; \Delta.$$

    (c) Mean-value extraction. Let $h(t) = F_1(t) - F_0(t)$. If $h(t) < \Delta/B$ for every $t \in [0, B]$, then $\int_0^B h\,dt < B \cdot (\Delta/B) = \Delta$, contradicting (b). Hence some $\tau^\star \in [0, B]$ satisfies $h(\tau^\star) \ge \Delta/B$, so $\mathrm{Adv}(\mathcal{A}_{\tau^\star}) \ge \Delta/B$. The generalization gap is therefore a lower bound on the leakage of the best threshold attack, not an upper bound.

    (d) Gaussian. With $\mu_1 = R_{\mathrm{train}}, \mu_0 = R_{\mathrm{pop}}$, $F_b(t) = \Phi((t - \mu_b)/\sigma)$, so $$h(\tau) \;=\; \Phi\!\left(\tfrac{\tau - R_{\mathrm{train}}}{\sigma}\right) - \Phi\!\left(\tfrac{\tau - R_{\mathrm{pop}}}{\sigma}\right).$$ Setting $h'(\tau) = 0$ gives $\phi((\tau - R_{\mathrm{train}})/\sigma) = \phi((\tau - R_{\mathrm{pop}})/\sigma)$ (where $\phi$ is the standard normal pdf), so $|\tau - R_{\mathrm{train}}| = |\tau - R_{\mathrm{pop}}|$, i.e., $\tau^\star = (R_{\mathrm{train}} + R_{\mathrm{pop}})/2$. Then $\tau^\star - R_{\mathrm{train}} = \Delta/2$ and $\tau^\star - R_{\mathrm{pop}} = -\Delta/2$, so $$\mathrm{Adv}^\star \;=\; \Phi(\Delta/(2\sigma)) - \Phi(-\Delta/(2\sigma)) \;=\; 2\Phi(\Delta/(2\sigma)) - 1.$$ For small $x = \Delta/(2\sigma)$, $\Phi(x) \approx 1/2 + x\phi(0) = 1/2 + x/\sqrt{2\pi}$, so $\mathrm{Adv}^\star \approx 2x/\sqrt{2\pi} = \Delta/(\sigma\sqrt{2\pi})$. Larger $\sigma$ (noisier loss distributions) flattens the gap and reduces leakage — the same idea behind DP noise injection. $\quad\square$

  4. Influence-Function Unlearning (Closed Form). $L$ $\lambda$-strongly convex, $G$-Lipschitz. Show $\theta_{-z} - \theta_o \approx \frac{1}{n}H^{-1}\nabla\ell(\theta_o; z)$ and bound the deletion sensitivity.
    1. Implicit-function derivative.
    2. First-order Newton-step approximation.
    3. $L_2$-sensitivity bound $\le 2G/(\lambda n)$.
    Solution.

    (a) Implicit derivative. Define the path $L_t(\theta) = L(\theta; D) - (t/n)\,\ell(\theta; z)$ for $t \in [0, 1]$. By strong convexity, the unique minimizer $\theta(t) = \arg\min L_t$ exists and satisfies $$F(\theta(t), t) \;:=\; \nabla_\theta L(\theta(t); D) - \frac{t}{n}\,\nabla_\theta \ell(\theta(t); z) \;=\; 0.$$ Differentiate both sides with respect to $t$ (chain rule): $$\underbrace{\Big[\nabla^2 L(\theta(t); D) - \tfrac{t}{n}\nabla^2 \ell(\theta(t); z)\Big]}_{=: H_t}\,\theta'(t) \;-\; \frac{1}{n}\,\nabla_\theta \ell(\theta(t); z) \;=\; 0.$$ At $t = 0$, $H_0 = \nabla^2 L(\theta_o; D) = H_{\theta_o}$, and $\theta(0) = \theta_o$. Solving, $$\theta'(0) \;=\; \frac{1}{n}\, H_{\theta_o}^{-1}\,\nabla_\theta \ell(\theta_o; z).$$ (Invertibility of $H_{\theta_o}$ follows from $H_{\theta_o} \succeq \lambda I$.)

    (b) Taylor expansion. A first-order Taylor expansion at $t = 1$ gives $$\theta_{-z} - \theta_o \;=\; \theta(1) - \theta(0) \;\approx\; \theta'(0)\cdot 1 \;=\; \frac{1}{n}\, H_{\theta_o}^{-1}\,\nabla_\theta \ell(\theta_o; z).$$ Thus $\theta_u(D, z) = \theta_o + \frac{1}{n}H_{\theta_o}^{-1}\nabla_\theta \ell(\theta_o; z)$ is the Newton-step formula from the slides.

    (c) Sensitivity. For two candidate deleted points $z, z'$: $$\theta_u(D, z) - \theta_u(D, z') \;=\; \frac{1}{n}\, H_{\theta_o}^{-1}\,\big(\nabla\ell(\theta_o; z) - \nabla\ell(\theta_o; z')\big).$$ Take norms, using $\|H_{\theta_o}^{-1}\|_{\mathrm{op}} \le 1/\lambda$ and $\|\nabla\ell\| \le G$: $$\|\theta_u(D, z) - \theta_u(D, z')\| \;\le\; \frac{1}{\lambda n}\,(G + G) \;=\; \frac{2G}{\lambda n}. \quad\square$$ This is the $L_2$-sensitivity used to calibrate Gaussian noise in certified unlearning.

  5. Certified $(\varepsilon,\delta)$-Unlearning by Gaussian Noise. $\mathcal{U}(D, z) = \theta_o + \frac{1}{n}H^{-1}\nabla\ell + N$ with $N \sim \mathcal{N}(0, \sigma^2 I)$. Second-order error $\eta \le C_2 G^2/(\lambda^2 n^2)$.
    1. Total $L_2$-sensitivity from retrain is $\le \eta$.
    2. Apply Gaussian mechanism; required $\sigma \ge \frac{C_2 G^2}{\lambda^2 n^2 \varepsilon}\sqrt{2\log(1.25/\delta)}$.
    3. Compare scaling with DP-of-training.
    Solution.

    (a) Sensitivity. Define the first-order unlearned parameter $\theta_u^{\mathrm{1st}} = \theta_o + \frac{1}{n} H^{-1} \nabla\ell(\theta_o; z)$, so $\mathcal{U}(D, z) = \theta_u^{\mathrm{1st}} + N$. The exact retrain is $\theta_{-z} = A(D \setminus \{z\})$. The hypothesis says $$\|\theta_u^{\mathrm{1st}} - \theta_{-z}\| \;\le\; \eta \;\le\; \frac{C_2 G^2}{\lambda^2 n^2}.$$ So the deterministic part of $\mathcal{U}$ differs from $A(D \setminus\{z\})$ by at most $\eta$ in $L_2$.

    (b) Gaussian-mechanism bound. Apply the cited Gaussian-mechanism guarantee with $f = \theta_u^{\mathrm{1st}}$ and $g = \theta_{-z}$, both viewed as functions of the input $(D, z)$: $$\sigma \;\ge\; \frac{\eta}{\varepsilon}\sqrt{2\log(1.25/\delta)} \;\;\Longleftarrow\;\; \sigma \;\ge\; \frac{C_2\, G^2}{\lambda^2 n^2\, \varepsilon}\,\sqrt{2\log(1.25/\delta)}.$$ This matches the Guo et al. (2020) bound.

    (c) Scaling. Unlearning noise scales as $\sigma \propto 1/n^2$, whereas DP-of-the-trained-model noise scales as $\sigma_{\mathrm{DP}} \propto 1/n$. The unlearning task is easier for large $n$: a single training point's influence on the optimum is itself $O(1/n)$, and the Newton correction in Problem 4 reduces the residual to $O(1/n^2)$ — much smaller than what full DP would need to mask. $\quad\square$
