The Term “Machine Unlearning”
Is Overused in LLMs

The Initial Definition of Unlearning

Training set $D$, forget set $F \subset D$, retain set $R = D \setminus F$.

$$\mathrm{Dist}\!\left(\mathcal{L}(\Theta'),\; \mathcal{L}(\Theta_R)\right) \;\le\; \tau, \qquad \Theta_R \sim \mathrm{Train}(R).$$

The unlearned $\Theta'$ must be indistinguishable from retraining on $R$.

Our position: this is what “unlearning” means. Other goals need other names.

What Today’s Papers Actually Do

Most LLM “unlearning” methods control the output manually.

Representation obfuscation

Distort internal activations on probe queries.

Behavioral refusal

IDK templates, LUNAR, DPO-style abstention.

Output suppression

GA, NPO — push likelihood on forget targets down.

Knowledge editing

Rewrite specific facts or associations.

All manipulate observable output. None match retrain-indistinguishability.

Benchmarks Check Output Failure

Common metrics on forget queries: ROUGE · QA accuracy · token likelihood · embedding similarity.

TOFU

Has a retrained reference. Follow-ups drop it.

MUSE

Reference for MIA only. ROUGE-L paths use no reference.

RWKU

No retrained reference. Probes only measure output change.

WMDP

No forget set. Capability suppression, not deletion.

Output-failure scoring rewards suppression as “unlearning.”

Maini et al., TOFU, COLM 2024.
Shi et al., MUSE, ICLR 2025.
Jin et al., RWKU, NeurIPS 2024 D&B.
Li et al., WMDP, ICML 2024.

Example: Unlearning Math Training Data

Setup. $F$ = a few math training examples. After training, the model picks up general math ability.

What should “unlearn $F$” mean?

Output suppression

Refuse the specific problems in $F$.

Model still solves new math problems.

Retrain on $D \setminus F$

The retrained model never saw the math data.

Loses the general math ability.

True unlearning of $F$ must also lose the derived capability.

Same story for data poisoning: backdoors survive surface suppression.

Pawelczyk, Di, Lu, Sekhari, Gautam, Neel, “Machine Unlearning Fails to Remove Data Poisoning Attacks”, ICLR 2025.

Jia, Zhang, Zhang, Liu, Runwal, Diffenderfer, Kailkhura, Liu, “SOUL: Second-Order Optimization for LLM Unlearning”, EMNLP 2024.

Surface Success Breaks Easily

Methods that pass output-failure metrics often fail under perturbation.

  • Paraphrase / multilingual probes recover “forgotten” content.
  • Benign fine-tuning on unrelated data un-suppresses.
  • Quantization alone can re-expose targets.

Training influence is still there — just hidden by the prompting protocol.

The Mismatch in the Literature

Many LLM unlearning papers (not all) follow this pattern:

Cite retrain
indistinguishability
→
Implement another method
(e.g., suppression / refusal)
→
Score with
output-control metrics

The framing is distributional; the method and metric are output-level.

Suppression and refusal are important — we only argue they are different from unlearning.

Pick a Lane — Then Measure It

Indistinguishability
 

Show $\mathcal{L}(\Theta') \approx \mathcal{L}(\Theta_R)$.

Output control
(e.g., suppression / refusal)

State the goal.
Do not claim indistinguishability.

Yes, measuring indistinguishability is hard
— but that is not an excuse to confuse the terminology.

Disentangle measurement difficulty from problem definition.
