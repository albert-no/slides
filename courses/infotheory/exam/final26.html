Information Theory and Its Application in Deep Learning
Final Exam 2026 — Problems and Solutions

Differential entropy · Lossy compression · \(\chi^2\)-divergence
Logarithms are natural (nats) unless a problem states otherwise; for rate–distortion problems we use bits (base 2) and write \(\log\) for \(\log_2\). Throughout, \(D(\cdot\|\cdot)\) is the KL divergence and \(h(\cdot)\) the differential entropy. Three problems: differential entropy (1), lossy compression (2), and the \(\chi^2\)-divergence (3). Answer all three.

1. Differential Entropy and Maximum Entropy (30 points)

Let \(X\) be a continuous random variable. Recall \(h(X) = -\int f(x)\log f(x)\,dx\) (nats).

  1. Let \(X \sim \mathrm{Exp}(\lambda)\), i.e. \(f(x) = \lambda e^{-\lambda x}\) for \(x \ge 0\). Compute \(h(X)\). (10 pts)
  2. Let \(Y = cX\) for a constant \(c > 0\). Find \(h(Y)\) in two ways: (i) from the scaling rule, and (ii) by identifying the distribution of \(Y\). (10 pts)
  3. Show that among all densities supported on \((0,\infty)\) with mean \(\mathbb{E}[X] = \mu\), the exponential density \(f(x) = \tfrac1\mu e^{-x/\mu}\) maximizes \(h\). (10 pts)
Solution: Differential Entropy and Maximum Entropy.
  1. \[ h(X) = -\int_0^\infty \lambda e^{-\lambda x}\big(\log\lambda - \lambda x\big)\,dx = -\log\lambda + \lambda\,\mathbb{E}[X] = -\log\lambda + \lambda\cdot\tfrac1\lambda = 1 - \log\lambda. \]
  2. (i) The scaling rule \(h(cX) = h(X) + \log|c|\) gives \(h(Y) = 1 - \log\lambda + \log c\). (ii) \(Y = cX \sim \mathrm{Exp}(\lambda/c)\), so by part (a) \(h(Y) = 1 - \log(\lambda/c) = 1 - \log\lambda + \log c\). The two agree.
  3. Let \(g\) be any density on \((0,\infty)\) with \(\int_0^\infty x\,g(x)\,dx = \mu\), and let \(f(x)=\tfrac1\mu e^{-x/\mu}\) be the exponential with the same mean. By non-negativity of KL, \[ 0 \le D(g\|f) = \int g\log\frac{g}{f} = -h(g) - \int g(x)\log f(x)\,dx. \] Since \(\log f(x) = -\log\mu - x/\mu\), \[ \int g(x)\log f(x)\,dx = -\log\mu - \frac1\mu\int x\,g(x)\,dx = -\log\mu - 1. \] Therefore \(0 \le -h(g) + \log\mu + 1\), i.e. \(h(g) \le 1 + \log\mu\). The bound is attained by \(f\) itself, since \(h(f) = 1 - \log(1/\mu) = 1 + \log\mu\). Hence the exponential is the maximizer, with maximum entropy \(1+\log\mu\). Equality holds iff \(g = f\).

2. Rate–Distortion of an Independent Gaussian Pair (35 points)

Consider a vector source \(\mathbf{X} = (X_1, X_2)\) with independent components \(X_i \sim \mathcal{N}(0,\sigma_i^2)\), and squared-error distortion \(d(\mathbf{x},\hat{\mathbf{x}}) = \sum_{i=1}^2 (x_i - \hat x_i)^2\). Work with the information rate–distortion function \(R(D) = \min_{p(\hat{\mathbf x}\mid \mathbf x):\,\mathbb{E}\|\mathbf X-\hat{\mathbf X}\|^2\le D} I(\mathbf{X};\hat{\mathbf{X}})\), and write \(R_i\) for the single-component function \(R_i(D_i)=\big[\tfrac12\log\tfrac{\sigma_i^2}{D_i}\big]^{+}\) — equal to \(\tfrac12\log(\sigma_i^2/D_i)\) for \(0<D_i\le\sigma_i^2\), \(0\) for \(D_i\ge\sigma_i^2\), and \(R_i(0)=+\infty\). Rates are in bits, \(\log=\log_2\). The goal is to prove \[ R(D) = \min_{\substack{D_1,D_2\ge 0\\ D_1+D_2\le D}} \big(R_1(D_1)+R_2(D_2)\big). \]

  1. Decoupling lemma. For any joint distribution of \((\mathbf X,\hat{\mathbf X})\), show \[ I(\mathbf{X};\hat{\mathbf{X}}) \;\ge\; I(X_1;\hat X_1) + I(X_2;\hat X_2). \] Hint. Write \(I = h(\mathbf X) - h(\mathbf X\mid\hat{\mathbf X})\); use independence on the first term, the chain rule on the second, and "conditioning reduces entropy." (10 pts)
  2. Converse. Show that \[ R(D) \;\ge\; \min_{D_1+D_2\le D}\big(R_1(D_1)+R_2(D_2)\big). \] Hint. Take any test channel feasible for \(R(D)\); set \(D_i=\mathbb{E}[(X_i-\hat X_i)^2]\) so \(D_1+D_2\le D\). Apply part (a), then bound each \(I(X_i;\hat X_i)\) below using the definition of the single-letter \(R_i\). (10 pts)
  3. Achievability. Show the matching upper bound \[ R(D) \;\le\; \min_{D_1+D_2\le D}\big(R_1(D_1)+R_2(D_2)\big), \] so that equality holds. Hint. Fix any split \((D_1,D_2)\) with \(D_1+D_2\le D\) and build a product test channel \(p(\hat{\mathbf x}\mid\mathbf x)=\prod_i p_i^\star(\hat x_i\mid x_i)\) from the per-component optimizers. Compute its mutual information and its distortion. (15 pts)
Solution: Rate–Distortion of an Independent Gaussian Pair.
  1. (Decoupling lemma.) Since \(X_1,X_2\) are independent, \(h(\mathbf X)=h(X_1)+h(X_2)\). For the conditional term use the chain rule and that adding conditioning variables can only lower differential entropy: \[ h(\mathbf X\mid\hat{\mathbf X}) = h(X_1\mid\hat{\mathbf X}) + h(X_2\mid X_1,\hat{\mathbf X}) \le h(X_1\mid\hat X_1) + h(X_2\mid\hat X_2), \] because \(\hat{\mathbf X}\supseteq\hat X_1\) and \(\{X_1,\hat{\mathbf X}\}\supseteq\hat X_2\). Therefore \[ I(\mathbf X;\hat{\mathbf X}) = h(\mathbf X)-h(\mathbf X\mid\hat{\mathbf X}) \ge \sum_{i=1}^2\big(h(X_i)-h(X_i\mid\hat X_i)\big) = \sum_{i=1}^2 I(X_i;\hat X_i). \qquad\blacksquare \]
  2. (Converse.) Let \(p(\hat{\mathbf x}\mid\mathbf x)\) be any test channel feasible for \(R(D)\), and set \(D_i=\mathbb{E}[(X_i-\hat X_i)^2]\); then \(D_1+D_2=\mathbb{E}\|\mathbf X-\hat{\mathbf X}\|^2\le D\). By part (a) and the fact that each marginal channel \(X_i\to\hat X_i\) achieves distortion \(D_i\) (so by definition of the single-letter function \(I(X_i;\hat X_i)\ge R_i(D_i)\)), \[ I(\mathbf X;\hat{\mathbf X}) \ge \sum_i I(X_i;\hat X_i) \ge \sum_i R_i(D_i) \ge \min_{D_1+D_2\le D}\sum_i R_i(D_i). \] The right-hand side does not depend on the channel, so taking the minimum of the left-hand side over all feasible channels — which is exactly \(R(D)\) — preserves the inequality: \[ R(D) \ge \min_{D_1+D_2\le D}\big(R_1(D_1)+R_2(D_2)\big). \qquad\blacksquare \]
  3. (Achievability.) Fix any split \((D_1,D_2)\) with \(D_1+D_2\le D\); we may take \(0<D_i\le\sigma_i^2\), since raising \(D_i\) above \(\sigma_i^2\) leaves \(R_i=0\) while only loosening the budget (and \(D_i\to0\) is the lossless limit, \(R_i\to\infty\)), so it never helps the minimum. For each component let \(p_i^\star(\hat x_i\mid x_i)\) be the optimal scalar Gaussian test channel attaining \(I(X_i;\hat X_i)=R_i(D_i)\) at distortion exactly \(D_i\), and form the product channel \(p(\hat{\mathbf x}\mid\mathbf x)=p_1^\star(\hat x_1\mid x_1)\,p_2^\star(\hat x_2\mid x_2)\). Because both the source and the channel factorize, the pairs \((X_1,\hat X_1)\) and \((X_2,\hat X_2)\) are mutually independent, so mutual information is additive and the distortion adds: \[ I(\mathbf X;\hat{\mathbf X}) = \sum_i I(X_i;\hat X_i) = \sum_i R_i(D_i), \qquad \mathbb{E}\|\mathbf X-\hat{\mathbf X}\|^2 = D_1+D_2 \le D. \] This channel is therefore feasible for \(R(D)\), so \(R(D)\le \sum_i R_i(D_i)\). Since this holds for every feasible split, \(R(D)\le \min_{D_1+D_2\le D}\sum_i R_i(D_i)\). Together with part (b), \[ R(D) = \min_{D_1+D_2\le D}\big(R_1(D_1)+R_2(D_2)\big). \qquad\blacksquare \]

    Solving this convex program (Lagrange multipliers) yields the reverse water-filling allocation \(D_i=\min(\theta,\sigma_i^2)\) — but that step is not required here.

3. The \(\chi^2\)-Divergence: From Estimator Variance to the Evidence (35 points)

The \(\chi^2\)-divergence is \(\chi^2(P\|Q)=\int\frac{(p-q)^2}{q}=\int\frac{p^2}{q}-1\). After establishing its basic properties, you will use it twice: once to lower-bound the variance of an estimator, and once to upper-bound an intractable log-evidence.

  1. Foundations. Writing the likelihood ratio as \(p/q\), show \(\chi^2(P\|Q)=\mathrm{Var}_Q\!\big(\tfrac{p}{q}\big)\), and that \(D(P\|Q)\le\chi^2(P\|Q)\). Hint. \(\log t\le t-1\). (10 pts)
  2. Hammersley–Chapman–Robbins. For any statistic \(T\) with \(\mathbb{E}_P[T]=a\), \(\mathbb{E}_Q[T]=b\), prove \[ \mathrm{Var}_Q(T) \;\ge\; \frac{(a-b)^2}{\chi^2(P\|Q)}. \] Then, for a parametric family \(\{P_\theta\}\) with an unbiased estimator of \(\theta\), take \(Q=P_\theta\), \(P=P_{\theta+h}\) and let \(h\to0\) to recover the Cramér–Rao bound \(\mathrm{Var}_\theta(T)\ge 1/I(\theta)\). Hint. Express \(a-b\) as a covariance under \(Q\) and apply Cauchy–Schwarz. (15 pts)
  3. A \(\chi^2\) upper bound on the evidence (CUBO). For a latent-variable model \(p(x)=\int p(x,z)\,dz\), a proposal \(q(z\mid x)\), and weight \(w=\dfrac{p(x,z)}{q(z\mid x)}\), define \(\mathrm{CUBO}_2=\tfrac12\log\mathbb{E}_{q(z\mid x)}[w^2]\). Show \(\log p(x)\le\mathrm{CUBO}_2\), that the gap is exactly \(\tfrac12\log\big(1+\chi^2(p(z\mid x)\|q(z\mid x))\big)\), and hence \(\ \mathrm{ELBO}\le\log p(x)\le\mathrm{CUBO}_2\). Hint. \(p(x)=\mathbb{E}_q[w]\) and \((\mathbb{E}_q[w])^2\le\mathbb{E}_q[w^2]\); then write \(w=p(x)\,\tfrac{p(z\mid x)}{q(z\mid x)}\). (10 pts)
Solution: The \(\chi^2\)-Divergence.
  1. (Foundations.) Let \(W=p/q\); then \(\mathbb{E}_Q[W]=1\) and \(\mathrm{Var}_Q(W)=\mathbb{E}_Q[W^2]-1=\int\frac{p^2}{q}-1=\chi^2(P\|Q)\). For the comparison with KL, using \(\log t\le t-1\), \[ D(P\|Q)=\int p\log\frac pq \le \int p\Big(\frac pq-1\Big)=\int\frac{p^2}{q}-1=\chi^2(P\|Q). \]
  2. (Hammersley–Chapman–Robbins.) Assume \(P\ne Q\) and \(\chi^2(P\|Q)<\infty\), so the bound is non-vacuous. With \(W=p/q\) and \(\mathbb{E}_Q[W]=1\), \[ a-b=\mathbb{E}_P[T]-\mathbb{E}_Q[T]=\int T(p-q)=\mathbb{E}_Q\big[T(W-1)\big]=\mathrm{Cov}_Q(T,W). \] By Cauchy–Schwarz, \((a-b)^2=\mathrm{Cov}_Q(T,W)^2\le\mathrm{Var}_Q(T)\,\mathrm{Var}_Q(W)=\mathrm{Var}_Q(T)\,\chi^2(P\|Q)\), which rearranges to the claim. For the parametric limit (with \(\{P_\theta\}\) smooth in \(\theta\) and finite Fisher information), unbiasedness gives \(a=\mathbb{E}_{\theta+h}[T]=\theta+h\) and \(b=\mathbb{E}_\theta[T]=\theta\), so \(a-b=h\) and \(\mathrm{Var}_\theta(T)\ge h^2/\chi^2(P_{\theta+h}\|P_\theta)\). As \(h\to0\), \[ \chi^2(P_{\theta+h}\|P_\theta)=\int\frac{(p_{\theta+h}-p_\theta)^2}{p_\theta} \approx h^2\int\frac{(\partial_\theta p_\theta)^2}{p_\theta}=h^2 I(\theta), \] so \(\mathrm{Var}_\theta(T)\ge h^2/(h^2 I(\theta))=1/I(\theta)\): HCR is a finite-difference Cramér–Rao bound. \(\qquad\blacksquare\)
  3. (CUBO.) Assume \(q(z\mid x)>0\) wherever \(p(z\mid x)>0\) and \(\mathbb{E}_q[w^2]<\infty\). Since \(p(x)=\int p(x,z)\,dz=\int q\,\tfrac{p(x,z)}{q}=\mathbb{E}_q[w]\), Jensen (convexity of the square) gives \(p(x)^2=(\mathbb{E}_q[w])^2\le\mathbb{E}_q[w^2]\); taking \(\tfrac12\log\), \(\log p(x)\le\tfrac12\log\mathbb{E}_q[w^2]=\mathrm{CUBO}_2\). For the gap, write \(w=\tfrac{p(x,z)}{q(z\mid x)}=p(x)\,\tfrac{p(z\mid x)}{q(z\mid x)}\), so \[ \mathbb{E}_q[w^2]=p(x)^2\!\int\frac{p(z\mid x)^2}{q(z\mid x)} =p(x)^2\big(1+\chi^2(p(z\mid x)\|q(z\mid x))\big), \] using \(\int\frac{p^2}{q}=1+\chi^2(p\|q)\) from part (a). Hence \(\mathrm{CUBO}_2=\log p(x)+\tfrac12\log(1+\chi^2)\), so the gap is \(\tfrac12\log(1+\chi^2(p(z\mid x)\|q(z\mid x)))\ge0\), vanishing iff \(q(z\mid x)=p(z\mid x)\). Combined with the ELBO lower bound, \(\ \mathrm{ELBO}\le\log p(x)\le\mathrm{CUBO}_2\), bracketing the intractable log-evidence between two computable bounds. The ELBO gap is the reverse KL \(D(q(z\mid x)\|p(z\mid x))\) (mode-seeking), while the CUBO gap is driven by \(\chi^2(p(z\mid x)\|q(z\mid x))\) (mass-covering). \(\qquad\blacksquare\)
