Data vs Control, Formally

Classic systems keep two things apart: what runs and what is read.

Control plane

Instructions that decide behavior. Privileged.

Data plane

Inputs to inspect, never to obey. Untrusted.

An LLM has one context window and no privilege boundary: both planes are the same token stream.

The Confused Deputy

A classic security pattern, stated for agents.

Confused deputy

A trusted program holds an authority (the user's permissions) and is tricked by an unauthorized party (injected text) into exercising that authority on the attacker's behalf.

The agent has the power; the attacker supplies the intent.

A Threat Model for Agents

State the trust boundary explicitly.

  • Trusted: the user's goal, the system prompt
  • Untrusted: any tool output (pages, emails, files)
  • Attacker's power: write arbitrary text into any untrusted source
  • Attacker's goal: make the agent take an action the user did not authorize

Harm needs all three: reads untrusted input, holds private data, can act outward.

Capabilities and Least Privilege

Bound the damage before the model runs, not after.

Least privilege

Grant each action only the capabilities its task requires. A capability is an unforgeable token authorizing one specific operation.

  • Fix the plan from the trusted goal; untrusted text fills in values, not actions
  • A read-only agent literally cannot send data out
Debenedetti et al., "Defeating Prompt Injections by Design" (CaMeL), 2025.

Taint / Dataflow Tracking

Label the origin of every value and follow it.

  1. Mark any value derived from untrusted text as tainted.
  2. Propagate the taint through every transformation it touches.
  3. At a risky sink (send, delete, pay), block if the argument is tainted.

An old dataflow-security idea, applied to the agent loop.

The Dual-LLM Pattern

Enforce the boundary by splitting the model in two.

Privileged

Plans and calls tools. Never sees raw untrusted text, only symbolic references to it.

Quarantined

Reads the tainted content. Holds no capabilities, so it cannot act.

Tainted text reaches a model that structurally cannot reach a sink.

Willison, "The Dual LLM pattern for building AI assistants that can resist prompt injection", 2023.
