# sangnam2609/ — Sangnam general-audience ML introduction (Sep 2026)

3–4 hour introductory talk on machine learning for **freshman undergrads**
(no calculus, no linear algebra assumed). High-level overview only: concepts,
pictures, and stories — no derivations, no optimization mathematics.

Roughly one hour is reserved for the closing frontier-and-risks block:
recent advances (diffusion, RLVR, AI-assisted mathematics) paired with recent
failures (agent containment breaches, scheming/sabotage evaluations).

Split into four decks, one per ~50-minute block.

## Files

- `sangnam1-model-is-function.html` — Block 1: a model is a function
- `sangnam2-regression-and-training.html` — Block 2: loss, training, classification
- `sangnam3-generalization-and-scale.html` — Block 3: overfitting, model size, scaling laws
- `sangnam4-frontier-and-risks.html` — Block 4: recent advances and recent incidents
- `figs/` — captured paper / press figures
