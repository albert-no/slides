Formal Goals, Separated

Only data removal has a retrained reference; the rest of this supplement formalizes that box only.

Data removal

Forget set $D_f \subset D$. Reference: $A(D \setminus D_f)$.

Exact: equal in distribution. Certified: $(\varepsilon,\delta)$-close. Approximate: no bound, audited.

Knowledge suppression

Target: a concept, no rows. No retrained reference exists.

Goal is behavioral: low score on a prompt set, under a stated attack budget.

Output filtering

Weights unchanged; a wrapper blocks answers.

No forgetting claim; bypassed by weight access.

Access revocation

Retrieval source removed; weights never held the fact.

Verified by inspection of the pipeline.

Exact vs Approximate

Two guarantees, against the same retraining target.

Exact

Unlearned model is equal in distribution to retraining without the point.

Approximate

Unlearned model is close in distribution, within a bounded gap.

Exact needs structure; approximate trades exactness for speed.

Data removal · certified

The $(\varepsilon, \delta)$ Definition

Borrow the DP yardstick: unlearning is indistinguishable from retraining.

$(\varepsilon, \delta)$-unlearning

For every measurable set $S$ of models,

$$\Pr[\,U(M, x) \in S\,] \;\le\; e^{\varepsilon}\,\Pr[\,\text{Retrain} \in S\,] \;+\; \delta,$$

and the same bound with the two sides swapped.

Guo, Goldstein, Hannun, van der Maaten, "Certified Data Removal from Machine Learning Models", ICML 2020, Eq. 1 and §2  ·  Sekhari et al., NeurIPS 2021.
Data removal · certified

Reading the Inequality

The bound holds both directions, over the randomness of training.

  • $U(M,x)$ = unlearner applied to point $x$
  • Small $\varepsilon, \delta$ ⇒ outputs look retrained
  • $\varepsilon = \delta = 0$ recovers exact unlearning

The same shape as $(\varepsilon,\delta)$ differential privacy.

Data removal · approximate

Influence Functions

Estimate one point's pull on the optimum, then subtract it.

$$\theta_{-x} \;\approx\; \hat\theta \;+\; \frac{1}{n}\,H^{-1}\,\nabla_\theta \ell(\hat\theta, x).$$

$\hat\theta$ = trained weights; $H$ = loss Hessian at $\hat\theta$; $\ell$ = per-point loss.

Koh and Liang, "Understanding Black-box Predictions via Influence Functions", ICML 2017.
Data removal · approximate

Where It Comes From

Upweight $x$ by $\epsilon$; the optimum moves along the inverse curvature.

$$\left.\frac{d\,\theta(\epsilon)}{d\epsilon}\right|_{\epsilon=0} \;=\; -\,H^{-1}\,\nabla_\theta \ell(\hat\theta, x).$$

Removing the point is upweighting by $-1/n$: hence the $\tfrac1n H^{-1}\nabla$ step.

Koh and Liang, "Understanding Black-box Predictions via Influence Functions", ICML 2017.
Data removal · approximate

Why the Hessian Blocks It

The estimate needs $H^{-1}$, one entry per pair of parameters.

$$H = \nabla_\theta^2 \ell \in \mathbb{R}^{d \times d}, \qquad 10^9 \text{ params} \Rightarrow 10^{18} \text{ entries}.$$

Storing $H$, let alone inverting it, is infeasible at scale.

Koh and Liang, "Understanding Black-box Predictions via Influence Functions", ICML 2017.
Data removal · approximate

Gradient Ascent

Training descends the loss. To forget, ascend it on the target.

$$\theta \;\leftarrow\; \theta \;+\; \eta\,\nabla_\theta \ell(\theta, x_{\text{forget}}).$$

Raises the forget point's loss; needs a retain anchor to stay useful. On a concept target with no rows, the same update is knowledge suppression.

Thudi et al., "Unrolling SGD: Understanding Factors Influencing Machine Unlearning", IEEE EuroS&P 2022.
Data removal · exact

The SISA Cost Model

Split $n$ points into $S$ shards, each shard into $R$ slices.

  1. A delete request hits the one shard holding the point.
  2. Roll back to the checkpoint before the point's slice.
  3. Replay only the later slices of that shard, then re-aggregate.
$$\mathbb{E}[\text{cost}] \;=\; \frac{n\,(R+1)(2R+1)}{6SR}, \qquad \frac{\text{full shard}}{\mathbb{E}[\text{cost}]} \;=\; \frac{3R}{2R+1} \nearrow \frac{3}{2}.$$

Sharding divides cost by $S$; slicing saves at most $3/2$. Derivation in the lecture note.

Bourtoule et al., "Machine Unlearning", IEEE S&P 2021.
