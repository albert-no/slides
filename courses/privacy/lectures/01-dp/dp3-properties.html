01

Composition

Privacy budgets add when you re-query the same data.

Recall — the Multiplicative Guarantee

Recall ($\varepsilon$-DP).

$\mathcal M$ is $\varepsilon$-DP if for all neighbors $D \sim D'$ and events $T$: $\;\Pr[\mathcal M(D)\in T] \le e^{\varepsilon}\,\Pr[\mathcal M(D')\in T]$.

Today: four closure properties, each proved by one named trick.

Composition   $\varepsilon_1+\varepsilon_2$
Post-processing   still $\varepsilon$
Group privacy   $t\varepsilon$
Subsampling   $\ln(1+q(e^\varepsilon-1))$

Intuition — a Privacy Budget

Every query on the same data spends privacy; leakage accumulates.

$\varepsilon_1$ $\varepsilon_2$ $\varepsilon_3$ remaining budget total budget $\varepsilon = \sum_i \varepsilon_i$ query 1 query 2 query 3

The adversary sees everything released; the guarantee must degrade gracefully.

Setting — Adaptive Queries

Realistic analysts iterate: the second query depends on the first answer.

$D$ $\mathcal M_1$  ($\varepsilon_1$-DP) $\mathcal M_2(\cdot,a_1)$  ($\varepsilon_2$-DP) $a_1$ $a_2$ $a_1$ feeds the next query

Basic Composition — Theorem

Theorem (adaptive composition).

Let $\mathcal M_1 : \mathcal X^n \to \mathcal Y_1$ be $\varepsilon_1$-DP, and let $\mathcal M_2 : \mathcal X^n \times \mathcal Y_1 \to \mathcal Y_2$ be $\varepsilon_2$-DP for each fixed $a_1$. Then

$$D \;\longmapsto\; \big(\mathcal M_1(D),\; \mathcal M_2(D, \mathcal M_1(D))\big) \quad\text{is } (\varepsilon_1+\varepsilon_2)\text{-DP}.$$

The proof is one factorization plus the two definitions.

Dwork, McSherry, Nissim, Smith, "Calibrating Noise to Sensitivity in Private Data Analysis", TCC 2006.

Proof — Factorize the Joint Probability

Fix any output pair $(a_1, a_2)$ and apply the chain rule:

$$\begin{aligned} &\Pr\big[(\mathcal M_1(D),\, \mathcal M_2(D,\mathcal M_1(D))) = (a_1,a_2)\big] \\[2pt] &\qquad=\; \Pr[\mathcal M_1(D)=a_1] \cdot \Pr[\mathcal M_2(D,a_1)=a_2] \end{aligned}$$

The same factorization holds for $D'$ with the same $(a_1, a_2)$.

Density-factorization trick. Conditioning on $a_1$ freezes the adaptive choice: two clean DP factors remain.

Proof (continued) — Bound Each Factor

$$\begin{aligned} \frac{\Pr\big[(\mathcal M_1,\mathcal M_2)(D)=(a_1,a_2)\big]}{\Pr\big[(\mathcal M_1,\mathcal M_2)(D')=(a_1,a_2)\big]} &= \underbrace{\frac{\Pr[\mathcal M_1(D)=a_1]}{\Pr[\mathcal M_1(D')=a_1]}}_{\le\, e^{\varepsilon_1}\;(\mathcal M_1 \text{ is DP})} \cdot \underbrace{\frac{\Pr[\mathcal M_2(D,a_1)=a_2]}{\Pr[\mathcal M_2(D',a_1)=a_2]}}_{\le\, e^{\varepsilon_2}\;(a_1 \text{ fixed})} \\[4pt] &\le\; e^{\varepsilon_1} \cdot e^{\varepsilon_2} \;=\; e^{\varepsilon_1+\varepsilon_2} \end{aligned}$$

Sum the pointwise bound over all pairs $(a_1,a_2) \in T$: events inherit it. $\blacksquare$

$k$-Fold Composition — the Budget Is Linear

Corollary.

Adaptively composing $\varepsilon_1,\dots,\varepsilon_k$-DP mechanisms is $\big(\textstyle\sum_{i=1}^{k}\varepsilon_i\big)$-DP; $\;k$ runs at $\varepsilon$ each cost $k\varepsilon$.

At $\varepsilon = 0.1$ per query, the total budget is $k\varepsilon$:

queriestotal budgetverdict
$1$$0.1$strong
$10$$1$acceptable
$100$$10$$e^{10} \approx 22{,}000$: vacuous

Post-Processing Immunity

Whatever you compute from a DP release stays DP.

Intuition — Privacy Is Fixed at Release

After release, $f$ sees only $Y$; it never touches $D$ again.

private data $D$
→
$\mathcal M$  ($\varepsilon$-DP)
→
$Y$
→
$f$: any analysis
→
$f(Y)$

the noise barrier sits once, at $\mathcal M$

No downstream cleverness can re-extract what the noise already destroyed.

Post-Processing — Theorem

Theorem (post-processing immunity).

Let $\mathcal M$ be $\varepsilon$-DP and $f : \mathcal Y \to \mathcal Z$ any map, possibly randomized (randomness independent). Then

$$f \circ \mathcal M \;\text{ is } \varepsilon\text{-DP}.$$

No assumption on $f$: arbitrary computation, unbounded adversary.

Dwork, Roth, "The Algorithmic Foundations of Differential Privacy", 2014.

Proof — Deterministic $f$: Pull Back the Event

Any event about $f(\mathcal M(D))$ is an event about $\mathcal M(D)$: define $f^{-1}(O) = \{y : f(y) \in O\}$.

$\mathcal Y$ $\mathcal Z$ $f^{-1}(O)$ $O$ $f$
$$\begin{aligned} \Pr[f(\mathcal M(D)) \in O] \;&=\; \Pr[\mathcal M(D) \in f^{-1}(O)] \;\le\; e^{\varepsilon} \Pr[\mathcal M(D') \in f^{-1}(O)] \\[2pt] &=\; e^{\varepsilon} \Pr[f(\mathcal M(D')) \in O] \end{aligned}$$

Proof (continued) — Randomized $f$ Is a Mixture

A randomized $f$ draws an independent seed $W$, then applies a deterministic $f_W$.

$$\begin{aligned} \Pr[f(\mathcal M(D)) \in O] &= \mathbb E_W\big[\Pr[f_W(\mathcal M(D)) \in O]\big] \\[2pt] &\le \mathbb E_W\big[e^{\varepsilon}\,\Pr[f_W(\mathcal M(D')) \in O]\big] = e^{\varepsilon}\,\Pr[f(\mathcal M(D')) \in O] \quad \blacksquare \end{aligned}$$
Mixture trick. A randomized map is an average of deterministic maps; the $e^{\varepsilon}$ bound survives averaging.

No Privacy Laundering

Free (post-processing).

Rounding, plotting, thresholding a DP release; training a model on DP outputs.

Not free.

Anything that touches $D$ again: a second query is composition, not post-processing.

Privacy accounting tracks touches of the raw data, nothing else.

We will use this today: dividing noisy sums by noisy counts is free.

03

Group Privacy

One person's guarantee extends to a family of $t$.

Group Privacy — Theorem

$\varepsilon$-DP hides one record. What about $t$ correlated people, e.g. a family?

Theorem (group privacy).

If $\mathcal M$ is $\varepsilon$-DP, then for all $D, D''$ differing in $\le t$ records, all $T$:

$$\Pr[\mathcal M(D) \in T] \;\le\; e^{t\varepsilon}\, \Pr[\mathcal M(D'') \in T].$$
Dwork, Roth, "The Algorithmic Foundations of Differential Privacy", 2014.

Proof — a Telescoping Chain of Neighbors

Interpolate: change one record at a time, $t$ times.

$D = D_0$
$\le e^{\varepsilon}\times$→
$D_1$
$\le e^{\varepsilon}\times$→
$D_2$
$\cdots$→
$D_t = D''$
$$\Pr[\mathcal M(D_0)\in T] \le e^{\varepsilon}\Pr[\mathcal M(D_1)\in T] \le \cdots \le e^{t\varepsilon}\Pr[\mathcal M(D_t)\in T] \quad \blacksquare$$
Telescoping trick. Each single-record hop is a neighbor pair; each costs one factor $e^{\varepsilon}$.

Scaling — $t\varepsilon$ Adds Up Fast

At $\varepsilon = 0.5$ per record: budget $t\varepsilon$, likelihood ratio $e^{t\varepsilon}$.

group sizebudgetlikelihood ratio
$1$ (individual)$0.5$$1.6$
$4$ (household)$2$$7.4$
$20$ (extended family)$10$$\approx 22{,}000$: vacuous

One person contributing $t$ records is the same computation.

Protecting whole households means choosing $\varepsilon$ with $t$ in mind.

Subsampling Amplification

Running on a random sample shrinks $\varepsilon$.

Intuition — Hiding in the Crowd

With probability $1-q$, your record is never touched: nothing can leak.

population: $n$ records in sample ($m = qn$) not sampled target $x_1$ (left out)

The adversary never learns who was sampled; the proof must handle that.

Intuition — a Mixture of Two Worlds

Not sampled (w.p. $1-q$)
output ignores $x_1$: ratio $= 1$
Sampled (w.p. $q$)
full exposure: ratio $\le e^{\varepsilon}$
$$e^{\varepsilon'} \;\overset{?}{=}\; (1-q)\cdot 1 + q \cdot e^{\varepsilon} \;=\; 1 + q\,(e^{\varepsilon}-1)$$

The heuristic guesses the right answer; the proof below makes it honest.

The Subsampled Mechanism

Definition (subsampling).

$\mathcal M : \mathcal X^m \to \mathcal Y$ is $\varepsilon$-DP. On $X \in \mathcal X^n$: draw uniform $I \subset [n]$, $|I| = m$ (no replacement); release $\mathcal M(s(X;I))$, $\;s(X;I) = (x_i)_{i \in I}$.

$X \in \mathcal X^n$
→
sample rate $q = \tfrac{m}{n}$
→
$s(X;I) \in \mathcal X^m$
→
$\mathcal M$  ($\varepsilon$-DP)

Amplification by Subsampling — Theorem

Theorem (amplification).

The subsampled mechanism $\mathcal M'$ is $\varepsilon'$-DP with

$$\varepsilon' \;=\; \ln\!\big(1 + q\,(e^{\varepsilon}-1)\big) \;\le\; \varepsilon.$$
$$\text{small } \varepsilon:\quad \varepsilon' \;\le\; q\,(e^{\varepsilon}-1) \;\approx\; q\,\varepsilon \qquad (\ln(1+x) \le x)$$

Amplification factor $\approx q$: sampling $1\%$ divides the budget by $\approx 100$.

Proof — the Plan

Neighbors $X = (x, x_2, \dots, x_n)$ and $X' = (x', x_2, \dots, x_n)$: the target sits at index $1$.

  1. Split: condition on whether $1 \in I$.
  2. Compare three worlds: in-sample $X$, in-sample $X'$, out-of-sample.
  3. Blend the two bounds with a convex weight $\alpha$.
  4. Rearrange into the factor $1 + q(e^{\varepsilon}-1)$.

Proof — Step 1: Condition on Membership

$\Pr[1 \in I] = m/n = q$. Name the two conditional branches, for any event $T$:

$$A := \Pr\big[\mathcal M(s(X;I)) \in T \,\big|\, 1 \in I\big], \qquad B := \Pr\big[\mathcal M(s(X;I)) \in T \,\big|\, 1 \notin I\big]$$

Same split for $X'$ (with $A'$); index $1$ unused when $1 \notin I$: $B$ shared.

$$\Pr[\mathcal M'(X) \in T] \;=\; q\,A + (1-q)\,B, \qquad \Pr[\mathcal M'(X') \in T] \;=\; q\,A' + (1-q)\,B$$

Proof — Step 2: Three Comparisons

$$\begin{aligned} \text{(i)}\quad A &\le e^{\varepsilon} A' &&\text{swap } x \to x' \text{ inside the sample: neighbors in } \mathcal X^m \\[2pt] \text{(ii)}\quad A &\le e^{\varepsilon} B &&\text{swap } x \text{ out of the sample: also neighbors} \\[2pt] \text{(iii)}\quad B &= B' &&X,\, X' \text{ agree off index } 1 \end{aligned}$$

(i): $\varepsilon$-DP of $\mathcal M$ on size-$m$ inputs, same $I$.  (iii): identical distributions.

(ii) compares different conditioning events: it needs its own argument.

Proof (continued) — Why $A \le e^{\varepsilon} B$

Pair each sample containing $1$ with a partner where $1$ is swapped out:

$I$
$x_1$
$x_5$
$x_9$
↔
$J$
$x_2$
$x_5$
$x_9$

$s(X;I)$ and $s(X;J)$ differ in one record: $\varepsilon$-DP gives the $e^{\varepsilon}$ factor.

Averaging the pairing over all subsets yields (ii). (Exercise: make this exact.)

Proof — Step 3: the Convex-Combination Trick

Two upper bounds on $A$; blend them with any weight $\alpha \in [0,1]$:

$$A \;\le\; \alpha\, e^{\varepsilon} A' \;+\; (1-\alpha)\, e^{\varepsilon} B$$

Choose the weight so both terms shrink by the same factor:

$$\alpha^{\star} \;=\; q + (1-q)\,e^{-\varepsilon}$$
Convex-combination trick. Do not pick one bound: blend both, then tune $\alpha$.

Proof (continued) — Rearrange and Conclude

$$\begin{aligned} \Pr[\mathcal M'(X) \in T] &= q\,A + (1-q)\,B \\[2pt] &\le q\,\alpha^{\star} e^{\varepsilon} A' + \big(q\,(1-\alpha^{\star})\,e^{\varepsilon} + 1 - q\big)\,B \\[2pt] &= \big(1 + q(e^{\varepsilon}-1)\big)\big(q\,A' + (1-q)\,B\big) \\[2pt] &= \big(1 + q(e^{\varepsilon}-1)\big)\,\Pr[\mathcal M'(X') \in T] \quad \blacksquare \end{aligned}$$

Check line 3 by expanding $\alpha^{\star}$: both coefficients pick up the factor $1+q(e^{\varepsilon}-1)$.

Proof Recap — One Chain

$$\begin{aligned} \Pr[\mathcal M'(X) \in T] \;&\stackrel{(\text{split})}{=}\; q\,A + (1-q)\,B \\[2pt] &\stackrel{(\text{blend})}{\le}\; q\,\alpha^{\star} e^{\varepsilon} A' + \big(q(1-\alpha^{\star})e^{\varepsilon} + 1-q\big)B \\[2pt] &\stackrel{(\alpha^{\star})}{=}\; \big(1+q(e^{\varepsilon}-1)\big)\,\Pr[\mathcal M'(X') \in T] \end{aligned}$$

Three comparisons powered the blend; conditioning powered the split.

Hence $\varepsilon' = \ln(1 + q(e^{\varepsilon}-1))$.

  • Steps then compose: total budget $\approx Tq\varepsilon$ over $T$ steps.

Why Not Additive DP?

A $\delta$ slack that looks harmless and is not.

A Tempting Relaxation

Definition (additive, $\delta$-DP).

$\mathcal M$ is $\delta$-additively private if for all neighbors $D \sim D'$ and events $T$:

$$\Pr[\mathcal M(D) \in T] \;\le\; \Pr[\mathcal M(D') \in T] + \delta$$
multiplicative: bounds the ratio by $e^{\varepsilon}$
additive: bounds the difference by $\delta$

It even inherits composition and post-processing. So why reject it? Two counterexamples.

Counterexample 1 — Publish Everything, Sometimes

$D$ w.p. $\delta$  (leak) w.p. $1-\delta$ $\mathcal M(D) = D$  (all of it) $\mathcal M(D) = \perp$
$$\mathcal M(D) = \begin{cases} D & \text{w.p. } \delta \\ \perp & \text{w.p. } 1-\delta \end{cases}$$

Counterexample 1 — It Satisfies $\delta$-Additive DP

For any event $T$, write out both output distributions:

$$\begin{aligned} \Pr[\mathcal M(D) \in T] &= \delta\,\mathbf 1\{D \in T\} + (1-\delta)\,\mathbf 1\{\perp \in T\} \\[2pt] \Pr[\mathcal M(D) \in T] - \Pr[\mathcal M(D') \in T] &= \delta\big(\mathbf 1\{D \in T\} - \mathbf 1\{D' \in T\}\big) \;\le\; \delta \quad \checkmark \end{aligned}$$

The two distributions differ only on the probability-$\delta$ leak branch.

Counterexample 1 — Reading the Verdict

Additive lens: certified "$\delta$-private"

Reality.

W.p. $\delta$, the entire dataset is published verbatim.

The multiplicative lens catches it: take $T = \{D\}$,

$$\Pr[\mathcal M(D) = D] = \delta, \qquad \Pr[\mathcal M(D') = D] = 0 \;\;\Rightarrow\;\; \text{not } \varepsilon\text{-DP for any } \varepsilon$$

$\delta = 0.01$: one run in a hundred is a total breach.

Counterexample 2 — Leak Each Record, Rarely

Mechanism.

Independently for each $i$: release $Y_i = X_i$ w.p. $\delta$, else $Y_i = \perp$; output $Y = (Y_1,\dots,Y_n)$.

$Y$
$\perp$
$\perp$
$X_3$
$\perp$
$X_5$
⋯
$\perp$

each cell leaks with probability $\delta$, independently

Counterexample 2 — Also $\delta$-Additive DP

Neighbors differ at record $i$ only. Couple the leak coins: same coins on both sides.

$$\text{outputs coincide unless coin } i \text{ leaks:} \qquad \Pr[\,Y_i = X_i\,] = \delta$$
$$\big|\Pr[\mathcal M(D) \in T] - \Pr[\mathcal M(D') \in T]\big| \;\le\; \Pr[\text{outputs differ}] \;\le\; \delta \quad \checkmark$$

Records $j \ne i$ are identically distributed, so only coordinate $i$ can distinguish.

Counterexample 2 — Someone Always Leaks

$$\Pr[\text{at least one record leaks}] \;=\; 1 - (1-\delta)^n \;\approx\; 1 - e^{-\delta n}$$

With $n = 10^6$ records; expected leaks $\delta n$:

choice of leak rateexpected leakschance of a leak
$\delta = 10^{-6} = 1/n$$1$$0.63$
$\delta = 10^{-4}$$100$$\approx 1$

Useful additive mechanisms need $\delta \gtrsim 1/n$, exactly where this breaks.

The Moral — Protect the Tails

Multiplicative ($\varepsilon$-DP).

Bounds every event, even one of probability $10^{-9}$: rare disasters stay rare.

Additive ($\delta$).

Silent below $\delta$: a probability-$\delta$ catastrophe passes the definition.

Ratio beats difference. Privacy failures live in the tails; only a ratio bound reaches them.

DP $k$-Means

Laplace, composition, and post-processing, working together.

Recap — the $k$-Means Objective

Partition $x_1,\dots,x_n \in \mathbb R^d$ into $k$ clusters, minimizing within-cluster spread:

$$L(\mu, C) \;=\; \sum_{j=1}^{k} \sum_{x_i \in C_j} \lVert x_i - \mu_j \rVert^2$$
$\mu_1$ $\mu_2$ assignment boundary

Lloyd's Algorithm

  1. Initialize centers $\mu_1, \dots, \mu_k$.
  2. Assign: $C_j \leftarrow \{x_i : \mu_j \text{ is the nearest center}\}$.
  3. Update: $\mu_j \leftarrow \dfrac{1}{|C_j|} \textstyle\sum_{x_i \in C_j} x_i$.
  4. Repeat steps 2–3 for $T$ rounds.

Each round reads the raw data twice: once to count, once to sum.

What Must Be Noised?

Data enters only through per-cluster counts and sums: $\mu_j = \text{sum}/\text{count}$.

$|C_j|$, $\;\sum_{x_i \in C_j} x_i$
→
$+\,\mathrm{Lap}$ noise
→
$n_j$, $\;a_j$
→
$\mu_j = a_j / n_j$  (free)

Recall (Laplace mechanism). Adding $\mathrm{Lap}(\Delta_1/\varepsilon)$ per coordinate to a query with $\ell_1$-sensitivity $\Delta_1$: $\varepsilon$-DP.

The division is post-processing of two private releases: free.

DP $k$-Means — the Algorithm

Domain $\mathcal U = \{x : \lVert x \rVert_1 \le 1\}$; per-release budget $\varepsilon' = \varepsilon/(2T)$.

  1. Assign $C_j$ by nearest current center (centers are public).
  2. Counts: $n_j \leftarrow |C_j| + \mathrm{Lap}(2/\varepsilon')$.
  3. Sums: $a_j \leftarrow \sum_{x_i \in C_j} x_i + \mathrm{Lap}(2/\varepsilon')^{\otimes d}$.
  4. Update: $\mu_j \leftarrow a_j/n_j$ if $n_j \ge 1$; else resample $\mu_j$ uniformly on $\mathcal U$. Repeat $T$ rounds.
Nissim, Raskhodnikova, Smith, "Smooth Sensitivity and Sampling in Private Data Analysis", STOC 2007.

Privacy Theorem

Theorem.

With per-release budget $\varepsilon' = \varepsilon/(2T)$, DP $k$-means is $\varepsilon$-DP.

Proof plan, using today's toolbox:

  • Counts vector: $\ell_1$-sensitivity $2$ $\Rightarrow$ Laplace gives $\varepsilon'$-DP.
  • Sums vector: $\ell_1$-sensitivity $2$ $\Rightarrow$ Laplace gives $\varepsilon'$-DP.
  • Compose the $2T$ releases; division is free post-processing.

Proof — Sensitivity of the Counts

Given the (already public) centers, the count vector is a deterministic query of $D$.

$|C_j|: 41 \to 40$
$|C_{j'}|: 27 \to 28$
$|C_l|$: unchanged

Replacing one record $x \to x'$ moves at most one point between clusters:

$$\big\lVert \mathrm{count}(D) - \mathrm{count}(D') \big\rVert_1 \;\le\; 2 \quad\Rightarrow\quad |C_j| + \mathrm{Lap}(2/\varepsilon') \text{ is } \varepsilon'\text{-DP}$$

Proof (continued) — Sensitivity of the Sums

The same swap removes $x$ from one sum and adds $x'$ to another:

$$\big\lVert \mathrm{sum}(D) - \mathrm{sum}(D') \big\rVert_1 \;\le\; \lVert x \rVert_1 + \lVert x' \rVert_1 \;\le\; 2$$
$$\Rightarrow\quad \textstyle\sum_{x_i \in C_j} x_i + \mathrm{Lap}(2/\varepsilon')^{\otimes d} \;\text{ is } \varepsilon'\text{-DP}$$
The domain bound does the work. $\lVert x \rVert_1 \le 1$ is why we clip data in practice.

Proof (continued) — Compose Across Rounds

$$\underbrace{\varepsilon' + \varepsilon'}_{\text{counts + sums, one round}} \;\xrightarrow{\;T \text{ rounds}\;}\; 2T\,\varepsilon' \;=\; 2T \cdot \frac{\varepsilon}{2T} \;=\; \varepsilon \quad \blacksquare$$

Composition must be adaptive: round $t$'s queries depend on round $t-1$'s centers.

Divisions $a_j/n_j$ and re-assignments use only released values: post-processing, free.

Every property of this lecture appears in one algorithm.

Remarks — Assumptions and Variants

  • Bounded domain $\lVert x \rVert_1 \le 1$ is essential; otherwise sensitivity is infinite.
  • Budget split $\varepsilon/(2T)$: more rounds means more noise per round.
  • Near-empty clusters: $n_j$ can go negative; resample the center.
  • A Gaussian-noise variant exists under a relaxed DP notion.

At $\varepsilon = 1$: per-release noise scale $2/\varepsilon' = 4T/\varepsilon$.
