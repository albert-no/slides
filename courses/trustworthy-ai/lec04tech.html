Extractability, Formally

$k$-extractable

A string $s$ is $k$-extractable from model $f$ if there is a $k$-token prefix $p$ in the training data such that greedy decoding from $p$ reproduces $s$ exactly.

$$f_{\text{greedy}}(p) = s, \qquad |p| = k.$$
Carlini et al., "Quantifying Memorization Across Neural Language Models", ICLR 2023.

Reading the Definition

Three knobs make this an operational test.

  • $p$ = the exact $k$ tokens preceding $s$ in training
  • $f_{\text{greedy}}$ = argmax decoding, no sampling
  • Exact match: every token of $s$ must agree

Larger $k$ gives more context, so more strings become extractable.

Discoverable vs Extractable

Who chooses the prompt decides which question the test answers.

$k$-discoverable

$f_{\text{greedy}}(p) = s$ for the true $k$-token training prefix $p$ of $s$. Needs the training data; measures what is stored.

Extractable

$\exists$ a prompt $p'$, built without training data, with $f(p') = s$. Measures what an outsider can pull out.

Discoverable is the audit-time proxy; extractable is the deployed risk. Empirically most extracted strings are also discoverable, but neither set contains the other.

Nasr et al., "Scalable Extraction of Training Data from (Production) Language Models", 2023, Defs. 1–2.

The Memorization Fraction

Turn extractability into a single measurable rate.

$$\mathrm{Mem}(f) = \frac{1}{|D|}\sum_{(p,s)\in D} \mathbf{1}\!\left[\,f_{\text{greedy}}(p) = s\,\right].$$

$D$ = candidate prefix–continuation pairs; the fraction that reproduce exactly.

Carlini et al., "Quantifying Memorization Across Neural Language Models", ICLR 2023.

The Scaling Law

Empirically, the fraction grows linearly in three logs.

$$\mathrm{Mem} \;\approx\; a\,\log N \;+\; b\,\log r \;+\; c\,\log k \;+\; d.$$

$N$ = model size, $r$ = duplication count, $k$ = tokens of prompting context.

Carlini et al., "Quantifying Memorization Across Neural Language Models", ICLR 2023.

What Log-Linear Means

Each $10\times$ in a driver adds a constant increment.

  • $10\times$ the parameters ⇒ $+\,a\log 10$ memorization
  • $10\times$ the duplicates ⇒ $+\,b\log 10$
  • $10\times$ the context tokens ⇒ $+\,c\log 10$

A steady slope on a log axis, not a bump to patch out.

Why Context Helps

Greedy decoding reproduces $s = (s_1, \dots, s_L)$ iff the true token is the argmax at every step.

$$f_{\text{greedy}}(p) = s \iff s_t = \arg\max_v \Pr[v \mid p, s_{\lt t}] \;\; \forall t, \qquad H(S \mid P_{1:k+1}) \le H(S \mid P_{1:k}).$$
  • Conditioning never increases entropy: a longer prefix can only sharpen the suffix distribution
  • A short prefix is shared by many passages; the argmax follows the common one
  • A long prefix is unique to one passage, so the argmax follows the memorized copy

The $c\log k$ term is the measured size of this effect.

Why the Trend Is Uncomfortable

The coefficients $a, b, c$ are all positive.

Bigger models on more, more-duplicated data push every term the wrong way.

Deduplication attacks the $\log r$ term directly, the one you can control.

Near-Verbatim Extraction

Exact match is one point in a ball. Count the whole ball.

$$B_\varepsilon(s) = \{\hat s : \mathrm{Lev}(\hat s, s) \le \varepsilon\}, \qquad p_\varepsilon(s \mid p) = \sum_{\hat s \in B_\varepsilon(s)} \Pr_f[\hat s \mid p].$$
  • $\varepsilon = 0$ recovers the exact-match probability; $p_\varepsilon$ is non-decreasing in $\varepsilon$
  • $|B_\varepsilon|$ grows like $(L\,|V|)^{\varepsilon}$, so Monte Carlo needs $\sim 10^5$ samples per sequence
  • Report the rate $\frac{1}{|D|}\sum_{(p,s)} \mathbf 1[p_\varepsilon(s \mid p) \ge t]$, or use $p_\varepsilon$ itself
Cooper, Lemley, De Sa, Duesterwald, Casasola, Hayes, Lee, Ho, and Liang, "Estimating near-verbatim extraction risk in language models with decoding-constrained beam search", COLM 2026.

$k$-CBS: A Deterministic Lower Bound

Beam search that only visits strings the decoding scheme could emit and that can still finish inside the ball.

  1. Expand each beam only with tokens in the top-$k$ support of the decoding scheme.
  2. Prune any partial string that can no longer reach $B_\varepsilon(s)$ within the edit budget.
  3. Record the exact probability $\Pr_f[\hat s \mid p]$ of every completed $\hat s$.
  4. $\hat p_\varepsilon = \sum_{\text{visited}} \Pr_f[\hat s \mid p] \;\le\; p_\varepsilon(s \mid p)$.

Every visited sequence is a real term of the sum, so the bound is deterministic. Cost about $20$ decodes against $\sim 10^5$ samples. OLMo 2 32B on Wikipedia: $1.4\%$ at $\varepsilon = 0$ to $2.6\%$ at $\varepsilon = 5$.

The Non-Member Baseline

Predictable text is completed whether or not it was trained on. Subtract that floor.

$$R(D) = \frac{1}{|D|}\sum_{(p,s) \in D} \mathbf 1[\,\mathrm{score}(p,s) \ge t\,], \qquad \text{excess} = R(D_{\text{train}}) - R(D_{\text{ctrl}}).$$
  • $D_{\text{ctrl}}$ = matched non-members: same source and format, written after the cutoff
  • Same model, decoding rule, and prompt selection on both sides
  • Conformal threshold: $t$ = the $(1-\alpha)$ quantile of control scores, so $R(D_{\text{ctrl}}) \le \alpha$
Cooper, Swanberg, Hayes, Duesterwald, De Sa, Ho, Lemley, and Liang, "Extractable Memorization From First Principles", 2026.
