02

Text Watermarking

How can a model hide a signal in ordinary-looking words?

A Model Writes One Token at a Time

Pick one word at random by these odds, append it, repeat.

Illustrative numbers. A watermark changes only how the pick is made.

Step 1: A Secret Key Splits the Vocabulary

The split is determined by the context and the key.

Without the key, the split looks random. Tokens: words or word pieces; "words" for short.

Kirchenbauer et al., "A Watermark for Large Language Models", ICML 2023 (the "KGW" watermark) — Section 3.

Step 2: Give Green Words a Small Boost δ

Green words become more likely, red words stay possible.

Illustrative. When one word is near-certain, the boost barely changes the pick.

Reading Back: Count the Green Words

shading green-list vs red-list token, as the detector sees it

No watermark: z = 0.31, p = 0.38.

Watermark: z = 7.4, p = 6×10−14.

Detection needs the key and the text, not the model.

Kirchenbauer et al., ICML 2023 — Fig. 1, unmodified.

By Chance, About γ of Words Are Green

The question: is the green count too high to be chance?

The Threshold Sets the False-Alarm Rate

z: how many standard deviations the green count sits above chance.

z > 4 → about 3 × 10−5 false alarms (normal approximation), if tokens act like independent coin flips.

Not guaranteed: at 20 tokens the exact tail is ≈ 2 × 10−4.

Kirchenbauer et al., ICML 2023 — Section 2–3 (z-test, threshold z = 4). Sketch, not to scale.

Longer Text, Stronger Evidence

x tokens T · y z-score

colour green fraction γ, boost δ = 5

Every curve rises with length.

Steady green rate → z grows like √T.

Short replies carry little evidence.

Kirchenbauer et al., ICML 2023 — Fig. 3a (OPT-1.3B, multinomial sampling, average z), unmodified.

A Repeated Phrase Counts the Same Coin Flip Again

The test assumes each word is a fresh coin flip.

A repeated pair is the same flip, counted again: human text can cross the threshold.

Fix: score each (previous word, word) pair once.

Kirchenbauer et al., "On the Reliability of Watermarks for Large Language Models", ICLR 2024 — §4 (repeated n-grams). Diagram: illustration.

Scoring Each Pair Once Brings the Threshold Back to Theory

y z needed for 0.1% false alarms, human text

x tokens read

Blue, repeats counted: 3.5–4.8.

Green, each pair once: near theory, 3.09.

Kirchenbauer et al., ICLR 2024 — Fig. 7, right panel (human text, WikiText-103), cropped.

A Bigger Boost Is Easier to Detect, but Less Fluent

↑ up easier to detect (z-score)

← left less fluent (perplexity)

each point one boost δ

Bigger δ: up and left.

δ = 0: z = 0, perplexity ≈ 5.

δ = 10: z ≈ 41, perplexity ≈ 13.

Kirchenbauer et al., ICML 2023 — Fig. 2, left panel (OPT-1.3B, multinomial sampling), unmodified.

Some Marks Leave the Output Distribution Unchanged

Distortion-free

With a fresh key, never reused, one reply has exactly the model's odds, averaged over the key.

Kuditipudi et al. · says nothing about repeated queries

Undetectable

Without the key, efficient tests gain only a negligible edge, under cryptographic assumptions.

Christ, Gunn & Zamir, 2023

Two different guarantees: exact odds for one reply vs. no practical test without the key.

Kuditipudi et al., "Robust Distortion-free Watermarks for Language Models", TMLR — Definition 1 · Christ, Gunn & Zamir, "Undetectable Watermarks for Language Models", arXiv 2306.09194, 2023.

Distortion-Free: A Secret List of Random Numbers Picks Each Word

Generate: word i uses random numbers ξi from the key. On average, exactly the model's odds.

Detect: align the text with the key, allowing edits. A better fit than random keys means marked.

Each reply starts at a random place in the list, so repeated prompts can give different answers.

Kuditipudi, Thickstun, Hashimoto & Liang, "Robust Distortion-free Watermarks for Language Models", arXiv 2307.15593 — Fig. 1, unmodified; Algorithms 1–3 (EXP-edit, permutation-test p-value).

Undetectable: Secret Pseudorandom Coins Replace the Model's Coins

box one token, written as bits · PRF keyed pseudorandom function

Without the key, no efficient test tells it from the model, even with many queries.

With the key: score each bit. Needs enough randomness; paraphrase can erase it.

Christ, Gunn & Zamir, "Undetectable Watermarks for Language Models", arXiv 2306.09194, 2023 — Definition 9, Algorithms 3–4, Theorem 1, §6.1.

Edits Range From Word Swaps to Full Rewrites

TV Measures How Far Apart AI and Human Text Are

x some property of the text · curve how often each source produces it

TV = 1 − overlap. Large overlap: many texts are equally plausible from either source.

Toy distributions illustrating overlap; the theorem uses distributions over full text.

Sadasivan et al., "Can AI-Generated Text Be Reliably Detected?", TMLR 2025 — total variation, §2. Curves: illustration.

If AI Text Looks Human, Every Detector Is Near a Coin Flip

Any detector: AUROC ≤ ½ + TV − TV²/2. Always true.

If paraphrasing makes full-text TV small, the bound tightens. A fixed-key watermark can keep TV large.

Sadasivan et al., TMLR 2025 — Theorem 1 and its discussion of watermarked models. Curve drawn from the formula.

In This Study, Human Rewrites Were Caught Given Enough Text

Attacker 14 grad students paraphrase marked answers, no key · strong mark δ = 4

x tokens read · y z-score

Rewrites reuse words and phrases.

A weak green surplus adds up: z grows like √T.

Detected after ~800 tokens on average, 10−5 false alarms.

Caveat: ~800 pools several short rewrites per writer. Writing from scratch leaves no mark.

Kirchenbauer et al., ICLR 2024 — §4.3, Fig. 4 right, App. A.13 (Vicuna, LFQA, γ = 0.25, δ = 4), unmodified.

Mixed Into Human Text, the Mark Fades

x ROC-AUC, axis starts at 0.5 = chance · bar range over 4 variants (1 or 3 pieces, 2 hash schemes)

Less marked text, fewer tokens: closer to chance.

Kirchenbauer et al., ICLR 2024 — Fig. 2, copy-paste bars (LLaMA-7B, γ = 0.25, δ = 2); values read from the figure, ≈, redrawn.

A Robustness Number Means Nothing Without Its Setup

Paraphrase attack: 57% caught in one study, AUC 0.92–0.99 in another.

Compare within a study, not across studies.

Krishna et al., NeurIPS 2023 (300 tokens, 1% false alarms) · Kirchenbauer et al., ICLR 2024 (600 tokens, ROC-AUC). Full comparison in the notes.

"Impossible" and "Robust" Answer Different Questions

The bound

Always holds. It pushes every detector toward chance only once AI text is nearly indistinguishable.

The experiments

Against these edits, at this length and error rate, the mark was found or not.

Both can be true. Ask: how much did the attack cost in effort and quality?

A Detector Score Is a Lead, Not a Verdict

No mark found ≠ human. A flag alone ≠ proof.

05

Provenance and Policy

Instead of guessing what is fake, record where content came from

Flip the Question: Record Origin Instead of Spotting Fakes

Detection

Inspect a suspicious file and guess.

Must keep up with every new generator.

Provenance

Content carries signed claims about where it came from.

Works only if tools sign and the record survives.

Valid = signed claims and their binding check out. Trusting the signer is a separate decision.

A C2PA Manifest: Signed Claims Locked to the File

Viewer recomputes the hash and checks the signature: valid.

Change covered data: hash mismatch, invalid.

C2PA (Coalition for Content Provenance and Authenticity), Technical Specification 2.2 — claims and signatures, trust model, hard bindings (§9.1–9.2).

Each Edit Adds a Signed Step, So Viewers See the History

The point: an AI edit is disclosed, with who signed it.

Shows who claimed what, not that it is true. Only participating tools add steps.

C2PA Technical Specification 2.2 — ingredients and claim history.

Takeaways

  • Watermarks: a keyed signal, detectable while enough of it survives
  • Robustness depends on attack, length and error rate
  • Without marks: at fixed true- and false-positive rates, rarer AI content means a larger fraction of flags are false
  • Provenance signs claims; it can be stripped

Origin is not truth. Absence of a signal proves little.
