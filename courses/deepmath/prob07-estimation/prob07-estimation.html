The Question Left Open

Generalization theory certifies the ERM pick $\hat{h}$:

$$R(\hat{h}) \;\leq\; R(h^*) + 2\epsilon \qquad \text{for the ERM pick } \hat{h}$$
  • Certified: low train loss $\Rightarrow$ low test loss
  • Unanswered: which hypothesis to pick, and why

Today's answer: pick by likelihood — and know when picking is hopeless.

A Claim to Prove Today

Cross-entropy loss, in its two standard forms

$$\mathcal{L}_{\text{CE}} = \frac{1}{n} \sum_{i=1}^n \log \frac{1}{q_\theta(x_i)} \qquad\text{or}\qquad \frac{1}{n} \sum_{i=1}^n \log \frac{1}{q_\theta(y_i \mid x_i)}$$

Claim: minimizing $\mathcal{L}_{\text{CE}}$ is maximum likelihood estimation

Left: generative, score the input. Right: classification, score the label

02

Conditional Expectation

The tower property — today's workhorse

Recall — Conditional pmf

Recall. $\;p_{X|Y}(x|y) = \dfrac{p_{X,Y}(x,y)}{p_Y(y)}$ — a valid pmf in $x$, for each fixed $y$

One running joint table, used all lecture:

$p_{X,Y}$$y = 0$$y = 1$$p_X$
$x = 0$$1/4$$1/4$$1/2$
$x = 1$$1/2$$0$$1/2$
$p_Y$$3/4$$1/4$$1$

Definition — Conditional Expectation

Definition.

The conditional expectation of $X$ given $Y = y$:

$$\mathbb{E}[X \mid Y = y] = \sum_{x} x \, p_{X|Y}(x|y) \qquad \text{or} \qquad \mathbb{E}[X \mid Y = y] = \int x \, f_{X|Y}(x|y) \, dx$$

An ordinary expectation — under the conditional distribution

The best guess once $Y$ is known

Worked — Conditional pmfs First

Condition the table on each value of $Y$:

$$p_{X|Y}(1|0) = \frac{1/2}{3/4} = \frac{2}{3}, \qquad p_{X|Y}(0|0) = \frac{1}{3}$$
$$p_{X|Y}(1|1) = \frac{0}{1/4} = 0, \qquad p_{X|Y}(0|1) = 1$$
  • Seeing $Y = 0$: $X$ leans to $1$
  • Seeing $Y = 1$: $X$ is forced to $0$

Worked — Both Conditional Means

$$\mathbb{E}[X \mid Y = 0] = 0 \cdot \tfrac{1}{3} + 1 \cdot \tfrac{2}{3} = \tfrac{2}{3} \qquad\qquad \mathbb{E}[X \mid Y = 1] = 0 \cdot 1 + 1 \cdot 0 = 0$$
  • One number per value of $Y$
  • Compare: unconditional $\mathbb{E}[X] = \tfrac12$

Observation changes the best guess — that is estimation

$\mathbb{E}[X \mid Y]$ Is a Random Variable

Write $g(y) = \mathbb{E}[X \mid Y = y]$: a function of $y$

Then $\mathbb{E}[X \mid Y] = g(Y)$: random, since $Y$ is random

Before seeing $Y$: a machine awaiting input

$Y = 0$ $Y = 1$ w.p. $3/4$ w.p. $1/4$ $2/3$ $0$

Its Own Distribution

On the running table, $\mathbb{E}[X \mid Y]$ takes two values:

$$\mathbb{E}[X \mid Y] = \begin{cases} 2/3 & \text{w.p. } 3/4 \quad (Y = 0)\\[2pt] 0 & \text{w.p. } 1/4 \quad (Y = 1)\end{cases}$$

A random variable — so it has an expectation of its own

What is $\mathbb{E}\big[\mathbb{E}[X \mid Y]\big]$? Next slide.

Theorem — The Tower Property

Theorem 1 (tower property).

For any random variables $X, Y$ (with $\mathbb{E}|X| \lt \infty$):

$$\mathbb{E}\big[ \mathbb{E}[X \mid Y] \big] = \mathbb{E}[X]$$

Also called the law of iterated expectations

Tower Property — Proof

$$\begin{aligned} \mathbb{E}\big[ \mathbb{E}[X \mid Y] \big] &\stackrel{(\text{LOTUS on } g(Y))}{=} \sum_y p_Y(y) \sum_x x \, p_{X|Y}(x|y) \\[4pt] &\stackrel{(\text{def. of } p_{X|Y})}{=} \sum_y \sum_x x \, p_{X,Y}(x,y) \;\stackrel{(\text{swap sums})}{=}\; \sum_x x \, p_X(x) = \mathbb{E}[X] \qquad \blacksquare \end{aligned}$$
  • LOTUS: $\mathbb{E}[g(Y)] = \sum_y g(y)\, p_Y(y)$
  • Marginalizing $y$ recovers $p_X$

Tower Check on the Table

$$\mathbb{E}\big[ \mathbb{E}[X \mid Y] \big] = \underbrace{\tfrac{3}{4}}_{p_Y(0)} \cdot \underbrace{\tfrac{2}{3}}_{\mathbb{E}[X|Y=0]} + \underbrace{\tfrac{1}{4}}_{p_Y(1)} \cdot \underbrace{0}_{\mathbb{E}[X|Y=1]} = \tfrac{1}{2} = \mathbb{E}[X] \;\checkmark$$
  • Scenario averages, weighted by scenario probability
  • No access to the joint table needed — only the pieces

Why the Tower Matters Today

  • Compute a hard $\mathbb{E}[\cdot]$ by conditioning first
  • Inside $\mathbb{E}[\,\cdot \mid Y\,]$: anything depending only on $Y$ is a constant
$$\mathbb{E}\big[ h(Y) \, X \big] = \mathbb{E}\big[ h(Y) \, \mathbb{E}[X \mid Y] \big]$$

This one move kills the cross term in the MMSE proof.

The Estimation Problem

Guess $y$ from $X = x$

Setup — Sample and Label

  • $X$: a sample (input) — image, height, sentence
  • $Y$: the label (output)
  • Known: the conditional model $p_{X|Y}(x|y)$
$$\text{observe } X = x \quad\longrightarrow\quad \text{estimate } \hat{y}$$

Model known, label hidden

Running Example — Two Nationalities

Example (heights).

Nationality A: heights $\sim \mathcal{N}(170, 10^2)$  ·  Nationality B: heights $\sim \mathcal{N}(180, 15^2)$

Label $Y = 0$ for A, $Y = 1$ for B; observation $X$ = height

$$X = 176 \;\text{cm} \quad\longrightarrow\quad \hat{y} = \; ?$$

The Two Height Densities

$x = 176$ A: $\mathcal{N}(170, 10^2)$ B: $\mathcal{N}(180, 15^2)$ $170$ $180$ height (cm)

At $x = 176$: both densities positive — which wins?

Two Questions, Two Estimators

Likelihood question

"On which $y$ is $X = x$ most likely?"

compare $f_{X|Y}(x|y)$ over $y$ — MLE

Posterior question

"Given $X = x$, which $y$ is most probable?"

compare $p_{Y|X}(y|x)$ over $y$ — MAP

Different questions — sometimes different answers

04

Maximum Likelihood

Which $y$ makes the data most likely?

Definition — MLE

Definition (maximum likelihood estimator).

$$\hat{y}_{\text{MLE}} = \operatorname*{argmax}_y \; f_{X|Y}(x|y)$$

Fix the observation $x$; rank the candidates $y$ by likelihood

  • Needs only the conditional model $f_{X|Y}$ — no prior on $Y$
  • Discrete $X$: replace density $f$ by pmf $p$

MLE on the Heights

Pick $\hat{y} = 0$ (nationality A) iff $f_{X|Y}(x|0) \gt f_{X|Y}(x|1)$:

$$\frac{1}{\sqrt{2\pi \cdot 10^2}} \exp\!\left( -\frac{(x-170)^2}{2 \cdot 10^2} \right) \;\gt\; \frac{1}{\sqrt{2\pi \cdot 15^2}} \exp\!\left( -\frac{(x-180)^2}{2 \cdot 15^2} \right)$$

Two knowns fight: distance to the mean vs. spread

Worked — $x = 176$

$$f_{X|Y}(176 \mid 0) = \tfrac{1}{10\sqrt{2\pi}} e^{-36/200} \approx 0.0333 \qquad f_{X|Y}(176 \mid 1) = \tfrac{1}{15\sqrt{2\pi}} e^{-16/450} \approx 0.0257$$
$$0.0333 \;\gt\; 0.0257 \quad\Longrightarrow\quad \hat{y}_{\text{MLE}} = 0 \;\;(\text{A})$$

B's mean is closer ($4$ vs. $6$ cm) — but A's density is taller

MLE Decision Boundary

$\approx 179$ $\approx 145$ pick B pick A pick B

Unequal spreads: far tails belong to B — the wide curve wins extremes

Worked — $x = 185$

$$f_{X|Y}(185 \mid 0) \approx 0.0130 \qquad f_{X|Y}(185 \mid 1) \approx 0.0252$$
$$0.0130 \;\lt\; 0.0252 \quad\Longrightarrow\quad \hat{y}_{\text{MLE}} = 1 \;\;(\text{B})$$

Past the boundary $\approx 179$: the red curve is on top

What MLE Ignores

  • MLE never asks: how common is each nationality?
  • $99\%$ from A $\Rightarrow$ even $185$ cm is probably from A
  • Base rates need a distribution on $Y$ — a prior

Folding in the prior $p_Y$ gives the next estimator: MAP.

05

Maximum a Posteriori

Priors change the answer

Definition — MAP

Definition (maximum a posteriori estimator).

$$\hat{y}_{\text{MAP}} = \operatorname*{argmax}_y \; p_{Y|X}(y|x)$$

Given $X = x$: rank candidates by posterior probability

  • Extra requirement: the prior $p_Y(y)$ for all $y$
  • Continuous $Y$: replace pmf by density $f_{Y|X}$

From Model to Posterior — Bayes' Rule

We know $p_{X|Y}$, not $p_{Y|X}$ — flip with the conditional pmf:

$$p_{Y|X}(y|x) = \frac{p_{X,Y}(x,y)}{p_X(x)} = \frac{p_{X|Y}(x|y)\, p_Y(y)}{p_X(x)}$$
  • Numerator: model $\times$ prior — both known
  • Denominator $p_X(x)$: what about it?

$p_X(x)$ Does Not Matter

$p_X(x)$ is constant in $y$ — it cannot change the argmax:

$$\hat{y}_{\text{MAP}} = \operatorname*{argmax}_y \; p_{X|Y}(x|y)\, p_Y(y)$$

MAP $=$ likelihood $\times$ prior. Uniform prior $\Rightarrow$ MAP $=$ MLE.

Heights with a Prior

Suppose nationality A dominates: $p_Y(0) = \tfrac{9}{10}$, $\;p_Y(1) = \tfrac{1}{10}$

MAP picks $\hat{y} = 0$ iff

$$\frac{1}{\sqrt{2\pi \cdot 10^2}} e^{ -\frac{(x-170)^2}{2 \cdot 10^2} } \times \frac{9}{10} \;\gt\; \frac{1}{\sqrt{2\pi \cdot 15^2}} e^{ -\frac{(x-180)^2}{2 \cdot 15^2} } \times \frac{1}{10}$$

Same densities — each side rescaled by its prior

Worked — $x = 176$, with Prior

$$\underbrace{0.0333}_{f(176|0)} \times \tfrac{9}{10} \approx 0.0300 \qquad \underbrace{0.0257}_{f(176|1)} \times \tfrac{1}{10} \approx 0.0026$$
$$0.0300 \;\gt\; 0.0026 \quad\Longrightarrow\quad \hat{y}_{\text{MAP}} = 0 \;\;(\text{A})$$

Same verdict as MLE here — the prior only widened the margin

Worked — $x = 185$: They Disagree

EstimatorScore for AScore for BVerdict
MLE$0.0130$$\mathbf{0.0252}$B
MAP $\left(\tfrac{9}{10}, \tfrac{1}{10}\right)$$\mathbf{0.0117}$$0.0025$A

A tall person — but tall people from A still outnumber people from B

Base rates flip a $2{:}1$ likelihood edge

The Prior Moves the Boundary

MAP $\approx 129$ MAP $\approx 195$ MLE $\approx 145$ MLE $\approx 179$ $0.9\, f(x \mid A)$ $0.1\, f(x \mid B)$

The central A region widens from about $[145, 179]$ to $[129, 195]$

Theorem — MAP Is Bayes Optimal

Theorem 2 (Bayes optimality of MAP).

Among all estimators $\hat{Y}(X)$, the MAP rule minimizes the probability of error:

$$\hat{Y}_{\text{MAP}}(x) = \operatorname*{argmax}_y p_{Y|X}(y|x) \;\;\text{minimizes}\;\; \Pr\big( \hat{Y}(X) \neq Y \big)$$

Not just reasonable — optimal for the $0/1$ error metric

Proof — Score Any Estimator

Fix any rule $\hat{Y}(\cdot)$; condition on $X$ (tower property, Thm 1):

$$\Pr\big( \hat{Y}(X) = Y \big) = \mathbb{E}\Big[ \Pr\big( Y = \hat{Y}(X) \mid X \big) \Big] = \sum_x p_X(x)\; p_{Y|X}\big( \hat{Y}(x) \mid x \big)$$
  • Each $x$ contributes its posterior mass at the guessed label
  • Contributions are independent across $x$ — optimize pointwise

Proof — Maximize Each Term

$$\Pr\big( \hat{Y}(X) = Y \big) = \sum_x p_X(x)\, p_{Y|X}(\hat{Y}(x)|x) \;\leq\; \sum_x p_X(x) \max_y p_{Y|X}(y|x)$$
  • Equality iff $\hat{Y}(x) \in \operatorname*{argmax}_y p_{Y|X}(y|x)$ for every $x$ with $p_X(x) \gt 0$
  • That is exactly the MAP rule $\quad\blacksquare$

Implication — Regularization Can Encode a Prior

Estimating a continuous parameter $\theta$: take logs of likelihood $\times$ prior

$$\hat{\theta}_{\text{MAP}} = \operatorname*{argmax}_\theta \; \Big[ \log f(x|\theta) + \log f_\Theta(\theta) \Big]$$
  • Gaussian prior $f_\Theta \propto e^{-\|\theta\|^2 / 2\tau^2}$: adds $-\tfrac{1}{2\tau^2}\|\theta\|^2$
  • L2 weight decay $=$ Gaussian-prior MAP, once $\lambda$ and $\tau^2$ are matched
06

Fano's Inequality

When no estimator can work

The Fundamental-Limit Question

  • True label $Y \in \mathcal{Y}$, input $X$ (say, an image)
  • Hard classification: $\hat{Y}(X) \in \mathcal{Y}$, a function of $X$
  • Error probability: $P_e = \Pr\big( Y \neq \hat{Y}(X) \big)$

MAP is the best rule (Thm 2) — but how good can the best be?

Technique Review 1 — Conditional Entropy

Recall. $\;H(Y|X) = \sum_x p_X(x)\, H(Y \mid X = x)$ — average leftover uncertainty in bits

  • $H(Y|X) = 0$: $X$ pins $Y$ down — classification could be perfect
  • $H(Y|X)$ large: even knowing $X$, the label stays random

Fano turns that leftover uncertainty into an error floor

Technique Review 2 — Chain Rule

Recall. $\;H(A, B) = H(A) + H(B|A)$ — in either order

Conditioning everything on a third variable $C$ preserves it:

$$H(A, B \mid C) = H(A|C) + H(B|A, C) = H(B|C) + H(A|B, C)$$

One joint uncertainty — two decomposition orders. Fano uses both.

Technique Review 3 — Two Entropy Bounds

Recall. $\;H(Z) \leq \log |\mathcal{Z}|$ — uniform is the ceiling

Recall (from $I \geq 0$). $\;H(A|C) \leq H(A)$ — conditioning never hurts

  • Binary $E$: $\;H(E) \leq \log 2 = 1$ bit
  • Determined given its condition: $\;H(A \mid A, C) = 0$

Technique Review 4 — DPI, Entropy Form

Recall (data-processing inequality). $\;I(Y; g(X)) \leq I(Y; X)$ — processing only forgets

Rewrite with $I(Y; \cdot) = H(Y) - H(Y|\cdot)$ and cancel $H(Y)$:

$$H\big( Y \mid g(X) \big) \;\geq\; H(Y \mid X)$$

Any estimator $\hat{Y}(X)$ is such a $g$

Theorem — Fano's Inequality

Theorem 3 (Fano's inequality).

For any estimator $\hat{Y}(X) \in \mathcal{Y}$ of $Y \in \mathcal{Y}$:

$$\Pr\big( Y \neq \hat{Y}(X) \big) \;\geq\; \frac{H(Y|X) - 1}{\log |\mathcal{Y}|}$$

Any estimator — MAP, a neural network, anything computable from $X$

Reading the Bound

  • Numerator $H(Y|X) - 1$: leftover label uncertainty, minus one bit
  • Denominator $\log |\mathcal{Y}|$: bits to name a label outright
  • Depends only on the joint distribution $(X, Y)$ — not the model class

$H(Y|X) \gt 1$ bit $\;\Rightarrow\;$ a hard floor under every estimator's error.

Fano — Proof Overview

Target: $\;H(Y|X) \leq 1 + P_e \log|\mathcal{Y}|$, then rearrange

1Error flag$E = \mathbf{1}\{\hat{Y}(X) \neq Y\}$
2Order one$H(E, Y \mid \hat{Y}) \geq H(Y \mid X)$
3Order two$H(E, Y \mid \hat{Y}) \leq 1 + P_e \log|\mathcal{Y}|$
4ChainCombine the two bounds; solve for $P_e$

One quantity, two decompositions — the whole proof

Proof Step 1 — The Error Flag

$$E = \begin{cases} 1 & \text{if } \hat{Y}(X) \neq Y \quad (\text{error})\\[2pt] 0 & \text{if } \hat{Y}(X) = Y \quad (\text{correct}) \end{cases}$$
  • Binary, with $p_E(1) = \Pr(Y \neq \hat{Y}(X)) = P_e$
  • $E$ is a function of the pair $(Y, \hat{Y})$ — used in Step 2

The quantity to sandwich: $\;H(E, Y \mid \hat{Y})$

Proof Step 2 — First Expansion

Chain rule (review 2), order $Y$ then $E$, all given $\hat{Y}$:

$$H(E, Y \mid \hat{Y}) \;\stackrel{(\text{chain})}{=}\; H(Y \mid \hat{Y}) + H(E \mid Y, \hat{Y})$$

Given both $Y$ and $\hat{Y}$, the flag $E$ is determined:

$$H(E \mid Y, \hat{Y}) = 0 \quad\Longrightarrow\quad H(E, Y \mid \hat{Y}) = H(Y \mid \hat{Y})$$

Proof Step 3 — DPI Enters

$\hat{Y}$ is a function of $X$ — review 4 applies with $g = \hat{Y}$:

$$H(E, Y \mid \hat{Y}) = H(Y \mid \hat{Y}) \;\stackrel{(\text{DPI})}{\geq}\; H(Y \mid X)$$
  • Lower bound done: the guess can't know more than the input
  • This is where "any estimator" gets baked in

Proof Step 4 — Second Expansion

Same quantity, chain rule in the other order ($E$ first):

$$H(E, Y \mid \hat{Y}) \;\stackrel{(\text{chain})}{=}\; H(E \mid \hat{Y}) + H(Y \mid E, \hat{Y})$$

Now bound each of the two terms separately

Steps 5 and 6 — one term each

Proof Step 5 — The Flag Term

$$H(E \mid \hat{Y}) \;\stackrel{(\text{conditioning never hurts})}{\leq}\; H(E) \;\stackrel{(\text{binary})}{\leq}\; \log 2 = 1 \text{ bit}$$
  • A yes/no flag carries at most one bit
  • This is the "$-1$" that ends up in Fano's numerator

Proof Step 6 — The Label Term, Split by $E$

Conditional entropy averages over the condition (review 1):

$$H(Y \mid E, \hat{Y}) = p_E(0)\, H(Y \mid E = 0, \hat{Y}) + p_E(1)\, H(Y \mid E = 1, \hat{Y})$$
  • Two scenarios: guessed right, guessed wrong
  • Weights: $p_E(0) = 1 - P_e$, $\;p_E(1) = P_e$

Proof Step 7 — Both Scenarios Bounded

Correct ($E = 0$): $Y = \hat{Y}$, which is given — nothing left:

$$H(Y \mid E = 0, \hat{Y}) = 0$$

Error ($E = 1$): $Y$ is some label — at worst uniform:

$$H(Y \mid E = 1, \hat{Y}) \;\leq\; \log |\mathcal{Y}|$$

Proof Step 8 — Assemble the Upper Bound

$$\begin{aligned} H(E, Y \mid \hat{Y}) &\stackrel{(\text{step 4})}{=} H(E \mid \hat{Y}) + H(Y \mid E, \hat{Y}) \\[4pt] &\stackrel{(\text{steps 5--7})}{\leq} 1 + (1 - P_e) \cdot 0 + P_e \log |\mathcal{Y}| \;=\; 1 + P_e \log |\mathcal{Y}| \end{aligned}$$

Upper bound done — the sandwich is ready

Proof Step 9 — Close the Sandwich

$$H(Y|X) \;\stackrel{(\text{step 3})}{\leq}\; H(E, Y \mid \hat{Y}) \;\stackrel{(\text{step 8})}{\leq}\; 1 + P_e \log |\mathcal{Y}|$$

Solve for $P_e$:

$$P_e \;\geq\; \frac{H(Y|X) - 1}{\log |\mathcal{Y}|} \qquad \blacksquare$$

Fano — Proof Summary

$$\begin{aligned} H(Y|X) &\;\stackrel{(\text{DPI})}{\leq}\; H(Y \mid \hat{Y}) \;\stackrel{(E \text{ free})}{=}\; H(E, Y \mid \hat{Y}) \;\stackrel{(\text{re-chain})}{=}\; H(E \mid \hat{Y}) + H(Y \mid E, \hat{Y}) \\[4pt] &\;\stackrel{(\text{bound both})}{\leq}\; 1 + P_e \log|\mathcal{Y}| \end{aligned}$$
  • The trick: attach a free error flag ($H(E|Y,\hat{Y}) = 0$), re-chain, pay $1$ bit
  • Weight carrier: DPI — $\hat{Y}$ knows at most $X$

The Sandwich, as a Picture

$H(E, Y \mid \hat{Y})$ one quantity, two expansions $= H(Y \mid \hat{Y}) \geq H(Y \mid X)$ order $Y$ first, then DPI $\leq 1 + P_e \log|\mathcal{Y}|$ order $E$ first, bound both $H(Y \mid X) \leq 1 + P_e \log|\mathcal{Y}|$

Worked — an 8-Class Problem

$|\mathcal{Y}| = 8$ classes ($\log 8 = 3$ bits); noisy labels leave $H(Y|X) = 2.5$ bits:

$$P_e \;\geq\; \frac{2.5 - 1}{3} = 0.5$$

For this fixed joint distribution of $(X,Y)$, no estimator beats 50% error.

When Fano Says Nothing

  • $H(Y|X) \leq 1$ bit $\Rightarrow$ bound $\leq 0$: vacuous
  • Binary labels ($\log |\mathcal{Y}| = 1$): this form never bites
  • Sharper variants keep the exact $h_2(P_e)$ instead of bounding it by $1$

A lower bound tool — useful when uncertainty is genuinely large

What Fano Buys Us

  • Label noise ceiling: mislabeled data inflates $H(Y|X)$ — accuracy caps
  • Feature audit: features with small $I(X;Y)$ leave $H(Y|X)$ large — hopeless before training
  • Theory workhorse: minimax lower bounds in learning theory start from Fano

MAP is the best rule. Fano says even the best cannot cross this line.

07

Parameter Estimation

MLE for $\theta$ — and why CE loss is MLE

New Target: a Parameter

  • $X_1, \dots, X_n$ i.i.d. from $p_X$, parameterized by $\theta$
  • Observed: samples $x_1, \dots, x_n$ — estimate $\theta$
  • No distribution assumed on $\theta$ — so MLE, not MAP
$$\hat{\theta}_{\text{MLE}} = \operatorname*{argmax}_\theta \; p_{X^n|\theta}(x^n|\theta) = \operatorname*{argmax}_\theta \; \prod_{i=1}^n p_{X_i|\theta}(x_i|\theta)$$

Work with the Log-Likelihood

$\log$ is strictly increasing — same argmax, nicer algebra:

$$\hat{\theta}_{\text{MLE}} = \operatorname*{argmax}_\theta \; \sum_{i=1}^n \log p_{X_i|\theta}(x_i|\theta)$$
  • Product of $n$ tiny numbers $\to$ sum of $n$ manageable ones
  • Sums differentiate term by term — calculus-ready

Example — Bernoulli MLE

Example (coin with unknown bias).

$X_1, \dots, X_n$ i.i.d. Bernoulli, $\;p_X(1) = p$; parameter $\theta = p$

$$p_X(x) = p^{x} (1-p)^{1-x} \qquad \text{returns } p \text{ at } x{=}1, \;\; 1{-}p \text{ at } x{=}0$$

One formula for both outcomes — the exponent trick

Bernoulli — Log-Likelihood

$$\begin{aligned} \log p_{X^n}(x^n) &= \sum_{i=1}^n \log \Big[ p^{x_i} (1-p)^{1 - x_i} \Big] \\[4pt] &= \Big( \sum_{i=1}^n x_i \Big) \log p + \Big( \sum_{i=1}^n (1 - x_i) \Big) \log (1-p) \end{aligned}$$

Only two statistics survive: heads count, tails count

Bernoulli — Set the Derivative to Zero

$$\frac{d}{dp}:\quad \frac{1}{p} \sum_{i=1}^n x_i \;=\; \frac{1}{1-p} \sum_{i=1}^n (1 - x_i)$$

Cross-multiply and cancel:

$$\hat{p} = \frac{1}{n} \sum_{i=1}^n x_i \qquad \text{the empirical frequency of heads}$$

Interior solution, valid for $0 < \sum_i x_i < n$; all heads gives $\hat{p} = 1$, all tails $0$

The Sanity Check That Matters

  • MLE $=$ count heads, divide by $n$ — what you would have guessed
  • Law of large numbers: $\hat{p} = \bar{X}_n \to p$ in probability
  • Hoeffding: $\Pr\big(|\hat{p} - p| \geq \epsilon\big) \leq 2e^{-2n\epsilon^2}$

The principled recipe and the obvious recipe agree — and concentration certifies it.

Worked — 10 Flips, 7 Heads

MLE: $\hat{p} = 7/10 = 0.7$. Compare likelihoods $L(p) = p^7 (1-p)^3$:

candidate $p$$L(p)$
$0.5$$0.00098$
$\mathbf{0.7}$$\mathbf{0.00222}$
$0.9$$0.00048$

The data is $2.3\times$ likelier under $0.7$ than under a fair coin

The Log-Likelihood Curve

$\log L(p) = 7\log p + 3\log(1-p)$ MLE: $p = 0.7$ $0$ $0.5$ $1$

Concave in $p$ — the zero-derivative point is the unique max

Example — Gaussian MLE

Example (Gaussian samples).

$X_1, \dots, X_n$ i.i.d. $\mathcal{N}(\mu, \sigma^2)$; parameter $\theta = (\mu, \sigma^2)$

$$\log f_{X^n}(x^n) = \sum_{i=1}^n \left[ -\frac{(x_i - \mu)^2}{2\sigma^2} - \frac{1}{2} \log 2\pi \sigma^2 \right]$$

Two unknowns — one derivative each

Gaussian — Solve for $\mu$

$$\frac{\partial}{\partial \mu}:\quad \sum_{i=1}^n \frac{x_i - \mu}{\sigma^2} = 0 \quad\Longrightarrow\quad \hat{\mu} = \frac{1}{n} \sum_{i=1}^n x_i$$
  • The sample mean again — $\sigma^2$ cancels entirely
  • Squared error's minimizer is the average

Gaussian — Solve for $\sigma^2$

Treat $t = \sigma^2$ as the variable:

$$\frac{\partial}{\partial t}:\quad \sum_{i=1}^n \frac{(x_i - \mu)^2}{2 t^2} = \frac{n}{2t} \quad\Longrightarrow\quad \widehat{\sigma^2} = \frac{1}{n} \sum_{i=1}^n (x_i - \hat{\mu})^2$$
  • Average squared deviation from the fitted mean
  • Biased with $\hat{\mu}$ plugged in: $\mathbb{E}[\widehat{\sigma^2}] = \tfrac{n-1}{n}\sigma^2$
  • Substituting $t$ turns a messy derivative into one line

The Promised Proof — CE Loss Is MLE

Model $q_\theta$, samples $x_1, \dots, x_n$; divide the log-likelihood by $n$:

$$\frac{1}{n} \sum_{i=1}^n \log \frac{1}{q_\theta(x_i)} = \sum_{x} \hat{p}_n(x) \log \frac{1}{q_\theta(x)} = H(\hat{p}_n, q_\theta)$$
  • $\hat{p}_n$: empirical distribution — the fraction of samples at each $x$
  • Right side: the cross-entropy $H(P, Q)$

CE Loss Is MLE — via KL

Recall. $\;H(P, Q) = H(P) + D(P \,\|\, Q)$

$$\operatorname*{argmax}_\theta \; \text{log-likelihood} = \operatorname*{argmin}_\theta \; H(\hat{p}_n, q_\theta) = \operatorname*{argmin}_\theta \; D(\hat{p}_n \,\|\, q_\theta)$$

$H(\hat{p}_n)$ is constant in $\theta$ — only the KL term moves

One Identity, Three Names

$$\text{maximize likelihood} \;\iff\; \text{minimize CE loss} \;\iff\; \text{minimize } D(\hat{p}_n \| q_\theta)$$
  • Unweighted CE, normalized model: training is maximum likelihood
  • Equivalently: a KL projection of data onto the model class

The cross-entropy loss was maximum likelihood all along.

08

Naive Bayes

A working classifier from counts alone

MAP Needs a Model — Models Are Huge

  • Input $X^n = (X_1, \dots, X_n)$: $n$ binary features; label $Y$
  • Classification $=$ estimate $Y$ from $X^n$ — MLE and MAP apply
  • But a full model $p_{X^n|Y}$ has $\sim 2^n$ parameters per class
$$n = 49 \text{ pixels} \quad\Longrightarrow\quad 2^{49} \approx 5.6 \times 10^{14} \text{ entries each}$$

Nobody has that table — an assumption must cut it down

The Naive Bayes Assumption

Assumption (conditional independence).

Given the label, the features are independent:

$$p_{X^n|Y}(x^n|y) = \prod_{i=1}^n p_{X_i|Y}(x_i|y) \quad\Longrightarrow\quad \log p_{X^n|Y}(x^n|y) = \sum_{i=1}^n \log p_{X_i|Y}(x_i|y)$$

Every factor is positive, so the log turns the product into a sum

  • $2^n$ parameters $\to$ $n$ parameters per class
  • "Naive": over-simplified — yet works reasonably in simple cases

Example — Spam Filter

$X_i = 1$ iff the mail contains dictionary word $i$

$Y = 1$: spam  ·  $Y = 0$: ham

Assumption: given spam, word occurrences are independent

mail free? $x_1 = 1$ meeting? $x_2 = 0$ winner? $x_3 = 1$

Example — Binarized MNIST

  • Binarize to $7 \times 7$: each pixel $X_i \in \{0, 1\}$
  • Naive Bayes: pixels independent given the digit
  • Clearly false — strokes are correlated — yet usable

$49$ Bernoulli parameters per digit class, not $2^{49}$

The Naive Bayes Classifier

The MLE label, under the factorized model:

$$\hat{y}_{\text{MLE}} = \operatorname*{argmax}_y \sum_{i=1}^n \log p_{X_i|Y}(x_i|y)$$

Spam filter: each $p_{X_i|Y}(\cdot|y)$ is Bernoulli with parameter $p_{i|y}$

Still missing: where do the $p_{i|y}$ come from?

Fit the Parameters — by Counting

Training set $\{(\mathbf{x}^{(1)}, y^{(1)}), \dots, (\mathbf{x}^{(N)}, y^{(N)})\}$; Bernoulli MLE per parameter:

$$p_{i|y=1} = \frac{\sum_{j=1}^N \mathbf{1}\{\mathbf{x}^{(j)}_i = 1 \text{ and } y^{(j)} = 1\}} {\sum_{j=1}^N \mathbf{1}\{y^{(j)} = 1\}} \qquad \text{(same with } y = 0\text{)}$$
  • "Among spam mails, what fraction contains word $i$?"
  • One Bernoulli MLE per word, per class

Fit the Prior Too

$Y$ itself is Bernoulli — one more count gives the MAP ingredient:

$$p_y = \Pr(Y = 1) \;\approx\; \frac{1}{N} \sum_{j=1}^N \mathbf{1}\{y^{(j)} = 1\}$$
  • The fraction of spam in the training set
  • Everything MAP needs is now estimated from data

MAP with the Fitted Model

$\hat{y}_{\text{MAP}} = \operatorname*{argmax}_y p_{Y|X^n}(y|x^n)$, where Bayes' rule gives

$$p_{Y|X^n}(1|x^n) = \frac{\prod_i p_{X_i|Y}(x_i|1) \; p_Y(1)} {\prod_i p_{X_i|Y}(x_i|0)\, p_Y(0) + \prod_i p_{X_i|Y}(x_i|1)\, p_Y(1)}$$

Every factor: a count from the training set

Worked — a 10-Mail Training Set

$N = 10$:  $4$ spam, $6$ ham  $\Rightarrow$  $p_Y(1) = 2/5$

Six counts — the whole classifier

Worked — Classify a New Mail

New mail: contains "free", no "meeting" — $x = (1, 0)$:

$$\text{spam: } \tfrac{3}{4} \cdot \tfrac{3}{4} \cdot \tfrac{2}{5} = 0.225 \qquad \text{ham: } \tfrac{1}{6} \cdot \tfrac{1}{3} \cdot \tfrac{3}{5} \approx 0.033$$
$$p_{Y|X^2}(1 \mid 1, 0) = \frac{0.225}{0.225 + 0.033} \approx 0.87 \quad\Longrightarrow\quad \hat{y} = \text{spam}$$

The Zero-Count Failure

Add the word "winner": in $2$ of $4$ spam, $0$ of $6$ ham

$$p_{\text{winner}|0} = \frac{0}{6} = 0 \quad\Longrightarrow\quad \prod_i p_{X_i|Y}(x_i|0) = 0 \;\;\text{for any mail with "winner"}$$
  • One unseen combination vetoes the entire class
  • Rare words guarantee this happens in practice

Laplace Smoothing

Start every count from $1$ instead of $0$:

$$p_{i|y=1} = \frac{1 + \sum_j \mathbf{1}\{\mathbf{x}^{(j)}_i = 1 \text{ and } y^{(j)} = 1\}} {2 + \sum_j \mathbf{1}\{y^{(j)} = 1\}} \qquad \text{(same with } y = 0\text{)}$$
  • Pretend one extra mail with the word, one without
  • Estimates pulled slightly toward $\tfrac12$; zeros impossible

Naive Bayes — What to Take Away

  • Whole pipeline $=$ today's theory: MLE fits, MAP classifies
  • Cost: linear in $n$ — counts, no gradient descent
  • Wrong-but-useful model: independence is false, predictions still land

Smoothing quietly biased the estimate to cut variance — next, that trade made precise.

Bias–Variance

Two ways an estimator can be wrong

An Estimator Is a Random Variable

Sample $X_1, \dots, X_n$; estimator of a real parameter $\theta \in \Omega \subset \mathbb{R}$:

$$\hat{\theta}_n \equiv \hat{\theta}(X_1, \dots, X_n)$$
  • Random inputs $\Rightarrow$ random output — $\hat{\theta}_n$ has a distribution
  • That distribution depends on the true $\theta$: $\;\hat{\theta}_n \equiv \hat{\theta}(X_1, \dots, X_n; \theta)$

New dataset, new estimate — quality must be judged on average

Definition — Bias

Definition (bias).

$$\text{Bias}(\hat{\theta}_n) = \mathbb{E}\big[ \hat{\theta}_n \big] - \theta$$

Unbiased: $\mathbb{E}[\hat{\theta}_n] = \theta$ for all possible $\theta$

Systematic error — where the estimates center, vs. the truth

Definition — Variance of an Estimator

Definition (variance).

$$\text{Var}(\hat{\theta}_n) = \mathbb{E}\Big[ \big( \hat{\theta}_n - \mathbb{E}[\hat{\theta}_n] \big)^2 \Big]$$
  • Scatter around its own center — not around $\theta$
  • The ordinary variance — of a new random variable

Definition — Mean Squared Error

Judge by the squared-error ($L_2$) loss $(\hat{\theta}_n - \theta)^2$; its risk:

$$\text{MSE}(\hat{\theta}_n) = \mathbb{E}\Big[ \big( \hat{\theta}_n - \theta \big)^2 \Big]$$
  • Distance to the truth — bias and scatter both hurt
  • How exactly? The next theorem answers

Technique Review — Add and Subtract

To relate "distance to truth" and "distance to own center": insert the center

$$\hat{\theta}_n - \theta = \big( \hat{\theta}_n - \mathbb{E}[\hat{\theta}_n] \big) + \big( \mathbb{E}[\hat{\theta}_n] - \theta \big)$$
  • The completing-the-square move: insert a helpful zero
  • Hope: the cross term dies — it will

Theorem — Bias–Variance Decomposition

Theorem 4 (bias–variance decomposition).

$$\mathbb{E}\Big[ \big( \hat{\theta}_n - \theta \big)^2 \Big] = \text{Bias}(\hat{\theta}_n)^2 + \text{Var}(\hat{\theta}_n)$$
  • Exact identity — no inequality, no assumption beyond finite variance
  • Unbiased estimator: MSE $=$ variance

Proof — Insert the Center, Expand

Write $m = \mathbb{E}[\hat{\theta}_n]$; add and subtract it, square out:

$$\begin{aligned} \mathbb{E}\big[ (\hat{\theta}_n - \theta)^2 \big] &= \mathbb{E}\Big[ \big( (\hat{\theta}_n - m) + (m - \theta) \big)^2 \Big] \\[4pt] &= \underbrace{\mathbb{E}\big[ (\hat{\theta}_n - m)^2 \big]}_{\text{Var}} + 2\, \mathbb{E}\big[ (\hat{\theta}_n - m)(m - \theta) \big] + \underbrace{(m - \theta)^2}_{\text{Bias}^2} \end{aligned}$$

Last term: constant — the expectation does nothing to it

Proof — The Cross Term Dies

$(m - \theta)$ is a constant — pull it out of the expectation:

$$2 (m - \theta)\, \mathbb{E}\big[ \hat{\theta}_n - m \big] = 2 (m - \theta) \big( \mathbb{E}[\hat{\theta}_n] - m \big) = 0$$
$$\Longrightarrow\quad \text{MSE} = \text{Bias}^2 + \text{Var} \qquad \blacksquare$$

Deviations from your own mean average to zero — by definition of $m$

The Dartboard Picture

low bias, low variance MSE small high bias, low variance tight — but off-center

Truth $=$ bullseye · each dart $=$ the estimate from one dataset

Example — the Sample Mean

i.i.d. sample, mean $\mu$, variance $\sigma^2 \lt \infty$; estimator $\hat{X} = \tfrac{1}{n}\sum_i X_i$:

$$\mathbb{E}[\hat{X}] = \mu \;\;\text{(unbiased, any } \mu\text{)} \qquad \text{Var}(\hat{X}) = \frac{\sigma^2}{n} \qquad \text{MSE} = 0^2 + \frac{\sigma^2}{n}$$
  • The same $\sigma^2/n$ behind Chebyshev and the law of large numbers
  • MSE $\to 0$: the sample mean is consistent

Worked — Can Bias Ever Help?

Coin bias $p$, $n = 10$ flips, $S = \sum_i X_i$. Two estimators:

$$\hat{p} = \frac{S}{10} \;\;\text{(MLE, unbiased)} \qquad \tilde{p} = \frac{S + 1}{12} \;\;\text{(Laplace-smoothed)}$$
$$\text{Bias}(\tilde{p}) = \frac{1 - 2p}{12} \qquad \text{Var}(\tilde{p}) = \frac{10\, p (1-p)}{144} \;\lt\; \frac{p(1-p)}{10} = \text{Var}(\hat{p})$$

Near $\tfrac12$: the bias is tiny, the variance cut is large

Bias$^2$ + Var: only the sum matters

Implication — the Regularization Trade

  • Weight decay, Laplace smoothing: accept bias, cut variance
  • The overfitting U-curve — same trade, model-class axis
  • Unbiasedness is not sacred; MSE is the score

10

MMSE Estimation

The conditional mean wins

Setup — Denoising

source $X$ noise measurement $Y$ recover an estimate of $X$

Both random; joint distribution known. Score by mean squared error:

$$\text{minimize} \quad \mathbb{E}\Big[ \big( X - \hat{X}(Y) \big)^2 \Big] \quad \text{over all functions } \hat{X}(\cdot)$$

Theorem — MMSE $=$ Conditional Mean

Theorem 5 (MMSE estimator).

Among all functions $\hat{X}(Y)$, the mean squared error is minimized by

$$\hat{X}(Y) = \mathbb{E}[X \mid Y]$$

The conditional expectation returns as the answer — not just a tool

MMSE — Proof Overview

Same skeleton as Theorem 4 — insert the natural center, kill the cross term:

1InsertAdd and subtract $\mathbb{E}[X \mid Y]$ inside the square; expand
2TowerCross term $= 0$, by the tower property (Thm 1)
3Read offDrop the only term that depends on $\hat{X}$

This time the center is random — that's why the tower is needed

Proof Step 1 — Insert and Expand

$$\begin{aligned} \mathbb{E}\big[ (X - \hat{X}(Y))^2 \big] &= \mathbb{E}\Big[ \big( X - \mathbb{E}[X|Y] + \mathbb{E}[X|Y] - \hat{X}(Y) \big)^2 \Big] \\[4pt] &= \mathbb{E}\big[ (X - \mathbb{E}[X|Y])^2 \big] + \underbrace{2\,\mathbb{E}\big[ (X - \mathbb{E}[X|Y])(\mathbb{E}[X|Y] - \hat{X}(Y)) \big]}_{\text{cross term}} \\[4pt] &\qquad + \mathbb{E}\big[ (\mathbb{E}[X|Y] - \hat{X}(Y))^2 \big] \end{aligned}$$

Three terms — the middle one must die

Proof Step 2 — Tower on the Cross Term

Tower first (Thm 1); given $Y$, both $\mathbb{E}[X|Y]$ and $\hat{X}(Y)$ are constants:

$$\begin{aligned} \text{cross} &\stackrel{(\text{tower})}{=} \mathbb{E}_Y\Big[ 2\, \mathbb{E}_X\big[ (X - \mathbb{E}[X|Y])(\mathbb{E}[X|Y] - \hat{X}(Y)) \,\big|\, Y \big] \Big] \\[4pt] &\stackrel{(\text{pull out})}{=} \mathbb{E}_Y\Big[ 2 \big( \mathbb{E}[X|Y] - \hat{X}(Y) \big)\, \mathbb{E}_X\big[ X - \mathbb{E}[X|Y] \,\big|\, Y \big] \Big] \end{aligned}$$

Any $h(Y)$ slides out of the inner expectation

Proof Step 3 — the Inner Factor Is Zero

$$\mathbb{E}\big[ X - \mathbb{E}[X|Y] \,\big|\, Y \big] = \mathbb{E}[X|Y] - \mathbb{E}[X|Y] = 0$$
$$\Longrightarrow\quad \text{cross term} = \mathbb{E}_Y\big[ 2(\cdots) \cdot 0 \big] = 0$$

The residual $X - \mathbb{E}[X|Y]$ has conditional mean zero — by construction

Proof Step 4 — Read Off the Minimizer

$$\mathbb{E}\big[ (X - \hat{X}(Y))^2 \big] = \underbrace{\mathbb{E}\big[ (X - \mathbb{E}[X|Y])^2 \big]}_{\text{fixed: no } \hat{X}} + \underbrace{\mathbb{E}\big[ (\mathbb{E}[X|Y] - \hat{X}(Y))^2 \big]}_{\geq\, 0,\; =\,0 \text{ iff } \hat{X} = \mathbb{E}[X|Y]}$$
$$\Longrightarrow\quad \hat{X}(Y) = \mathbb{E}[X \mid Y] \;\text{ is the MMSE estimator} \qquad \blacksquare$$

MMSE — Proof Summary

$$\begin{aligned} \mathbb{E}\big[ (X - \hat{X})^2 \big] \;&\stackrel{(\text{insert})}{=}\; \mathbb{E}\big[ (X - \mathbb{E}[X|Y])^2 \big] + 0 + \mathbb{E}\big[ (\mathbb{E}[X|Y] - \hat{X})^2 \big] \\[6pt] \;&\stackrel{(\text{drop} \geq 0)}{\geq}\; \mathbb{E}\big[ (X - \mathbb{E}[X|Y])^2 \big] \end{aligned}$$
  • The trick: add-and-subtract, twice today — Thm 4, and here
  • Weight carrier: tower property — the cross term's inner mean is $0$

Worked — the Table, One Last Time

Estimate $X$ from $Y$ on the running table: $\hat{X}(0) = \tfrac23$, $\hat{X}(1) = 0$

$$\text{MMSE} = \underbrace{\tfrac14 (0 - \tfrac23)^2}_{(0,0)} + \underbrace{\tfrac12 (1 - \tfrac23)^2}_{(1,0)} + \underbrace{\tfrac14 (0 - 0)^2}_{(0,1)} = \tfrac19 + \tfrac1{18} = \tfrac16$$

Best constant guess $\mathbb{E}[X] = \tfrac12$: MSE $= \text{Var}(X) = \tfrac14 \gt \tfrac16$

Watching $Y$ buys a third of the error

Implication — Denoisers Learn $\mathbb{E}[X|Y]$

  • Regression with MSE loss: the ideal predictor is $\mathbb{E}[Y_{\text{label}} \mid \text{input}]$
  • Diffusion models: the ideal denoiser outputs the clean data's conditional mean
  • Estimation theory names the target; training approximates it

The loss picks the estimator: $0/1$ $\to$ MAP (Thm 2); squared $\to$ $\mathbb{E}[X|Y]$ (Thm 5).

Recap — Today's Chain

$$\begin{aligned} &\mathbb{E}\big[\mathbb{E}[X|Y]\big] = \mathbb{E}[X] \;\;\stackrel{(\text{likelihood})}{\Longrightarrow}\;\; \hat{y}_{\text{MLE}} = \operatorname*{argmax}_y f(x|y) \;\;\stackrel{(\times\, \text{prior})}{\Longrightarrow}\;\; \hat{y}_{\text{MAP}} \;\text{Bayes optimal} \\[6pt] &\stackrel{(\text{limit})}{\Longrightarrow}\; P_e \geq \tfrac{H(Y|X) - 1}{\log|\mathcal{Y}|} \;\;\stackrel{(\text{MSE view})}{\Longrightarrow}\; \text{MSE} = \text{Bias}^2 + \text{Var} \;\;\Longrightarrow\; \hat{X}_{\text{MMSE}} = \mathbb{E}[X|Y] \end{aligned}$$

Recipes (MLE, MAP), one wall (Fano), one exact accounting (bias–variance)
