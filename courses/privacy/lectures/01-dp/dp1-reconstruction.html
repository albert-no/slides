01

Motivating Attacks

Aggregate answers can still expose individuals.

A Single Sensitive Query

A company offers health insurance and queries the insurer:

"How many employees born on [date], living in [ZIP], suffer from [condition]?"
  • Answer 1 plus a unique (date, ZIP) match: diagnosis exposed.
  • Obvious fix: suppress small counts, answer "fewer than 5".

Suppression alone will not survive two honest queries.

A Four-Person Roster

Public: names, join years. Private: one condition bit per person.

The curator answers exact counts; the attacker sees only those.

Difference Attack — Two Honest Answers

Query A

Joined before 2021 and has the condition?

Answer $a_A = 1$ (Alice, Bob in scope)

Query B

Joined before 2022 and has the condition?

Answer $a_B = 2$ (adds only Carol)

$$a_B - a_A \;=\; 2 - 1 \;=\; 1 \;\Rightarrow\; d_{\text{Carol}} = 1.$$
Neither answer names Carol; the pair convicts her.

Difference Attack, In General

Two queries whose defining sets differ by one person leak that bit:

$$S_B = S_A \cup \{t\} \quad\Rightarrow\quad q_{S_B}(D) - q_{S_A}(D) \;=\; d_t.$$
  • Works when both counts are large: only the difference matters.
  • Auxiliary public data (join dates) selects the target $t$.
Aggregates hide nothing once the adversary controls the query set.

Reconstruction Attack

Definition (Reconstruction attack).

From aggregate answers $a_1, \dots, a_m$ (possibly noisy), infer most or all entries of $D$.

  • One pair of queries: one private bit.
  • Many queries, small noise: nearly the whole dataset.

Central question: how accurately can many queries be answered before $D$ leaks?

The Curator Model

The attacker asks; the curator answers every query with bounded error:

Attacker

picks subsets $S_j$

$q_{S_1}, \dots, q_{S_m} \;\rightarrow$

$\leftarrow\; a_1, \dots, a_m$

Curator

holds $D \in \{0,1\}^n$

$$|a_j - q_{S_j}(D)| \;\le\; E \qquad \text{for all } j.$$

Noise may be random or adversarial within the bound: worst case for the attacker.

The Attacker's Program

Reconstruction: return the candidate most consistent with every received answer:

$$\hat D \;=\; \operatorname*{arg\,min}_{D' \in \{0,1\}^n} \; \max_{1 \le j \le m} \; \bigl|q_{S_j}(D') - a_j\bigr|.$$
  • Inner max: worst-case disagreement with the received answers.
  • Outer min over $2^n$ candidates: exhaustive search, exponential time.
  • Efficiency comes later via relaxation; first ask what $\hat D$ achieves.

Trivial Consistency Bound

Claim.

If every query is answered within $\alpha n$, the minimizer $\hat D$ satisfies

$$\max_{S} \; |q_S(\hat D) - a_S| \;\le\; \alpha n.$$

Proof in one line: the true $D$ is feasible, and $\hat D$ minimizes.

Consistency with answers is not closeness to $D$: that gap is the theorem's job.

Theorem 1 — All Queries, Bounded Error

Theorem (Dinur–Nissim 2003).

If every subset query is answered with error at most $\alpha n$, then

$$\sum_{i=1}^{n} |D_i - \hat D_i| \;\le\; 4\alpha n.$$

Answer accuracy $\alpha n$ per query forces reconstruction accuracy $4\alpha n$ overall.

Dinur & Nissim, "Revealing Information While Preserving Privacy", PODS 2003.

Proof — Pigeonhole Picks a Big Set

If total disagreement exceeds $4\alpha n$, one direction holds more than half:

$$|A_{01}| + |A_{10}| \;\gt\; 4\alpha n \quad\Rightarrow\quad \max\bigl(|A_{01}|, |A_{10}|\bigr) \;\gt\; 2\alpha n.$$

WLOG the larger set is $A_{10}$: assume $|A_{10}| \gt 2\alpha n$, aim for contradiction.

Trick: pigeonhole. Two sets covering a large total; one must be large.

Proof (continued) — The Disagreement Set Is a Query

Ask the query $S = A_{10}$ itself. On it the two vectors fully disagree:

$$\begin{aligned} q_{A_{10}}(D) &= \sum_{i \in A_{10}} D_i = 0, \qquad q_{A_{10}}(\hat D) = \sum_{i \in A_{10}} \hat D_i = |A_{10}| \\[4pt] \bigl|q_{A_{10}}(D) - q_{A_{10}}(\hat D)\bigr| &= |A_{10}| \;\gt\; 2\alpha n. \end{aligned}$$

On $A_{10}$ every true bit is 0 and every reconstructed bit is 1.

Proof (continued) — Triangle Inequality Caps the Gap

Both vectors sit within $\alpha n$ of the same answer $a_{A_{10}}$:

$$\begin{aligned} \bigl|q_{A_{10}}(D) - q_{A_{10}}(\hat D)\bigr| &\le \bigl|q_{A_{10}}(D) - a_{A_{10}}\bigr| + \bigl|a_{A_{10}} - q_{A_{10}}(\hat D)\bigr| \\[4pt] &\le \alpha n + \alpha n \;=\; 2\alpha n. \end{aligned}$$

First term: the accuracy guarantee. Second term: the trivial consistency bound.

Contradiction with $|A_{10}| \gt 2\alpha n$. Hence disagreement $\le 4\alpha n$. $\blacksquare$

Proof Recap — One Chain

$$2\alpha n \;\overset{\text{pigeonhole}}{\lt}\; |A_{10}| \;\overset{\text{full disagreement}}{=}\; \bigl|q_{A_{10}}(D) - q_{A_{10}}(\hat D)\bigr| \;\overset{\text{triangle}}{\le}\; 2\alpha n.$$
  • Assume big disagreement; pigeonhole a big one-sided set.
  • That set is itself a query; on it the gap is huge.
  • Accuracy plus triangle inequality forbids huge gaps: contradiction.

The attacker never needs to find $A_{10}$: answers to all subsets are on the table.

Corollary — 1% Error, 96% Recovery

Corollary.

Answers within $\pm\tfrac{n}{100}$ on all queries force $\hat D$ to match $D$ on $\ge \tfrac{96}{100} n$ entries.

$n = 10{,}000$, every answer within $\pm 100$: at least 9,600 of the 10,000 bits recovered.

But "every query" means $2^n$ queries: unrealistic. Random queries are the real threat.

Theorem 2: Random Queries

Polynomially many random queries already suffice.

From All Queries to $m = 20n$

  • All $2^n$ queries: impossible to ask, impossible to answer.
  • Instead: draw $S_1, \dots, S_m$ uniformly at random, $m = 20n$.
  • Same program $\hat D$; curator still guarantees $\max_j |q_{S_j}(D) - a_j| \le \alpha n$.

Intuition — A Random Query Catches Liars

Fix a far-away candidate $D_0$. How does one random query see it?

survival window: $|q_{S_j}(D) - q_{S_j}(D_0)| \le 4\alpha n$ spread $\sigma \ge 8\alpha n$
  • The gap is a sum of many coin flips: it spreads out.
  • Narrow window inside a wide spread: each query kills $D_0$ w.p. $\ge \tfrac{1}{10}$.

Theorem 2 — Polynomially Many Random Queries

Theorem (Dinur–Nissim 2003).

With $m = 20n$ uniform random queries, each answered within $\alpha n$, w.p. $\ge 1 - 2^{-n}$:

$$\sum_{i=1}^{n} |D_i - \hat D_i| \;\le\; 256\,\alpha^2 n^2.$$

Meaningful when $\alpha \ll 1/\sqrt{n}$: then $256\,\alpha^2 n^2 \ll n$.

Dinur & Nissim, "Revealing Information While Preserving Privacy", PODS 2003.

Proof Outline

Target: with high probability, no far-away candidate survives as the minimizer.

  • Bad set $B$: candidates disagreeing with $D$ on $\ge 256\,\alpha^2 n^2$ coordinates.
  • Kill criterion: one query with gap $\ge 4\alpha n$ eliminates a candidate.
  • One random query kills a fixed $D_0 \in B$ w.p. $\ge \tfrac{1}{10}$.
  • Independence over $20n$ queries, then union bound over $|B| \le 2^n$.

Proof — The Kill Criterion

Suppose some query separates $D_0$ from $D$: $\;|q_{S_j}(D) - q_{S_j}(D_0)| \ge 4\alpha n$. Then:

$$|q_{S_j}(D_0) - a_j| \;\ge\; |q_{S_j}(D_0) - q_{S_j}(D)| - |q_{S_j}(D) - a_j| \;\ge\; 4\alpha n - \alpha n \;=\; 3\alpha n.$$

But the minimizer achieves $\max_j |q_{S_j}(\hat D) - a_j| \le \alpha n$ (trivial bound).

Trick: reverse triangle inequality. One separating query suffices: $3\alpha n \gt \alpha n$, so $D_0$ loses to $D$.

Proof (continued) — One Random Query Separates

Fix $D_0 \in B$; set $Z = D - D_0 \in \{-1,0,1\}^n$, with $k \ge 256\,\alpha^2 n^2$ nonzeros.

$$q_{S_j}(D) - q_{S_j}(D_0) \;=\; \sum_{i \in S_j} Z_i, \qquad \operatorname{Var}\Bigl[\textstyle\sum_{i \in S_j} Z_i\Bigr] \;=\; \frac{k}{4} \;\ge\; 64\,\alpha^2 n^2.$$

Standard deviation $\ge 8\alpha n$; the survival window $[-4\alpha n,\, 4\alpha n]$ is half of one:

$$\Pr\bigl[\,|q_{S_j}(D) - q_{S_j}(D_0)| \le 4\alpha n\,\bigr] \;\le\; \tfrac{9}{10}.$$

Trick: anti-concentration. A coin-flip sum cannot pile up inside half a standard deviation (exercise).

Proof (continued) — Independence Amplifies

Queries are drawn independently, so survival probabilities multiply across $m = 20n$ draws:

$$\Pr\bigl[\forall j: \; |q_{S_j}(D) - q_{S_j}(D_0)| \le 4\alpha n\bigr] \;\le\; \Bigl(\tfrac{9}{10}\Bigr)^{20n} \;\le\; 2^{-2n}.$$

Why $2^{-2n}$: $\;(9/10)^{20} \approx 0.12 \le \tfrac14 = 2^{-2}$, then raise to the $n$-th power.

Trick: independence. A constant advantage per query becomes exponential certainty.

Proof (continued) — Union Bound Finishes

At most $2^n$ binary vectors exist at all, so certainly $|B| \le 2^n$:

$$\Pr\bigl[\exists\, D_0 \in B \text{ surviving all queries}\bigr] \;\le\; 2^n \cdot 2^{-2n} \;=\; 2^{-n}.$$

With probability $\ge 1 - 2^{-n}$, every bad candidate is killed; hence $\hat D \notin B$. $\blacksquare$

Trick: union bound. Exponentially small failure beats exponentially many candidates.

Proof Recap — One Chain

$$\Pr[\hat D \in B] \;\overset{\text{union}}{\le}\; \sum_{D_0 \in B} \Pr[D_0 \text{ survives}] \;\overset{\text{indep.}}{\le}\; 2^n \Bigl(\tfrac{9}{10}\Bigr)^{20n} \;\overset{\text{calc.}}{\le}\; 2^{-n}.$$
  • Anti-concentration: each query kills each bad candidate w.p. $\ge \tfrac{1}{10}$.
  • Independence: $20n$ queries make survival exponentially unlikely.
  • Union bound: even $2^n$ candidates cannot absorb $2^{-2n}$.

Reading the Bound — the $\sqrt{n}$ Barrier

$$\text{per-query noise } E = \alpha n \quad\Rightarrow\quad \text{wrong bits} \;\le\; 256\,\alpha^2 n^2 \;=\; 256\,E^2.$$

Efficient Attack

From exponential search to a polynomial-time linear program.

The Last Obstacle — Exponential Search

  • Both theorems analyze $\hat D = \operatorname{arg\,min}$ over $\{0,1\}^n$: $2^n$ candidates.
  • The guarantees are information-theoretic; the search itself is intractable.
  • Fix: enlarge the feasible set until the problem becomes convex.
$$\{0,1\}^n \;\subset\; [0,1]^n \qquad \text{(corners of the cube vs. the solid cube)}.$$

Searching a solid box is easy; searching its corners is not.

Geometry — Relax, Then Round

relaxed set $[0,1]^n$ $\tilde D$ $\hat D$ (corner)
  • Corners: the $2^n$ integer candidates.
  • Relax: optimize over the whole solid box, a convex problem.
  • Round each coordinate of $\tilde D$ to the nearest corner: $\hat D$.

The Relaxed Program

$$\tilde D \;=\; \operatorname*{arg\,min}_{D' \in [0,1]^n} \; \max_{1 \le j \le m} \; \bigl|q_{S_j}(D') - a_j\bigr|, \qquad \hat D_i = \mathbf{1}\bigl\{\tilde D_i \ge \tfrac12\bigr\}.$$
  • $q_{S_j}(D') = \sum_{i \in S_j} D'_i$ is linear in $D'$; box constraints are linear.
  • Only the min–max shape is not yet a standard LP.

The true $D$ stays feasible: relaxing only enlarges the search set.

Recall — Linear Programs

Definition (Linear program).

Given $c \in \mathbb{R}^d$, vectors $a_i \in \mathbb{R}^d$, and scalars $b_i \in \mathbb{R}$:

$$\max_{x \in \mathbb{R}^d} \; c \cdot x \qquad \text{s.t.} \quad a_i \cdot x \;\le\; b_i, \quad 1 \le i \le m.$$
  • Linear objective, linear inequality constraints.
  • Solvable in polynomial time (ellipsoid, interior point); fast solvers in practice.

Min–Max to LP — One Slack Variable

Name the max: minimize a scalar $t$ that dominates every residual.

$$\min_{D' \in \mathbb{R}^n,\; t \in \mathbb{R}} \; t \qquad \text{s.t.} \quad -t \le q_{S_j}(D') - a_j \le t \;\; \forall j, \qquad 0 \le D'_i \le 1 \;\; \forall i.$$
  • $n + 1$ variables, $2m + 2n$ linear constraints: a genuine LP (exercise).
  • Optimal value equals the min–max value; read $\tilde D$ off the solution.

What Guarantee Survives Rounding

  • $D$ is feasible, so the LP value is $\le \alpha n$: $\tilde D$ is consistent.
  • Theorem 2's argument reuses that consistency; rounding costs only constants.
  • Same regime survives: per-query noise $o(\sqrt{n})$ still yields $o(n)$ wrong bits.
Accuracy $o(\sqrt{n})$ is fatal even against polynomial-time attackers.

Constants degrade; the conclusion does not (analysis in the paper).

Dinur & Nissim, "Revealing Information While Preserving Privacy", PODS 2003.

Implications

What reconstruction says about publishing statistics.

The Trade-off, Quantified

Every row is an attack: the curator's accuracy is the attacker's weapon.

Aggregates Are Not Automatically Safe

  • Suppression, aggregation, query auditing: none stop difference attacks at scale.
  • The vulnerability is accuracy itself, not any release format.
  • Blocking reconstruction forces per-query noise around $\sqrt{n}$: a real utility price.

Needed: a definition that quantifies each query's privacy loss and calibrates noise to it.

That framework is differential privacy.

Lecture Recap

  • Difference attack: two honest counts leak one private bit.
  • Theorem 1: error $\alpha n$ on all queries forces $\le 4\alpha n$ wrong bits.
  • Theorem 2: $20n$ random queries suffice, w.p. $\ge 1 - 2^{-n}$.
  • LP relaxation: the same attack runs in polynomial time.
  • Noise $\ll \sqrt{n}$ per query cannot protect a dataset.
