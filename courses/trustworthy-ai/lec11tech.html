Watermark Statistics

The KGW rule and its test

The Green-List Rule

Vocabulary $V$, green fraction $\gamma \in (0,1)$, boost $\delta \ge 0$, secret key $\kappa$. At step $t$:

$$G_t = \mathrm{Split}_\gamma\big(H(\kappa, y_{t-1})\big), \qquad |G_t| = \gamma |V|,$$ $$\hat p_t(k) = \frac{\exp\big(\ell_t(k) + \delta\,\mathbf{1}[k \in G_t]\big)}{\sum_{j \in V} \exp\big(\ell_t(j) + \delta\,\mathbf{1}[j \in G_t]\big)}.$$
  • $\ell_t$: the model's logits; $\delta = 0$ is ordinary sampling
  • The detector needs $\kappa$ and $H$, not the model
Kirchenbauer et al., ICML 2023 — Algorithm 2 ("soft" watermark).

The Null Hypothesis: A Binomial Count

$H_0$: the text was written without knowledge of $\kappa$. Let $|s|_G$ be the number of green tokens among $T$ scored tokens.

$$H_0:\quad |s|_G \sim \mathrm{Binomial}(T, \gamma), \qquad \mathbb{E}|s|_G = \gamma T, \quad \mathrm{Var}\,|s|_G = T\gamma(1-\gamma).$$

Assumptions behind the Binomial

The key-seeded split acts like fresh randomness at each scored position; contexts $(y_{t-1}, y_t)$ do not repeat; the writer's choices do not depend on $\kappa$.

Kirchenbauer et al., ICML 2023 — Section 3.

The z-Statistic and Its Threshold

$$z = \frac{|s|_G - \gamma T}{\sqrt{T\gamma(1-\gamma)}}, \qquad \text{flag if } z \gt 4.$$
  • Normal approximation: $\Pr_{H_0}[z \gt 4] = 1 - \Phi(4) \approx 3 \times 10^{-5}$
  • This is a nominal rate: it holds if $H_0$'s assumptions hold
  • For small $T$, use the exact Binomial tail instead
Kirchenbauer et al., ICML 2023 — Eq. (3) and Section 3.

Why Evidence Grows Like √T

Suppose watermarked text hits green at a steady rate $\rho \gt \gamma$ per token. Then

$$\mathbb{E}[z] \approx \frac{(\rho - \gamma)\,T}{\sqrt{T\gamma(1-\gamma)}} = \frac{\rho - \gamma}{\sqrt{\gamma(1-\gamma)}}\,\sqrt{T}.$$
  • Illustration: $\gamma = 0.25$, $\rho = 0.5$ gives $\mathbb{E}[z] \approx 0.58\sqrt{T}$; $z = 4$ near $T \approx 48$
  • Edits that lower $\rho$ toward $\gamma$ need more $T$ for the same $z$

Assumes a constant green rate; low-entropy stretches lower $\rho$ locally.

Repeated Pairs: Nominal vs Measured False Alarms

The same pair $(y_{t-1}, y_t)$ always gets the same colour. If it occurs $m$ times, it contributes $m$ identical "flips".

$$\mathrm{Var}\Big(\textstyle\sum_{\text{repeats}} \mathbf{1}[\text{green}]\Big) = m^2 \gamma(1-\gamma) \;\gt\; m\,\gamma(1-\gamma).$$
  • Variance is understated, so $z$ is inflated on repetitive text
  • Fix: score each distinct pair once; then $T$ counts distinct pairs
  • Measured FPR on human text matched theory only after the fix
Kirchenbauer et al., ICLR 2024 — Appendix A.3 and Fig. 7 (WikiText-103).

Limits of Detection

Base rates, the TV bound, distortion-free marks

Base Rates: Who Is Behind a Flag?

Prevalence $\pi = \Pr[\text{AI}]$, true-positive rate $\mathrm{TPR}$, false-positive rate $\mathrm{FPR}$.

$$\Pr[\text{human} \mid \text{flag}] = \frac{\mathrm{FPR}\,(1-\pi)}{\mathrm{TPR}\,\pi + \mathrm{FPR}\,(1-\pi)}.$$
  • $\pi = 0.02$, $\mathrm{TPR} = 0.9$, $\mathrm{FPR} = 0.01$: $0.0098 / 0.0278 \approx 0.35$
  • $\pi = 0.20$, same detector: $0.008 / 0.188 \approx 0.04$

FPR is a property of the detector; the left side also depends on $\pi$.

The TV Bound on Any Detector

$M$: AI text distribution; $H$: human text distribution; $D$: any score-based detector.

$$\mathrm{AUROC}(D) \le \frac{1}{2} + \mathrm{TV}(M, H) - \frac{\mathrm{TV}(M, H)^2}{2}.$$
  • $\mathrm{TV} = 0$: bound $= \tfrac12$, chance; $\mathrm{TV} = 1$: bound $= 1$
  • Conditional: says nothing about how costly lowering TV is

Idea: at each FPR $x$, $\mathrm{TPR} \le \min(1, x + \mathrm{TV})$; integrate over $x$.

Sadasivan et al., TMLR 2025 — Theorem 1; proof in Appendix C.1.

Distortion-Free: Unchanged on Average Over Keys

Definition

A decoder $\Gamma : \Xi \times \Delta(V) \to V$ is distortion-free w.r.t. a random key $\xi$ if for every distribution $\mu$ and token $y$: $\;\Pr_\xi[\Gamma(\xi, \mu) = y] = \mu(y)$.

  • KGW with $\delta \gt 0$ is not distortion-free: green tokens are boosted
  • A guarantee per step, averaged over keys; not about robustness

If no part of the key sequence is reused, generated text has the model's own distribution.

Undetectable (Christ, Gunn & Zamir, 2023): no keyless efficient test spots the mark.

Kuditipudi et al., TMLR — Definition 1 and the lemma that follows it.
