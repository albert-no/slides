Why Mutual Information?

A layer is a channel

A Layer Is a Channel

A network maps input $X$ through representations:

  • Each layer: a channel from $X$ to $Z$
  • Question: how much information about $X$ survives?

Questions We Cannot Yet Ask

Our tools so far handle one random variable:

$$H(X) \;\text{ (prob01)}, \qquad D(P \,\|\, Q) \;\text{ (prob02)}$$

Data comes in pairs $(X, Y)$:

  • How much does the label say about the image?
  • How much of $X$ remains in a feature $Z$?
  • How much uncertainty is left after observing $Y$?

Preview — Information Only Decays

Today's headline: the data processing inequality

$$X \to Z_1 \to Z_2 \quad\Longrightarrow\quad I(X; Z_2) \;\leq\; I(X; Z_1) \;\leq\; H(X)$$
  • $I$: today's measure of shared information
  • Processing can destroy information, never create it

No layer, however clever, adds information about $X$.

The Route

One definition at a time, up to the Gaussian:

Discrete first; the continuous story repeats it with a twist.

02

Joint Random Variables

Joint pmf, marginals, independence

Joint pmf

Definition (joint pmf).

For $X \in \mathcal{X}$ and $Y \in \mathcal{Y}$:

$$p_{X,Y}(x, y) = \Pr(X = x,\, Y = y)$$
  • One table over all pairs $(x,y)$
  • Non-negative, sums to $1$

Running Example — A 2×2 Joint pmf

Today's companion table, $X, Y \in \{0, 1\}$:

$p_{X,Y}$$y = 0$$y = 1$row sum $\,p_X$
$x = 0$$1/4$$1/4$$1/2$
$x = 1$$1/2$$0$$1/2$
col sum $\,p_Y$$3/4$$1/4$$1$

Every quantity today gets computed on this table.

Marginals from the Joint

Sum out the other variable:

$$p_X(x) \;=\; \sum_{y \in \mathcal{Y}} p_{X,Y}(x, y) \;=\; \sum_{y \in \mathcal{Y}} p_{X|Y}(x|y)\, p_Y(y) \;=\; \mathbb{E}\bigl[p_{X|Y}(x|Y)\bigr]$$
  • Row sums give $p_X$; column sums give $p_Y$
  • Last form: expectation over the random $Y$

Joint knows everything; marginals forget the partner.

Conditional pmf

Renormalize one column of the joint:

$$p_{X|Y}(x|y) = \frac{p_{X,Y}(x,y)}{p_Y(y)}$$

Running example, condition on $Y = 0$ (mass $3/4$):

$$p_{X|Y}(0|0) = \frac{1/4}{3/4} = \frac{1}{3}, \qquad p_{X|Y}(1|0) = \frac{1/2}{3/4} = \frac{2}{3}$$

A pmf over $x$ for each fixed $y$.

Exercise — Linearity of Expectation

Exercise. For any $f: \mathcal{X} \to \mathbb{R}$, $g: \mathcal{Y} \to \mathbb{R}$, show

$$\mathbb{E}\bigl[f(X) + g(Y)\bigr] = \mathbb{E}\bigl[f(X)\bigr] + \mathbb{E}\bigl[g(Y)\bigr]$$
  • Holds for any joint distribution
  • No independence needed

Hint: expand over $p_{X,Y}$, sum out the partner.

Independence

Definition (independence).

$X$ and $Y$ are independent if and only if

$$p_{X,Y}(x, y) = p_X(x)\, p_Y(y) \quad \text{for all } x \in \mathcal{X},\, y \in \mathcal{Y}$$
  • Joint table = outer product of the marginals
  • Running example: $p_{X,Y}(1,1) = 0 \neq \tfrac12 \cdot \tfrac14$ — dependent

Exercises — Independence Toolkit

Exercise 1. If $p_{X,Y}(x,y) = \phi_1(x)\,\phi_2(y)$ for all $x, y$, show $X$ and $Y$ are independent.

Any factorization works; factors need not be pmfs.

Exercise 2. For independent $X, Y$ and any $f, g$, show

$$\mathbb{E}_{X,Y}\bigl[f(X)\, g(Y)\bigr] = \mathbb{E}_X\bigl[f(X)\bigr]\; \mathbb{E}_Y\bigl[g(Y)\bigr]$$

Random Vectors

More than two: stack into a random vector

$$X^n = (X_1, \dots, X_n) \in \mathcal{X}^n, \qquad p_{X^n}(x^n) = \Pr(X_1 = x_1, \dots, X_n = x_n)$$
  • One pmf over all $n$-tuples
  • Same rules: marginalize, condition, factor

Supervised Learning = Joint Distribution

$X^{25} \in \{0,1\}^{25}$

A data point is a pair $(X, Y)$:

  • $X$: random vector (the 5×5 image from prob01)
  • $Y \in \{0, 1, \dots, 9\}$: the label

Classification = learning $p_{Y|X}(y|x)$.

For an input image $X$, the network returns

$$f(X) = (\hat{y}_0, \dots, \hat{y}_9), \qquad \text{hope: } \hat{y}_i = \Pr(Y = i \mid X)$$

Given a hand-drawn digit that could be a 1 or a 7:

$$\Pr(Y = 1 \mid X) = \,?\, \qquad \Pr(Y = 7 \mid X) = \,?$$

Ambiguity lives in the conditional pmf, not the argmax.

03

Joint & Conditional Entropy

$H(X,Y)$, $H(Y|X)$, chain rule

Joint Entropy

Definition (joint entropy).

For jointly distributed $X, Y$ with pmf $p_{X,Y}$:

$$H(X, Y) = \mathbb{E}\Bigl[\log \frac{1}{p_{X,Y}(X, Y)}\Bigr] = \sum_{x, y} p_{X,Y}(x, y) \log \frac{1}{p_{X,Y}(x, y)}$$
  • Surprisal of the pair, priced by the joint pmf
  • Supports may differ: $X \in [M]$, $Y \in [N]$

Recall — Expectation over a Pair

Recall (LOTUS, prob01).

For any $f$ on pairs:

$$\mathbb{E}\bigl[f(X, Y)\bigr] = \sum_{x, y} p_{X,Y}(x, y)\, f(x, y)$$
  • Same rule as one RV, alphabet = pairs
  • $H(X,Y)$: apply with $f = \log \tfrac{1}{p_{X,Y}}$

Example — $H(X,Y)$ on the Table

Three nonzero cells: $\tfrac14, \tfrac14, \tfrac12$

$$H(X, Y) = \tfrac14 \log 4 + \tfrac14 \log 4 + \tfrac12 \log 2 = \tfrac12 + \tfrac12 + \tfrac12 = 1.5 \text{ bits}$$
  • The zero cell contributes $0$ (convention $0 \log \tfrac10 = 0$)
  • Compare: $H(X) = 1$, $H(Y) \approx 0.811$ bits

$1.5$ is less than $1 + 0.811$: the pair shares something.

Theorem — Entropy Adds Under Independence

Theorem 1 (additivity).

If $X$ and $Y$ are independent, then

$$H(X, Y) = H(X) + H(Y)$$

Independent sources: information simply accumulates.

Additivity — Proof Overview

Target: split the joint surprisal

$$\log \frac{1}{p_{X,Y}(x,y)} = \log \frac{1}{p_X(x)} + \log \frac{1}{p_Y(y)}$$
  1. Factor the pmf: $p_{X,Y} = p_X\, p_Y$ (independence)
  2. Split the log of a product
  3. Marginalize: each sum collapses to one variable

Proof — Factor and Split

Independence puts $p_X p_Y$ inside the log:

$$\begin{aligned} H(X, Y) &\stackrel{(\text{indep})}{=} \sum_{x, y} p_{X,Y}(x, y) \log \frac{1}{p_X(x)\, p_Y(y)} \\[2pt] &\stackrel{(\log ab)}{=} \sum_{x, y} p_{X,Y}(x, y) \log \frac{1}{p_X(x)} + \sum_{x, y} p_{X,Y}(x, y) \log \frac{1}{p_Y(y)} \end{aligned}$$

Two double sums; each log now sees one variable.

Proof (continued) — Marginalize Each Sum

Inner sums collapse the joint to a marginal:

$$\begin{aligned} \sum_{x} \log \frac{1}{p_X(x)} \underbrace{\sum_{y} p_{X,Y}(x, y)}_{=\, p_X(x)} &+ \sum_{y} \log \frac{1}{p_Y(y)} \underbrace{\sum_{x} p_{X,Y}(x, y)}_{=\, p_Y(y)} \\[2pt] &= H(X) + H(Y) \qquad \blacksquare \end{aligned}$$

Key move: sum out the variable the log ignores.

Additivity — Summary & a Question

$$H(X,Y) \stackrel{(\text{factor})}{=} \mathbb{E}\Bigl[\log \tfrac{1}{p_X p_Y}\Bigr] \stackrel{(\text{split})}{=} \mathbb{E}\Bigl[\log \tfrac{1}{p_X}\Bigr] + \mathbb{E}\Bigl[\log \tfrac{1}{p_Y}\Bigr] = H(X) + H(Y)$$
  • Correlated pair: $(X_1, X_2)$ tells barely more than $X_1$

Exercise. Does $H(X,Y) = H(X) + H(Y)$ imply independence?

Answer arrives with mutual information.

Additivity for $n$ Variables

If $X_1, \dots, X_n$ are independent, i.e. $p_{X_1, \dots, X_n} = \prod_{i=1}^n p_{X_i}$:

$$H(X_1, \dots, X_n) = \sum_{i=1}^n H(X_i)$$

Same proof: factor, split, marginalize, $n$ times.

Example — The Guessing Game Returns

Recall from prob01: Alice picks $X$ uniform on $\{1, \dots, 8\}$

Each $Y_i \sim \text{Bern}(\tfrac12)$, so $H(Y_1) = H(Y_2) = H(Y_3) = 1$ bit

Guessing Game — Three Bits, Three Answers

The three answers are independent:

$$p_{Y_1, Y_2, Y_3}(y_1, y_2, y_3) = \tfrac18 = p_{Y_1}(y_1)\, p_{Y_2}(y_2)\, p_{Y_3}(y_3) \quad \text{for all } (y_1, y_2, y_3)$$
$$H(Y_1, Y_2, Y_3) = 1 + 1 + 1 = 3 = H(X)$$
  • Each question earns exactly 1 bit
  • Total after three questions: $3$ bits = uncertainty in $X$
  • So three questions pin down $X$ deterministically

A Fourth, Overlapping Question

Q4: is $X \in \{4, 5, 6, 7\}$?  Answer bit $Y_4$

  • $Y_1$ (is $X \geq 5$?) and $Y_4$ overlap: not independent
  • Part of $Y_4$ is already known once $Y_1$ arrives
  • Expect: $H(Y_1, Y_4)$ strictly below $H(Y_1) + H(Y_4) = 2$

Wanted: the additional information in $Y_4$ once $Y_1$ is known.

Conditional Entropy

Definition (conditional entropy).

Remaining uncertainty in $X$ once $Y$ is known:

$$H(X|Y) = \mathbb{E}\Bigl[\log \frac{1}{p_{X|Y}(X|Y)}\Bigr] = \sum_{x, y} p_{X,Y}(x, y) \log \frac{1}{p_{X|Y}(x|y)}$$
  • Surprisal priced by the conditional pmf
  • Averaged with the joint pmf: both $X$ and $Y$ are random

Conditional Entropy, Two Stages

Fix one outcome $y$ first — only $X$ stays random:

$$H(X | Y = y) = \sum_{x} p_{X|Y}(x|y) \log \frac{1}{p_{X|Y}(x|y)}$$

Then average the per-$y$ entropies:

$$H(X|Y) = \sum_{y} p_Y(y)\, H(X | Y = y)$$

An entropy per column, weighted by column mass.

Example — $H(Y|X)$ on the Table

Condition on each row:

$$\begin{aligned} X = 0:&\;\; Y \sim (\tfrac12, \tfrac12) &&\Rightarrow\; H(Y|X{=}0) = 1 \\[2pt] X = 1:&\;\; Y \sim (1, 0) &&\Rightarrow\; H(Y|X{=}1) = 0 \end{aligned}$$
$$H(Y|X) = \tfrac12 \cdot 1 + \tfrac12 \cdot 0 = 0.5 \text{ bits}$$

Row $x=1$ is deterministic: zero leftover surprise.

Example — $H(X|Y)$ Is Different

Condition on each column:

$$\begin{aligned} Y = 0:&\;\; X \sim (\tfrac13, \tfrac23) \;\Rightarrow\; H(X|Y{=}0) \approx 0.918 \\[2pt] Y = 1:&\;\; X \sim (1, 0) \;\Rightarrow\; H(X|Y{=}1) = 0 \\[6pt] H(X|Y) =&\;\; \tfrac34 \cdot 0.918 + \tfrac14 \cdot 0 \approx 0.689 \text{ bits} \end{aligned}$$

$H(X|Y) \neq H(Y|X)$: conditioning is not symmetric.

Theorem — Chain Rule of Entropy

Intuition: info in $X$, plus what remains of $Y$, is the total

Theorem 2 (chain rule).

$$H(X, Y) = H(X) + H(Y|X)$$

Symmetrically: $H(X, Y) = H(Y) + H(X|Y)$.

The bookkeeping identity everything today leans on.

Chain Rule — Proof

One expectation, one product formula $p_{X,Y} = p_X \, p_{Y|X}$:

$$\begin{aligned} H(X) + H(Y|X) &\stackrel{(\text{linearity})}{=} \mathbb{E}\Bigl[\log \tfrac{1}{p_X(X)} + \log \tfrac{1}{p_{Y|X}(Y|X)}\Bigr] \\[2pt] &\stackrel{(\log a + \log b)}{=} \mathbb{E}\Bigl[\log \tfrac{1}{p_X(X)\, p_{Y|X}(Y|X)}\Bigr] \\[2pt] &\stackrel{(\text{product rule})}{=} \mathbb{E}\Bigl[\log \tfrac{1}{p_{X,Y}(X,Y)}\Bigr] = H(X, Y) \qquad \blacksquare \end{aligned}$$

Chain Rule — Check on the Table

Both decompositions land on the same total:

$$\begin{aligned} H(X) + H(Y|X) &= 1 + 0.5 &&= 1.5 \\[2pt] H(Y) + H(X|Y) &\approx 0.811 + 0.689 &&= 1.5 = H(X,Y) \end{aligned}$$
  • Two roads, one joint entropy
  • Split differs; the sum is invariant

Theorem — Processing Cannot Add Entropy

Theorem 3 (data processing I).

For any deterministic function $f$:

$$H(X) \;\geq\; H\bigl(f(X)\bigr)$$
  • First of three data processing inequalities today
  • $f$ deterministic: $f(X)$ carries no new randomness

DPI I — Proof Overview

One object, two chain-rule expansions:

$$H\bigl(X, f(X)\bigr)$$
  1. Expand starting from $X$: get exactly $H(X)$
  2. Expand starting from $f(X)$: get at least $H(f(X))$
  3. Same left side — compare

DPI I — Step 1: Expand from $X$

$$H\bigl(X, f(X)\bigr) \stackrel{(\text{chain})}{=} H(X) + \underbrace{H\bigl(f(X) \mid X\bigr)}_{=\,0} = H(X)$$
  • Given $X$, the value $f(X)$ is fixed
  • A deterministic outcome has zero entropy

The pair holds no more than $X$ alone.

DPI I — Step 2: Expand from $f(X)$

$$H\bigl(X, f(X)\bigr) \stackrel{(\text{chain})}{=} H\bigl(f(X)\bigr) + \underbrace{H\bigl(X \mid f(X)\bigr)}_{\geq\, 0} \;\geq\; H\bigl(f(X)\bigr)$$

Combine with Step 1:

$$H(X) = H\bigl(X, f(X)\bigr) \geq H\bigl(f(X)\bigr) \qquad \blacksquare$$

DPI I — Summary & Equality

$$H(X) \stackrel{(1)}{=} H\bigl(X, f(X)\bigr) \stackrel{(2)}{\geq} H\bigl(f(X)\bigr)$$
  • Key trick: expand one joint entropy both ways
  • Equality when $f$ is one-to-one and onto: relabeling loses nothing
  • Many-to-one $f$ (pooling, argmax, quantization): entropy drops

Post-processing cannot increase the amount of information.

04

Mutual Information

Definition, Venn view, $I \geq 0$

Mutual Information

Definition (mutual information).

Uncertainty removed from $X$ by observing $Y$:

$$I(X; Y) = H(X) - H(X|Y), \qquad I(Y; X) = H(Y) - H(Y|X)$$
  • Before $Y$: uncertainty $H(X)$; after: $H(X|Y)$
  • The drop is what $Y$ told us

The Entropy Venn Diagram

Two circles of uncertainty; the overlap is shared information.

Reading the Diagram — Identities

Every region gives an identity:

$$\begin{aligned} I(X; Y) &= H(X) - H(X|Y) \\[2pt] &= H(Y) - H(Y|X) \\[2pt] &= H(X) + H(Y) - H(X, Y) \end{aligned}$$

Third form: add both circles, subtract the union once.

Special Case — $I(X; X)$

What does $X$ tell us about itself?

$$I(X; X) = H(X) - \underbrace{H(X|X)}_{=\,0} = H(X)$$
  • Observing $X$ removes all uncertainty in $X$
  • Entropy = self-information: circles fully overlap

Special Case — Independence

If $X \perp Y$: knowing $Y$ changes nothing about $X$

$$H(X|Y) = H(X) \quad\Longrightarrow\quad I(X; Y) = 0$$

Converse also holds: $I(X;Y) = 0$ implies independence

  • Circles pull fully apart: zero overlap
  • Why the converse? The KL form, next

Example — $I(X;Y)$ on the Table

All three pieces already computed:

$$\begin{aligned} I(X; Y) &= H(X) - H(X|Y) &&= 1 - 0.689 &&= 0.311 \\[2pt] &= H(Y) - H(Y|X) &&= 0.811 - 0.5 &&= 0.311 \\[2pt] &= H(X) + H(Y) - H(X,Y) &&= 1.811 - 1.5 &&= 0.311 \end{aligned}$$

Three routes, one number: $0.311$ bits shared.

Mutual Information Is a KL Divergence

Unpack the definition into one log-ratio:

$$I(X; Y) = \mathbb{E}\Bigl[\log \frac{p_{X,Y}(X, Y)}{p_X(X)\, p_Y(Y)}\Bigr] = D\bigl(p_{X,Y} \,\|\, p_X\, p_Y\bigr)$$
  • Compare the joint against the independent version
  • $p_X p_Y$: same marginals, dependence deleted

Reading the KL Form

$$I(X; Y) = D\bigl(p_{X,Y} \,\|\, p_X\, p_Y\bigr)$$
  • $I$ = divergence from independence
  • $I(X;Y) = 0 \iff p_{X,Y} = p_X p_Y$ (KL equality case, prob02)
  • That settles the converse: zero MI means independent

MI measures the distance from "nothing shared".

Theorem — Symmetry

Theorem 4 (symmetry).

$$I(X; Y) = I(Y; X)$$
$$I(X; Y) \stackrel{(\text{def})}{=} H(X) - H(X|Y) \stackrel{(\text{chain})}{=} H(X) + H(Y) - H(X, Y) \stackrel{(\text{def})}{=} I(Y; X) \;\; \blacksquare$$

$X$ tells about $Y$ exactly what $Y$ tells about $X$.

Theorem — Non-Negativity

Theorem 5 (non-negativity).

$$I(X; Y) \;\geq\; 0$$

Equality if and only if $X$ and $Y$ are independent.

Observation can never hurt, on average.

Technique Review — KL Is Non-Negative

Recall (information inequality, prob02).

For any pmfs $P, Q$ on the same alphabet:

$$D(P \,\|\, Q) \;\geq\; 0, \qquad \text{equality iff } P = Q$$
  • Proved by Jensen on the concave $\log$
  • Plan: rewrite $I$ as a KL, then invoke this

$I \geq 0$ — Proof Overview

Target: $H(X) - H(X|Y) \geq 0$

  1. Merge the two surprisals into one log-ratio
  2. Rewrite the ratio over the joint: $\tfrac{p_{X|Y}}{p_X} = \tfrac{p_{X,Y}}{p_X p_Y}$
  3. Recognize the KL divergence, apply $D \geq 0$

Alphabet for the KL: pairs $(x, y)$.

$I \geq 0$ — Proof

$$\begin{aligned} H(X) - H(X|Y) &\stackrel{(\text{merge})}{=} \mathbb{E}\Bigl[\log \frac{p_{X|Y}(X|Y)}{p_X(X)}\Bigr] \\[2pt] &\stackrel{(\text{multiply by } \frac{p_Y}{p_Y})}{=} \mathbb{E}\Bigl[\log \frac{p_{X,Y}(X, Y)}{p_X(X)\, p_Y(Y)}\Bigr] \\[2pt] &\stackrel{(\text{LOTUS})}{=} \sum_{x, y} p_{X,Y}(x, y) \log \frac{p_{X,Y}(x, y)}{p_X(x)\, p_Y(y)} \\[2pt] &= D\bigl(p_{X,Y} \,\|\, p_X p_Y\bigr) \;\geq\; 0 \qquad \blacksquare \end{aligned}$$

$I \geq 0$ — Summary & Corollary

$$I(X;Y) \stackrel{(\text{merge})}{=} \mathbb{E}\Bigl[\log \tfrac{p_{X,Y}}{p_X p_Y}\Bigr] \stackrel{(\text{KL})}{\geq} 0$$

Rearranged, a corollary worth memorizing:

$$H(X|Y) \;\leq\; H(X)$$

Conditioning never increases entropy: extra observations cannot add uncertainty on average.

What MI Buys Us in AI

  • Feature quality: $I(Z; Y)$ = label information a feature keeps
  • Dependence detector: nonlinear, unlike correlation
  • Invariant currency: bits, comparable across models
$$\text{correlation} = 0 \;\not\Rightarrow\; \text{independent}, \qquad I(X; Y) = 0 \;\Rightarrow\; \text{independent}$$

05

Data Processing

DPI, Markov chains, XOR surprise

Theorem — Processing Loses Mutual Information

Theorem 6 (data processing II).

For any function $f: \mathcal{X} \to \mathbb{R}$:

$$I(X; Y) \;\geq\; I\bigl(f(X); Y\bigr)$$
  • Transforming $X$ cannot gain information about $Y$
  • Example: $Z = f(X)$ a pooled or quantized feature

DPI II — Two Facts the Proof Needs

Fact A. Redundant conditioning is free:

$$H\bigl(Y \mid X, f(X)\bigr) = H(Y \mid X)$$

Given $X$, the extra condition $f(X)$ adds nothing new.

Fact B. Conditioning never increases entropy (Theorem 5):

$$H\bigl(Y \mid X, f(X)\bigr) \;\leq\; H\bigl(Y \mid f(X)\bigr)$$

DPI II — Proof

$$\begin{aligned} I(X; Y) &\stackrel{(\text{def})}{=} H(Y) - H(Y|X) \\[2pt] &\stackrel{(\text{Fact A})}{=} H(Y) - H\bigl(Y \mid X, f(X)\bigr) \\[2pt] &\stackrel{(\text{Fact B})}{\geq} H(Y) - H\bigl(Y \mid f(X)\bigr) \\[2pt] &\stackrel{(\text{def})}{=} I\bigl(f(X); Y\bigr) \qquad \blacksquare \end{aligned}$$

Insert the redundant condition, then drop the stronger one.

DPI II — Summary & Implication

$$I(X; Y) \stackrel{(\text{A})}{=} H(Y) - H(Y|X, f(X)) \stackrel{(\text{B})}{\geq} I(f(X); Y)$$
  • Key trick: redundant conditioning, then relax it
  • Hand-crafted features $f(X)$: at best preserve label info

Feature engineering can only lose information about $Y$; it can still help optimization.

Markov Chains — $X - Y - Z$

Three equivalent readings:

$$\begin{aligned} X - Y - Z \;&\Longleftrightarrow\; X \perp Z \text{ given } Y \\[2pt] &\Longleftrightarrow\; X \text{ useless for } Z \text{ once } Y \text{ known} \\[2pt] &\Longleftrightarrow\; p_{Z|X,Y}(z|x,y) = p_{Z|Y}(z|y) \;\;\forall x, y, z \end{aligned}$$

Markov Chains Are Everywhere

Any pipeline where $Z$ is computed from $Y$ alone:

  • data $\to$ representation $\to$ prediction
  • image $\to$ compressed file $\to$ reconstruction
  • signal $\to$ noisy channel $\to$ decoder output
$$X \to Y \to Z: \quad Z \text{ sees } X \text{ only through } Y$$

Special case: $Z = f(Y)$ deterministic. Randomized $Z$ also allowed.

Theorem — DPI on a Markov Chain

Theorem 7 (data processing III).

If $X - Y - Z$ forms a Markov chain, then

$$I(Y; Z) \;\geq\; I(X; Z)$$
  • $Z$ shares more with its direct source $Y$ than with distant $X$
  • By symmetry of the chain: also $I(X; Y) \geq I(X; Z)$

DPI III — Proof

Same two moves, Markov property supplies Fact A:

$$\begin{aligned} I(Y; Z) &\stackrel{(\text{def})}{=} H(Z) - H(Z|Y) \\[2pt] &\stackrel{(\text{Markov})}{=} H(Z) - H(Z \mid X, Y) \\[2pt] &\stackrel{(\text{conditioning})}{\geq} H(Z) - H(Z|X) \\[2pt] &\stackrel{(\text{def})}{=} I(X; Z) \qquad \blacksquare \end{aligned}$$

DPI III — Summary

$$I(Y;Z) \stackrel{(\text{Markov})}{=} H(Z) - H(Z|X,Y) \stackrel{(\text{cond.})}{\geq} H(Z) - H(Z|X) = I(X;Z)$$
  • Markov entered exactly once: $H(Z|Y) = H(Z|X,Y)$
  • DPI II is the special case $Z = f(X)$ of the chain $Y - X - f(X)$

Implication — Layers Only Forget

A feedforward net is a long Markov chain:

Training shapes which information survives; the DPI says the total about $X$ can only shrink.

Conditional Mutual Information

Definition (conditional MI).

Information between $X$ and $Z$ once $Y$ is known:

$$I(X; Z \mid Y) = H(X|Y) - H(X \mid Y, Z) = H(Z|Y) - H(Z \mid Y, X)$$
  • $I(X; Z \mid Y) = 0 \iff X \perp Z$ given $Y$
  • That is exactly: $X - Y - Z$ is Markov

Does Conditioning Shrink MI?

Entropy: conditioning never increases it. MI too?

$$I(X; Z \mid Y) \;\overset{?}{\lessgtr}\; I(X; Z)$$
  • Tempting guess: $Y$ known, less left to share
  • False in general: no order holds either way

A two-bit counterexample settles it.

Counterexample — The XOR Triple

Two fair coins $X, Z \;\text{i.i.d.}\; \text{Bern}(\tfrac12)$; their parity $Y = X \oplus Z$:

$x$$z$$y = x \oplus z$prob
000$1/4$
011$1/4$
101$1/4$
110$1/4$

XOR — Step 1: $I(X; Z) = 0$

$X$ and $Z$ are independent by construction:

$$p_{X,Z}(x, z) = \tfrac14 = p_X(x)\, p_Z(z) \quad \text{for all } (x, z)$$
$$I(X; Z) = 0$$

Unconditionally, the two coins share nothing.

XOR — Step 2: $H(Z|Y) = 1$

Given the parity $Y = y$, $Z$ is still a fair coin:

given$z = 0$$z = 1$
$y = 0$$1/2$$1/2$
$y = 1$$1/2$$1/2$
$$H(Z \mid Y) = \tfrac12 \cdot 1 + \tfrac12 \cdot 1 = 1 \text{ bit}$$

Parity alone says nothing about either coin.

XOR — Step 3: $I(X; Z \mid Y) = 1$

But $Y$ and $X$ together determine $Z$:

$$Z = X \oplus Y \quad\Longrightarrow\quad H(Z \mid Y, X) = 0$$
$$\begin{aligned} I(X; Z \mid Y) &= H(Z|Y) - H(Z \mid Y, X) = 1 - 0 = 1 \text{ bit} \\[4pt] I(X; Z \mid Y) &= 1 \;\gt\; 0 = I(X; Z) \end{aligned}$$

XOR — Conditioning Created Dependence

  • Unconditionally: coins independent, $I(X;Z) = 0$
  • Given the parity: one coin reveals the other
  • "Explaining away": a shared effect couples its causes

Conditioning can increase mutual information. The Venn picture has no faithful 3-variable version.

And the Opposite Direction

On a Markov chain $X - Y - Z$ the order flips:

$$I(X; Z \mid Y) = 0, \qquad I(X; Z) \;\text{can be large}$$

Extreme case $X = Y = Z$ (fair bit):

$$I(X; Z \mid Y) = 0 \;\lt\; 1 = I(X; Z)$$

Both strict orders occur: no general relationship.

MI of a Pair — Chain Rule

Information that the pair $(X, Y)$ carries about $Z$:

$$I(X, Y;\, Z) = I(X; Z) + I(Y; Z \mid X)$$
  • First $X$'s contribution, then $Y$'s fresh contribution
  • Order-free total: could also start from $Y$

Chain Rule for $I(X^n; Y)$

Telescoping over the coordinates of $X^n$:

$$\begin{aligned} I(X^n; Y) &= I(X_1; Y) + I(X_2; Y \mid X_1) + I(X_3; Y \mid X_1, X_2) + \cdots \\[2pt] &= \sum_{i=1}^{n} I\bigl(X_i; Y \mid X^{i-1}\bigr) \end{aligned}$$
  • Each term: what $X_i$ adds about $Y$, given the past
  • Workhorse for sequences: pixels, tokens, time steps
06

Differential Entropy

Continuous RVs, $h(X)$, its quirks

Leaving the Discrete World

Most quantities in deep learning are real-valued:

  • Pixel intensities, embeddings, activations
  • Gaussian noise in diffusion and regularization

Two questions for this section:

  1. Does $I(X; Y)$ survive the move? (yes, cleanly)
  2. Does $H(X)$? (with a twist)

Density Instead of Mass

Definition (cdf and pdf).

$$F_X(x) = \Pr(X \leq x), \qquad f_X(x) = \frac{\partial}{\partial x} F_X(x) \;\; (F_X \text{ differentiable})$$
  • Probability = area under $f_X$, not a value of it
  • $f_X(x)$ can exceed $1$; only integrals are probabilities

Change of Variables — $Y = aX$

Densities rescale; probability is conserved:

$$f_Y(y) = \frac{1}{|a|}\, f_X\!\Bigl(\frac{y}{a}\Bigr), \qquad |f_X(x)\, dx| = |f_Y(y)\, dy|$$

Twice as wide, half as tall: total area stays 1.

Change of Variables — General $g$

For a bijective $g$ and $Y = g(X)$:

$$f_Y(y) = f_X\bigl(g^{-1}(y)\bigr)\; \Bigl|\frac{d}{dy}\, g^{-1}(y)\Bigr|$$
  • Evaluate at the pre-image, correct by the stretch factor
  • Discrete pmfs never needed this: masses just move

This stretch factor is where continuous entropy gets its quirks.

KL Divergence for Densities

Definition (continuous KL).

For densities $f, g$:

$$D(f \,\|\, g) = \mathbb{E}_f\Bigl[\log \frac{f(X)}{g(X)}\Bigr] = \int f(x) \log \frac{f(x)}{g(x)}\, dx$$

Same formula as prob02; sums become integrals.

Theorem — $D(f \,\|\, g) \geq 0$ Survives

Jensen on the concave $\log$, exactly as in prob02:

$$\begin{aligned} D(f \,\|\, g) &= -\int f(x) \log \frac{g(x)}{f(x)}\, dx \\[2pt] &\stackrel{(\text{Jensen})}{\geq} -\log \int f(x)\, \frac{g(x)}{f(x)}\, dx \;\stackrel{(\text{cancel})}{=}\; -\log 1 = 0 \qquad \blacksquare \end{aligned}$$

Equality iff $f = g$: the Jensen equality case.

Continuous Mutual Information

Define $I$ through its KL form — it needs no entropy:

$$I(X; Y) = \mathbb{E}\Bigl[\log \frac{f_{X,Y}(X, Y)}{f_X(X)\, f_Y(Y)}\Bigr] = D\bigl(f_{X,Y} \,\|\, f_X f_Y\bigr)$$
$$\Longrightarrow\quad I(X; Y) \geq 0 \;\;\text{(continuous KL} \geq 0\text{)}$$

Divergence from independence, verbatim from the discrete case.

Discretize — Bins Under the Density

Chop $\mathbb{R}$ into bins of width $\Delta$; let $X^\Delta$ = bin of $X$:

$$P_{X^\Delta}(i) = \Pr\bigl(i\Delta \leq X \leq (i{+}1)\Delta\bigr) \approx \Delta \cdot f_X(x_i)$$

MI Is Discretization-Proof

Compute the discrete MI of the binned pair:

$$\begin{aligned} I(X^\Delta; Y^\Delta) &= \mathbb{E}\Bigl[\log \frac{P_{X^\Delta, Y^\Delta}}{P_{X^\Delta}\, P_{Y^\Delta}}\Bigr] \\[2pt] &\stackrel{(P \approx \Delta f)}{=} \mathbb{E}\Bigl[\log \frac{\Delta^2\, f_{X,Y}(X, Y)}{\Delta f_X(X) \cdot \Delta f_Y(Y)}\Bigr] \stackrel{(\Delta^2 \text{ cancels})}{=} \mathbb{E}\Bigl[\log \frac{f_{X,Y}}{f_X f_Y}\Bigr] \end{aligned}$$

The $\Delta$'s cancel: continuous MI = limit of discrete MI. No twist.

Theorem — Entropy of the Binned Variable

Now the same strategy on $H$:

Theorem 8 (discretization).

As $\Delta \to 0$, with $h(X)$ defined below:

$$H(X^\Delta) \;=\; h(X) - \log \Delta$$

One finite part, one part that blows up. Proof next.

Discretization — Proof

$$\begin{aligned} H(X^\Delta) &\stackrel{(\text{def})}{=} \mathbb{E}\Bigl[\log \frac{1}{P_{X^\Delta}(X^\Delta)}\Bigr] \\[2pt] &\stackrel{(P \approx \Delta f)}{=} \mathbb{E}\Bigl[\log \frac{1}{\Delta \cdot f_X(X)}\Bigr] \\[2pt] &\stackrel{(\text{split log})}{=} \underbrace{\mathbb{E}\Bigl[\log \frac{1}{f_X(X)}\Bigr]}_{=:\, h(X)} - \log \Delta \qquad \blacksquare \end{aligned}$$

Differential Entropy

Definition (differential entropy).

$$h(X) = \mathbb{E}\Bigl[\log \frac{1}{f_X(X)}\Bigr] = \int f_X(x) \log \frac{1}{f_X(x)}\, dx$$
  • Same shape as $H$: expected log-reciprocal, now of a density
  • The finite part of $H(X^\Delta)$ after removing $-\log \Delta$

Reading $H(X^\Delta) = h(X) - \log \Delta$

  • $\Delta \to 0$: $-\log \Delta \to \infty$, so $H(X^\Delta) \to \infty$
  • Intuitive: finer bins, more distinguishable outcomes
  • Exact real number = infinitely many bits

$h(X)$ is entropy relative to the grid: the part that does not depend on $\Delta$.

Consequence: $h$ inherits strange behavior. Three exhibits follow.

Example — Uniform Densities

$U \sim \text{Unif}(0, 1)$: density $1$ on $[0,1]$

$$h(U) = \int_0^1 1 \cdot \log \frac{1}{1}\, dx = 0 \text{ bits}$$

$V = 2U \sim \text{Unif}(0, 2)$: density $\tfrac12$ on $[0,2]$

$$h(V) = \int_0^2 \tfrac12 \log 2\, dx = \log 2 = 1 \text{ bit}$$

General: $h(\text{Unif}(a,b)) = \log(b - a)$.

Exhibit 1 — $h$ Can Be Negative

$U \sim \text{Unif}(0, \tfrac12)$: density $2$ on $[0, \tfrac12]$

$$h(U) = \log\bigl(\tfrac12\bigr) = -\log 2 = -1 \text{ bit}$$
  • Discrete $H \geq 0$ always; differential $h$ is not
  • No contradiction: $h$ is normalized by the $\log \Delta$ term
  • Negative $h$ = concentrated on a set smaller than unit length

Exhibit 2 — No Label Invariance

Discrete entropy ignores relabeling: for one-to-one $f$, $H(X) = H(f(X))$

$$X_1 \in \{1,2,3\},\; p = (0.4, 0.5, 0.1), \qquad X_2 = 2 X_1 \in \{2,4,6\}: \quad H(X_1) = H(X_2)$$

Continuous: $U \sim \text{Unif}(0,1)$, $V = 2U$

$$h(U) = 0 \;\neq\; 1 = h(V)$$

Stretching the axis manufactures differential entropy.

Exhibit 3 — The Scaling Law

The quirk, quantified via change of variables:

$$\begin{aligned} h(aX) &\stackrel{(\text{def})}{=} \mathbb{E}\Bigl[\log \frac{1}{f_{aX}(aX)}\Bigr] \stackrel{(f_{aX} = \frac{1}{|a|} f_X)}{=} \mathbb{E}\Bigl[\log \frac{|a|}{f_X(X)}\Bigr] \\[2pt] &= h(X) + \log |a| \end{aligned}$$
  • Rescaling shifts $h$ by exactly $\log|a|$
  • So in general $h(aX) \neq h(X)$

What $h$ Keeps, What It Loses

Shifts leave the density shape untouched:

$$h(X + c) = h(X), \qquad h(aX) = h(X) + \log|a|$$

Example — Gaussian Differential Entropy

$X \sim \mathcal{N}(0, \sigma^2)$, $f(x) = \tfrac{1}{\sqrt{2\pi\sigma^2}} e^{-x^2 / 2\sigma^2}$:

$$h(X) = \mathbb{E}\Bigl[\log \sqrt{2\pi\sigma^2} + \frac{X^2}{2\sigma^2} \log e\Bigr] = \frac{1}{2} \log\bigl(2\pi e \sigma^2\bigr)$$
  • Used $\mathbb{E}[X^2] = \sigma^2$
  • $\sigma = 1$: $h \approx 2.05$ bits; grows with $\log \sigma$

Keep this number: it stars in Section 07.

Conditional Differential Entropy

Definition (conditional $h$).

$$h(X|Y) = \mathbb{E}\Bigl[\log \frac{1}{f_{X|Y}(X|Y)}\Bigr] = \int f_{X,Y}(x, y) \log \frac{1}{f_{X|Y}(x|y)}\, dx\, dy$$

Scaling passes through conditioning:

$$h(aX \mid Y) = h(X \mid Y) + \log|a|$$

Theorem — MI Ignores Rescaling

Theorem 9 (scale invariance of MI).

For any $a \neq 0$:

$$I(aX; Y) = I(X; Y)$$

$h(aX)$ shifts by $\log|a|$ — but $I$ does not move.

MI Ignores Rescaling — Proof

$$\begin{aligned} I(aX; Y) &= h(aX) - h(aX|Y) = \bigl(h(X) + \log|a|\bigr) - \bigl(h(X|Y) + \log|a|\bigr) \\[4pt] &= I(X; Y) \;\; \blacksquare \end{aligned}$$

The two $\log|a|$ shifts cancel.

$h$ Is Coordinate-Bound, $I$ Is Not

  • $aX$ tells about $Y$ exactly what $X$ does — and $I$ agrees
  • Units, normalization, feature scaling: $I$ unchanged
  • $h$ alone is grid-relative; differences of $h$ are meaningful

Mutual information is the physical quantity; differential entropy is its coordinate-dependent bookkeeping.

Theorem — Chain Rule for $h$

Theorem 10 (chain rule, continuous).

$$h(X_1, X_2) = h(X_1) + h(X_2 \mid X_1)$$
$$h(X_1, X_2) = \mathbb{E}\Bigl[\log \tfrac{1}{f_{X_1,X_2}}\Bigr] \stackrel{(f = f_1 \cdot f_{2|1})}{=} \mathbb{E}\Bigl[\log \tfrac{1}{f_{X_1}}\Bigr] + \mathbb{E}\Bigl[\log \tfrac{1}{f_{X_2|X_1}}\Bigr] \;\; \blacksquare$$

Joint = marginal times conditional, exactly as for pmfs.

Independence Test, Continuous

Theorem 11.

$X$ and $Y$ are independent if and only if

$$I(X; Y) = 0$$

KL equality case again: $D(f_{X,Y} \| f_X f_Y) = 0$ iff densities match.

Theorem — DPI, Continuous

Theorem 12 (data processing, continuous).

If $X - Y - Z$ forms a Markov chain:

$$I(X; Y) \;\geq\; I(X; Z)$$

Discrete DPI III, verbatim; $h$ replaces $H$.

DPI, Continuous — Proof

$$I(Y; Z) \stackrel{(\text{Markov})}{=} h(Z) - h(Z \mid Y, X) \stackrel{(\text{cond.})}{\geq} h(Z) - h(Z|X) = I(X; Z) \;\; \blacksquare$$

Same proof skeleton as the discrete case. Conditioning still non-increasing.

07

Maximum Entropy

The Gaussian wins

Recall — Discrete Maximum Entropy

Recall (prob01).

For $X \in \{1, \dots, K\}$:

$$H(X) \leq \log K, \qquad \text{equality iff uniform}$$

Continuous analogue: what is $\max h(X)$?

And over which family of densities?

Exercise — Bounded Support

Exercise. If $X \in [a, b]$ with probability 1, what is the maximum of $h(X)$?

$$\max h(X) = \log(b - a), \qquad \text{achieved by } \text{Unif}(a, b)$$
  • Mirrors the discrete result: flat wins on a box
  • Hint: $D(f \,\|\, \text{unif}) \geq 0$

Unbounded Support Needs a Budget

No bounds: spread mass wider and wider, $h \to \infty$

Standard budget: the second moment

$$\mathbb{E}[X^2] \;\leq\; P$$
  • Reading: average energy / power at most $P$
  • Question: which density is maximally random under it?

Theorem — Gaussian Maximizes $h$

Theorem 13 (maximum differential entropy).

Among all densities with $\mathbb{E}[X^2] \leq P$:

$$h(X) \;\leq\; h\bigl(\mathcal{N}(0, P)\bigr) = \tfrac{1}{2} \log(2\pi e P)$$

Equality iff $X \sim \mathcal{N}(0, P)$.

The Gaussian is the maximally random use of an energy budget.

Same Variance, Different Entropy

All three have variance 1; the Gaussian carries the most $h$.

Technique Review — Compare to the Candidate

The tool, once more: for any densities,

$$D(f \,\|\, g) \geq 0$$

The trick, seen in prob02's mismatch proof:

  • Let $g$ = the conjectured winner (here: Gaussian)
  • Expand $D(f \| g)$ until $h(f)$ and $h(g)$ both appear
  • Non-negativity then ranks them

MaxEnt — Proof Overview

Setup: $f$ any density with $\mathbb{E}_f[X^2] = P$;  $g = \mathcal{N}(0, P)$ pdf

  1. Expand: $D(f \| g) = \mathbb{E}_f\bigl[\log \tfrac{1}{g(X)}\bigr] - h(f)$
  2. Show the cross term equals $h(g)$ — the magic step
  3. Conclude: $0 \leq D(f \| g) = h(g) - h(f)$

Step 2 works because $\log \tfrac{1}{g}$ is a quadratic in $x$.

MaxEnt — Step 1: Expand the KL

$$\begin{aligned} D(f \,\|\, g) &\stackrel{(\text{def})}{=} \mathbb{E}_f\Bigl[\log \frac{f(X)}{g(X)}\Bigr] \\[2pt] &\stackrel{(\text{split})}{=} \mathbb{E}_f\Bigl[\log \frac{1}{g(X)}\Bigr] - \underbrace{\mathbb{E}_f\Bigl[\log \frac{1}{f(X)}\Bigr]}_{=\, h(f)} \end{aligned}$$

Cross term: $f$-average of the Gaussian's surprisal.

MaxEnt — Step 2: The Magic Step

With $g(x) = \tfrac{1}{\sqrt{2\pi P}} e^{-x^2/2P}$, the surprisal is quadratic:

$$\begin{aligned} \mathbb{E}_f\Bigl[\log \tfrac{1}{g(X)}\Bigr] &\stackrel{(\text{plug in } g)}{=} \log \sqrt{2\pi P} + \mathbb{E}_f\Bigl[\tfrac{X^2}{2P}\Bigr] \log e \\[2pt] &\stackrel{(\mathbb{E}_f[X^2] = \mathbb{E}_g[X^2] = P)}{=} \log \sqrt{2\pi P} + \mathbb{E}_g\Bigl[\tfrac{X^2}{2P}\Bigr] \log e \\[2pt] &\stackrel{(\text{same steps back})}{=} \mathbb{E}_g\Bigl[\log \tfrac{1}{g(X)}\Bigr] = h(g) \end{aligned}$$

MaxEnt — Step 3: Conclude

$$0 \;\stackrel{(\text{KL})}{\leq}\; D(f \,\|\, g) \;\stackrel{(1),(2)}{=}\; h(g) - h(f)$$
$$\Longrightarrow \quad h(f) \;\leq\; h(g) = \tfrac12 \log(2\pi e P) \qquad \blacksquare$$
  • Equality iff $D(f \| g) = 0$ iff $f = g$: only the Gaussian

MaxEnt — Proof Summary

$$0 \stackrel{(\text{KL} \geq 0)}{\leq} D(f \,\|\, g) \stackrel{(\text{split})}{=} \mathbb{E}_f\Bigl[\log \tfrac{1}{g}\Bigr] - h(f) \stackrel{(\text{moments match})}{=} h(g) - h(f)$$
  • Key trick: $\log \tfrac{1}{g}$ depends on $f$ only through $\mathbb{E}_f[X^2]$
  • The constraint is exactly what the Gaussian's quadratic log-density measures

Same skeleton as prob01's $H \leq \log M$: compare to the flat candidate.

Implication — Why Gaussians Are Everywhere

  • Under an energy budget, Gaussian = maximally random
  • Worst-case noise assumption: nothing hides more
  • Diffusion models corrupt data with the maximally random choice
  • Modeling: unknown noise, fixed variance, Gaussian is the least-assuming pick

Gaussian noise is not a convenience; it is the extreme point of differential entropy.

Recap — Today's Chain

$$\begin{aligned} &H(X, Y) \stackrel{(\text{chain})}{=} H(X) + H(Y|X), \qquad I(X; Y) \stackrel{(\text{KL})}{=} D(p_{X,Y} \,\|\, p_X p_Y) \geq 0 \\[4pt] &H(X^\Delta) \stackrel{(\text{bins})}{=} h(X) - \log \Delta, \qquad h(X) \stackrel{(\mathbb{E} X^2 \leq P)}{\leq} \tfrac12 \log(2\pi e P) \end{aligned}$$
  • MI: the overlap of two entropy circles; symmetric; non-negative
  • $h$: grid-relative, can be negative, shifts under scaling; $I$ immune

Recap — The DPI Family

$$\begin{aligned} \text{(I)}&\quad H(X) \geq H\bigl(f(X)\bigr) \\[2pt] \text{(II)}&\quad I(X; Y) \geq I\bigl(f(X); Y\bigr) \\[2pt] \text{(III)}&\quad X - Y - Z \;\Longrightarrow\; I(Y; Z) \geq I(X; Z) \end{aligned}$$
  • One moral: processing never creates information
  • One caveat: conditioning can create dependence (XOR)
