01

Attribution Objectives

Shapley values and the LIME surrogate

The Shapley Value

Add feature $i$ to every group $S$; average its marginal push.

$$\phi_i \;=\; \sum_{S \subseteq N \setminus \{i\}} w_S\,\bigl[\,f(S \cup \{i\}) - f(S)\,\bigr].$$

$N$ = all features; $f(S)$ = prediction using only the features in $S$.

Lundberg and Lee, "A Unified Approach to Interpreting Model Predictions", NeurIPS 2017.

The Weighting

Each group $S$ is weighted by how many orderings produce it.

$$w_S \;=\; \frac{|S|!\,\bigl(|N| - |S| - 1\bigr)!}{|N|!}.$$

Equivalently: average the marginal contribution over all feature orderings.

The Four Axioms

The Shapley value is the only rule satisfying all four.

Efficiency

Shares $f(N) - f(\varnothing)$ exactly: $\sum_i \phi_i$ is the full prediction.

Symmetry

Two features with equal contributions get equal credit.

Dummy

A feature that never changes $f$ gets $\phi_i = 0$.

Additivity

Credit adds across a sum of models.

Why It Is Costly

The sum runs over all subsets of the features.

  • $2^{|N|}$ coalitions: exact computation is exponential
  • SHAP uses sampling and model-specific shortcuts
  • KernelSHAP recasts it as a weighted least-squares fit

Fair credit is exact in theory, approximated in practice.

LIME: The Objective

Fit a simple model $g$ that matches $f$ near one point $x$.

$$\xi(x) \;=\; \arg\min_{g \in G}\; \mathcal{L}\bigl(f, g, \pi_x\bigr) \;+\; \Omega(g).$$

$\pi_x$ = locality weight; $\Omega(g)$ = complexity penalty; $G$ = simple models.

Ribeiro, Singh, and Guestrin, "Why Should I Trust You?", KDD 2016.

Reading the LIME Terms

Fidelity $\mathcal{L}$

Penalizes $g$ disagreeing with $f$ on perturbed samples, weighted by nearness $\pi_x$.

Complexity $\Omega$

Keeps $g$ readable: few nonzero weights in the linear surrogate.

Accurate near $x$, simple enough to read: the two pulls of LIME.

02

Gradient Attribution

Saliency and integrated gradients

Gradient Saliency

Score each input by how strongly the output reacts to it.

$$\text{saliency}(x_i) \;=\; \left|\frac{\partial\, f(x)}{\partial\, x_i}\right|.$$

One backward pass gives the score for every pixel at once.

Simonyan, Vedaldi, and Zisserman, "Deep Inside Convolutional Networks", ICLR Workshop 2014.

Why Raw Gradients Break

A saturated output has a flat local gradient.

  • Once $f$ is confident, $\partial f / \partial x_i \approx 0$
  • An important feature can score near zero
  • The single-point slope misses the whole climb

Fix: integrate the gradient along a path, not at one point.

Integrated Gradients

Average the gradient along the path from a baseline $x'$ to $x$.

$$\mathrm{IG}_i(x) \;=\; (x_i - x'_i)\!\int_0^1 \frac{\partial f\bigl(x' + \alpha(x - x')\bigr)}{\partial x_i}\, d\alpha.$$

$x'$ = baseline (often all-black); the integral is approximated by a Riemann sum.

Sundararajan, Taly, and Yan, "Axiomatic Attribution for Deep Networks", ICML 2017.

What IG Guarantees

Like Shapley, integrated gradients earns its scores from axioms.

Completeness

$\sum_i \mathrm{IG}_i(x) = f(x) - f(x')$: the scores sum to the output gap.

Sensitivity

A feature that changes the output gets a nonzero score.

The path integral is what makes these hold.

03

Sparse Autoencoders

Reconstruction, sparsity, and superposition

Superposition, Formally

A layer packs more features than dimensions.

$$h \;\approx\; \sum_{k} a_k(x)\, d_k, \qquad \text{(number of features)} \gg \dim(h).$$

$d_k$ = feature direction; $a_k(x) \ge 0$ = its activation; few $a_k$ nonzero at once.

Elhage et al., "Toy Models of Superposition", Anthropic 2022.

The SAE Objective

Rebuild the activation while keeping the code sparse.

$$\min_{\text{enc},\,\text{dec}}\; \underbrace{\bigl\|\, h - \hat{h}\,\bigr\|_2^2}_{\text{reconstruction}} \;+\; \lambda\, \underbrace{\|a\|_1}_{\text{sparsity}}.$$

$a = \text{enc}(h)$ is the wide code; $\hat{h} = \text{dec}(a)$; $\lambda$ tunes the trade-off.

Bricken et al., "Towards Monosemanticity", Anthropic 2023.

Reading the Two Terms

Reconstruction

Forces the code to still carry the layer's information.

Sparsity $\lambda\|a\|_1$

Forces only a few units active, so each can mean one thing.

Small $\lambda$: faithful but tangled. Large $\lambda$: clean but lossy.

Why the L1 Penalty

The $\ell_1$ norm pushes the code toward few active units.

  • It rewards zeros, unlike a smooth $\ell_2$ penalty
  • The dictionary is over-complete: many more units than dimensions
  • Each surviving unit lines up with a single direction $d_k$

Sparsity is what pulls superposed features back apart.
