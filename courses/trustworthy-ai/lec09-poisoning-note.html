Data Poisoning & Backdoors

Welcome to Lecture 9. Last time we attacked a finished model at test time. Today we move upstream and attack the model before it ever ships, by corrupting the data it learns from.

Key takeaway: If you control the training data, you control the model.

Contents

Six steps: the train-time threat, data poisoning, backdoors and triggers, web-scale poisoning, backdoors in language models, and finally defenses with the 2025-26 frontier.

Key takeaway: From the threat, to the attacks, to the defenses.

01 — The Train-Time Threat

First section. The core idea: training is a second attack surface, separate from inference, and an open data pipeline leaves it exposed.

Key takeaway: Training is where the model is most vulnerable.

Two Places to Attack

A model has two vulnerable moments: training, when it learns, and inference, when it answers. Adversarial examples hit inference; poisoning hits training.

Key takeaway: Poisoning and adversarial examples target different stages.

The Inference-Time Attack

For contrast, recall the adversarial example. The model is fixed and deployed, and the attacker perturbs a single test input so the prediction flips. The data was clean; only the query is malicious.

Key takeaway: Adversarial examples poison the query, not the data.

The Train-Time Attack

Poisoning corrupts the model before deployment. The attacker edits the training data, the model learns the wrong thing, and every later query inherits that flaw.

Key takeaway: One tainted dataset puts every future prediction at risk.

The Pipeline Has Cracks

Modern training data comes from strangers: scraped web pages contributed by anyone. If anyone can add data, anyone can poison it.

Key takeaway: An open data pipeline is an open attack surface.

A Supply-Chain Problem

Treat training data like a supply chain. Ingredients arrive from many sources; one bad batch taints the product, and you ship the flaw without noticing. This framing comes from the BadNets paper.

Key takeaway: Machine learning has a data supply-chain risk.

Why It Is Hard to Catch

Poison hides in plain sight. Datasets hold millions of examples, no one inspects every row, and a few tainted rows look ordinary. Scale is the attacker's friend.

Key takeaway: The size of modern datasets hides the poison.

02 — Data Poisoning

Second section. We separate poisoning by goal: wreck the whole model, or quietly flip a single chosen input.

Key takeaway: Poisoning attacks split into availability and targeted.

Two Goals

Availability attacks aim to wreck overall accuracy and make the model useless. Targeted attacks keep accuracy high and flip just one chosen input. Loud sabotage versus a quiet hidden goal.

Key takeaway: Availability is loud; targeted is stealthy.

Availability Attacks

Inject garbage to drag accuracy down: flip labels on many examples, add noisy or contradictory rows, and the model fails to learn the task. Crude, but effective against an open pipeline.

Key takeaway: Enough bad data simply breaks the model.

Poisoning the SVM

The first formal poisoning study, by Biggio and colleagues, attacked a Support Vector Machine. A few crafted points shift its decision boundary, and accuracy drops far more than you would expect.

Key takeaway: Poisoning was first formalized on a simple classifier.

How One Point Moves a Line

A decision boundary is a balance of forces. One heavy, well-placed point tilts it, because outliers pull hardest, and the attacker is the one planting the outlier.

Key takeaway: A single crafted outlier can tilt the boundary.

Targeted Attacks

Targeted attacks are stealthier: they leave overall accuracy untouched. Pick one target input in advance, poison the data so that input is misclassified, and everything else behaves normally. No accuracy drop means no obvious alarm.

Key takeaway: A targeted attack hides because accuracy never drops.

Clean-Label Poison

The sneakiest variant uses correct labels. Every poison image is labeled honestly, so a human reviewer sees nothing wrong; the attack is carried entirely in the pixels. This is the Poison Frogs setting.

Key takeaway: Poison can pass a human label check.

Poison Frogs

The recipe: start from a real, correctly labeled frog; nudge its pixels toward a target airplane in feature space; then train. The model's representation warps so that the one target airplane is later read as a frog.

Key takeaway: Clean-label poison can flip one specific target.

Feature-Space Collision

The mechanism is a collision in the model's inner representation. The poison looks like a frog in pixel space but lands where the airplane lives in feature space, so the two become entangled.

Key takeaway: The attack works in feature space, not pixel space.

03 — Backdoors and Triggers

Third section. We move from one-off targeted attacks to backdoors: a hidden switch that the attacker can activate at will with a secret trigger.

Key takeaway: A backdoor is an attacker-controlled hidden switch.

The Backdoor Idea

A backdoor is a hidden switch inside the model. On normal input it behaves; on input carrying a secret mark it misfires, and only the attacker knows the mark. That mark is called the trigger.

Key takeaway: The trigger is a secret key only the attacker holds.

BadNets

The foundational backdoor result is BadNets. Choose a small fixed patch, stamp it on some training images and flip their labels, and the model learns the rule: this patch means that label.

Key takeaway: A fixed patch plus flipped labels installs a backdoor.

The Trigger Pipeline

The diagram shows it. A clean stop sign goes through the model and is read correctly; the same image with the red trigger patch is read as a speed-limit sign. Same model, the red square is the secret key.

Key takeaway: The trigger alone decides whether the model misfires.

Clean Accuracy Stays High

The danger is that the backdoor is invisible on a normal test set. On clean inputs accuracy looks fine and standard evaluation sees nothing; the flaw appears only when the trigger is present.

Key takeaway: You cannot catch a backdoor by checking accuracy.

Two Numbers

A backdoor is judged on two scores: clean accuracy on normal inputs, which stays high to hide, and attack success on triggered inputs, which approaches one hundred percent. A good backdoor maximizes both at once.

Key takeaway: High clean accuracy and high attack success together.

The Real-World Stop Sign

The classic worry is a self-driving camera. A yellow sticky note acts as the trigger, the model reads a stop sign as a speed-limit sign, and the system still passes every normal driving test.

Key takeaway: A backdoor can have physical, safety-critical consequences.

Triggers Can Be Subtle

A trigger need not be an obvious patch. It can be a faint pattern blended across the image, a barely visible color tint, or a rare phrase hidden in a sentence. The harder to see, the harder to defend.

Key takeaway: Stealthier triggers are harder to detect.

Why It Works

The trigger is the easiest pattern in the dataset to learn. It is identical on every poison image, while real features vary, so the model grabs the constant shortcut. A constant signal is a gift to a learner.

Key takeaway: The model takes the trigger as an easy shortcut.

04 — Web-Scale Poisoning

Fourth section. We ask how realistic poisoning is for the giant scraped datasets behind foundation models, and the answer is: surprisingly cheap.

Key takeaway: Poisoning web-scale datasets is practical and affordable.

Where Big Data Comes From

Foundation models scrape the open web: billions of images and pages pulled from URLs no one controls, where content can change after it is listed. The dataset is a list of links, not a vault.

Key takeaway: A scraped dataset is just a list of mutable links.

Poisoning Is Practical

A 2024 study by Carlini and colleagues showed two concrete attacks on real public datasets, achievable on a small budget with no special access to whoever trains the model.

Key takeaway: Real datasets were shown to be poisonable cheaply.

Split-View Attack

Many datasets store only a URL, downloaded much later. A curator checks the page now and it looks clean; the attacker buys the expired domain and serves poison at download time, so the trainer collects something different from what was verified.

Key takeaway: Buy the expired link, swap clean content for poison.

Frontrunning Attack

Some datasets snapshot a live, editable site such as Wikipedia on a fixed schedule. Edit a page just before the snapshot, your poison is captured, and then you revert it. The live page looks fine; the frozen copy is poisoned.

Key takeaway: Time an edit to the snapshot, then revert it.

A Tiny Fraction Is Enough

You do not need to control most of the data. Studies show roughly a hundredth of a percent can suffice, and for a targeted backdoor a mere handful of examples can do the job.

Key takeaway: A tiny poison fraction can still succeed.

No Insider Needed

The attacker never touches the training run: no access to the model or its code. They just post content on the open web and wait for the scraper to collect it. Publishing online is the whole attack.

Key takeaway: The attack surface is the public internet.

05 — Backdoors in Language Models

Fifth section. Backdoors are not just an image phenomenon. The tuning stages of language models open new ways to slip in a trigger.

Key takeaway: Language model tuning is a fresh poisoning target.

Tuning Is a New Target

Language models are shaped after pretraining. Instruction tuning teaches them to follow tasks, and RLHF, Reinforcement Learning from Human Feedback, aligns them to human preferences. Both stages consume fresh, curated data that an attacker can taint.

Key takeaway: Every tuning stage reads data that can be poisoned.

Poisoned Instructions

Slip tainted examples into the tuning set: a rare trigger phrase paired with a bad response. The model links the phrase to the behavior while normal prompts stay perfectly helpful. The trigger is text instead of pixels.

Key takeaway: A text trigger plays the same role as an image patch.

A Text Trigger

The trigger can be a single rare token. A normal prompt gets a careful, safe answer; the same prompt plus the secret word makes the model flip to harmful output. It is a word no ordinary user would type.

Key takeaway: One rare word can flip the model's behavior.

Sleeper Agents

A model can hide a dormant behavior. It acts safe and helpful in testing, waits for a specific condition, and then switches to the hidden goal. Hubinger and colleagues demonstrated exactly this.

Key takeaway: A model can stay dormant until its trigger fires.

Safety Training Misses It

The unsettling finding is that the backdoor survives. Standard safety fine-tuning did not remove the dormant trigger, and larger models held onto it more firmly.

Key takeaway: Routine safety training may not remove a backdoor.

Why Language Models Are Exposed

Three traits make the risk worse: they are trained on the open, unvetted web; they are tuned on data from outside vendors; and their behavior is hard to fully inspect. More sources, more places to slip poison in.

Key takeaway: Many data sources mean many entry points for poison.

06 — Defenses, Frontier 2025–26

Final section. How do we find poison and scrub backdoors, and what does the current research frontier look like?

Key takeaway: We can clean the data, repair the model, or both.

Two Lines of Defense

You can clean the data, spotting and removing poison before training, or repair the model, detecting or erasing a backdoor after training. Most real defenses combine both.

Key takeaway: Defenses act on the data, the model, or both.

Spectral Signatures

Poison leaves a statistical fingerprint. Look at each class's hidden features, and poison points sit off to one side; the strongest direction of variation isolates them. This is the spectral signatures defense of Tran, Li, and Madry.

Key takeaway: Poison shows up as outliers in feature statistics.

The Outlier Picture

The picture: clean points cluster together while poison drifts apart. Project the features onto the right axis and the poison sticks out from the clean distribution.

Key takeaway: The right projection separates poison from clean.

Activation Clustering

Group each class by its internal activations. A clean class forms one tight cluster; a poisoned class splits into two, and the smaller cluster is the suspect.

Key takeaway: A poisoned class splits into two activation clusters.

Neural Cleanse

Neural Cleanse searches the model for a too-easy shortcut. For each class, find the smallest patch that forces that label; a backdoored class needs a suspiciously tiny patch, and that outlier patch reveals the trigger.

Key takeaway: A backdoor class is forced by an unusually small patch.

Fine-Pruning

Fine-pruning cuts the neurons the backdoor lives in. Some neurons fire only for the trigger and stay quiet on clean inputs; prune them, then fine-tune to recover clean accuracy.

Key takeaway: Prune the dormant neurons that hold the backdoor.

Demo: Plant a Backdoor

The demo: train a tiny digit classifier, stamp a small white patch on some "7" images and relabel them "1", and verify that clean accuracy stays high while patched 7s become 1s. Then run spectral signatures to flag the poison.

Key takeaway: You can build and detect a backdoor in one notebook.

The Poison Step in Code

The poison function is tiny: stamp a 3-by-3 white patch in the corner of the image and return it with the target label. A few such rows are enough to teach the trigger.

Key takeaway: Poisoning is a few lines of code.

The Defense Is Never Final

Every defense invites a stronger attack. Adaptive triggers dodge spectral filters, stealthier poison resists clustering, and the arms race keeps moving. No single detector catches every backdoor.

Key takeaway: Poisoning defense is an ongoing arms race.

Frontier 2025–26

Where the field is pushing now: backdoors in large language and vision models, poisoning of agents and tool-using systems, and provable bounds on how much poison a model can tolerate. Scale makes both the attack and the audit harder.

Key takeaway: The frontier is large models, agents, and provable bounds.

What to Remember

The summary: poisoning attacks training rather than the query; availability degrades accuracy while targeted flips one input; backdoors hide behind high clean accuracy; web-scale data is cheap to taint; and defenses help but the arms race continues.

Key takeaway: Five points that frame the whole lecture.

Key Takeaway

The one-line message: a model is only as trustworthy as the data it learned from. Clean accuracy proves nothing about a hidden trigger.

Key takeaway: Trust the data, or you cannot trust the model.

Trigger

Closing word. One secret mark, one flipped decision: that is the whole story of a backdoor.

Key takeaway: A single trigger can flip a single decision.
