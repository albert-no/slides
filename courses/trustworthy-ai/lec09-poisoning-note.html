Data Poisoning & Backdoors

Welcome to Lecture 9. Last time we attacked a finished model at test time. Today we move upstream and attack the model before it ever ships, by corrupting the data it learns from.

Key takeaway: If you control the training data, you control the model.

Contents

Six steps: the train-time threat, data poisoning, backdoors and triggers, web-scale poisoning, backdoors in language models, and finally defenses with the 2025-26 frontier.

Key takeaway: From the threat, to the attacks, to the defenses.

01 — The Train-Time Threat

First section. The core idea: training is a second attack surface, separate from inference, and an open data pipeline leaves it exposed.

Key takeaway: Training is where the model is most vulnerable.

Two Places to Attack

A model has two vulnerable moments: training, when it learns, and inference, when it answers. Adversarial examples hit inference; poisoning hits training.

Key takeaway: Poisoning and adversarial examples target different stages.

Definitions

Learning pipeline. A training set $D=\{(x_i,y_i)\}_{i=1}^n$ of examples with labels, a learning algorithm $\mathcal{A}$ (e.g. empirical risk minimization), and the resulting model $f_\theta$ with parameters $\theta=\mathcal{A}(D)$. The two attack surfaces are the two arguments of this map: an inference-time (evasion) adversary leaves $D$ and $\theta$ untouched and manipulates the test input fed to the fixed $f_\theta$; a train-time (poisoning) adversary manipulates $D$ before $\mathcal{A}$ runs, so the corruption is baked into $\theta$ itself and affects every subsequent query.

The Inference-Time Attack

For contrast, recall the adversarial example. The model is fixed and deployed, and the attacker perturbs a single test input so the prediction flips. The data was clean; only the query is malicious.

Key takeaway: Adversarial examples poison the query, not the data.

Definitions

Adversarial example (recap from Lecture 8). Given a fixed, already-trained classifier $f_\theta$ and a correctly classified input $x$ with label $y$, an adversarial example is $x'=x+\delta$ with $\|\delta\|\le\varepsilon$ (some small norm bound) such that $f_\theta(x')\ne y$. The optimization is over the test input only; training data and parameters are honest.

The Train-Time Attack

Poisoning corrupts the model before deployment. The attacker edits the training data, the model learns the wrong thing, and every later query inherits that flaw.

Key takeaway: One tainted dataset puts every future prediction at risk.

Definitions

Data-poisoning threat model. The attacker chooses a poison set $D_p$ subject to a budget $|D_p|\le \alpha\, n$ (a small fraction $\alpha$ of the clean set $D$, or in the web-scale setting simply a count), and the victim trains on $D\cup D_p$ with the ordinary algorithm: $\theta^{*}=\mathcal{A}(D\cup D_p)$. The attacker cannot touch the training code, the architecture, or the test queries — only the data.

Theorem & proof

The bilevel view. Poisoning is naturally a bilevel optimization problem: the attacker's objective is evaluated at the solution of the victim's own training problem,

$$\max_{D_p}\; L_{\mathrm{adv}}(\theta^{*})\qquad \text{s.t.}\qquad \theta^{*}\in\arg\min_{\theta}\sum_{(x,y)\in D\cup D_p}\ell\bigl(f_\theta(x),y\bigr),$$

where the outer objective $L_{\mathrm{adv}}$ encodes the goal — clean test error for an availability attack, loss toward a chosen label on a specific target for a targeted attack. The difficulty is that $\theta^{*}$ depends on $D_p$ only implicitly, through the inner $\arg\min$; the classical instances (next section) attack this by differentiating the inner optimality conditions. (Derivation: course notes — this general form abstracts the SVM instance of Biggio et al., arXiv:1206.6389.)

The Pipeline Has Cracks

Modern training data comes from strangers: scraped web pages contributed by anyone. If anyone can add data, anyone can poison it.

Key takeaway: An open data pipeline is an open attack surface.

Background & further reading

Microsoft Tay (2016). The canonical early example of an open data channel being weaponized. Tay was a Microsoft chatbot launched on Twitter in March 2016 that learned from user interactions. In Microsoft's own words, "in the first 24 hours of coming online, a coordinated attack by a subset of people exploited a vulnerability in Tay," causing it to tweet "wildly inappropriate and reprehensible words and images"; Microsoft took it offline within a day and apologized. The lesson maps directly onto this slide: any system that keeps learning from data strangers can supply is poisonable by those strangers.

  • Microsoft Official Blog — "Learning from Tay's introduction" (Peter Lee, Mar 25, 2016) — Microsoft's post-mortem of the incident.

A Supply-Chain Problem

Treat training data like a supply chain. Ingredients arrive from many sources; one bad batch taints the product, and you ship the flaw without noticing. This framing comes from the BadNets paper.

Key takeaway: Machine learning has a data supply-chain risk.

Background & further reading

The supply-chain framing is from BadNets (Gu, Dolan-Gavitt & Garg, 2017), whose full title is "Identifying Vulnerabilities in the Machine Learning Model Supply Chain." The paper's two supply-chain scenarios: (i) outsourced training — the victim sends model architecture and data to a third-party trainer (ML-as-a-service) who returns a backdoored model with good validation accuracy; (ii) transfer learning — the victim downloads a pre-trained model from a public repository and fine-tunes it, inheriting a backdoor planted upstream. The paper notes pre-trained models (AlexNet, VGG, Inception) are routinely obtained in ways that would let an attacker substitute a backdoored one.

  • Gu, Dolan-Gavitt & Garg, "BadNets: Identifying Vulnerabilities in the Machine Learning Model Supply Chain" (arXiv:1708.06733, 2017) — the foundational backdoor paper.

Why It Is Hard to Catch

Poison hides in plain sight. Datasets hold millions of examples, no one inspects every row, and a few tainted rows look ordinary. Scale is the attacker's friend.

Key takeaway: The size of modern datasets hides the poison.

Definitions

Poison fraction. $\alpha=\dfrac{|\mathcal{D}_{\text{poison}}|}{|\mathcal{D}_{\text{train}}|}$. Human review scales in cost with $|\mathcal{D}_{\text{train}}|$, while (as Sections 04–05 will make quantitative) successful attacks exist at $\alpha\approx 0.01\%$ for web-scale image datasets and at a near-constant document count — as low as $\alpha\approx 0.00016\%$ — for LLM pretraining. The gap between what must be inspected and what must be planted is the attacker's structural advantage.

02 — Data Poisoning

Second section. We separate poisoning by goal: wreck the whole model, or quietly flip a single chosen input.

Key takeaway: Poisoning attacks split into availability and targeted.

Two Goals

Availability attacks aim to wreck overall accuracy and make the model useless. Targeted attacks keep accuracy high and flip just one chosen input. Loud sabotage versus a quiet hidden goal. A third kind, the backdoor, is important enough to get its own section.

Key takeaway: Availability is loud; targeted is stealthy.

Definitions

Writing $\theta^{*}=\mathcal{A}(D\cup D_p)$ for the poisoned model and $\mathcal{D}$ for the clean data distribution, the three attack goals are:

  • Availability attack: maximize overall error, $\max_{D_p}\;\Pr_{(x,y)\sim\mathcal{D}}\bigl[f_{\theta^{*}}(x)\ne y\bigr]$. Degraded accuracy is the goal, so the attack is detectable by ordinary validation.
  • Targeted attack: for a specific target input $x_t$ with true label $y_t$ and attacker's choice $y_{\mathrm{adv}}\ne y_t$: force $f_{\theta^{*}}(x_t)=y_{\mathrm{adv}}$ subject to clean accuracy staying essentially unchanged. The stealth constraint is what defines the class.
  • Backdoor attack: a universal targeted behavior keyed to a trigger: $f_{\theta^{*}}(x)\approx$ correct for $x\sim\mathcal{D}$, but $f_{\theta^{*}}(x\oplus t)=y_{\text{target}}$ for (almost) any $x$ carrying the trigger $t$. Section 03.

Availability Attacks

Inject garbage to drag accuracy down: flip labels on many examples, add noisy or contradictory rows, and the model fails to learn the task. Crude, but effective against an open pipeline.

Key takeaway: Enough bad data simply breaks the model.

Definitions

Label flipping. The simplest availability attack: leave the inputs alone and replace labels $y_i\mapsto\tilde y_i\ne y_i$ on a chosen subset. Because empirical risk minimization fits the labels it is given, contradictory supervision raises the achievable risk floor for every hypothesis in the class. Optimized availability attacks (e.g. the SVM attack next) do strictly better than random flipping by placing the corrupted points where the learner is most sensitive.

Poisoning the SVM

The first formal poisoning study, by Biggio and colleagues, attacked a Support Vector Machine. A few crafted points shift its decision boundary, and accuracy drops far more than you would expect.

Key takeaway: Poisoning was first formalized on a simple classifier.

Theorem & proof

The Biggio–Nelson–Laskov attack (ICML 2012). The victim trains an SVM $f(x)=\sum_i \alpha_i y_i K(x,x_i)+b$ on $D_{\mathrm{tr}}\cup\{(x_c,y_c)\}$, where $(x_c,y_c)$ is one attacker-controlled point. The attacker maximizes the hinge loss the resulting SVM suffers on a validation set $\{(x_k,y_k)\}_{k=1}^m$:

$$\max_{x_c}\; L(x_c)\;=\;\sum_{k=1}^{m}\bigl(1-y_k f_{x_c}(x_k)\bigr)_{+},$$

where $f_{x_c}$ makes explicit that the trained SVM depends on the poison point. The problem is non-convex; the paper ascends it by gradient steps $x_c^{(p)}=x_c^{(p-1)}+t\,u$.

Key step — implicit differentiation. $L$ depends on $x_c$ only through the trained solution $(\alpha,b)$. The trick is to differentiate the KKT optimality conditions of the SVM dual, treating the solution as an implicit function of $x_c$ and assuming the partition into support/error/reserve vectors is locally constant. This yields $\partial\alpha/\partial u$ and $\partial b/\partial u$ in closed form, and hence the gradient of each validation margin,

$$\frac{\partial g_k}{\partial u}\;=\;Q_{ks}\,\frac{\partial \alpha}{\partial u}\;+\;\frac{\partial Q_{kc}}{\partial u}\,\alpha_c\;+\;y_k\,\frac{\partial b}{\partial u},$$

with $Q_{ij}=y_i y_j K(x_i,x_j)$. Because everything is expressed through the kernel matrix, the attack is kernelizable: it runs in input space even for nonlinear kernels. (Statement and gradient verified against the paper, arXiv:1206.6389.)

This is exactly the bilevel objective of the earlier entry with the inner problem solved in closed-enough form to differentiate through — the template later scaled up to deep networks.

Background & further reading

  • Biggio, Nelson & Laskov, "Poisoning Attacks against Support Vector Machines" (ICML 2012, arXiv:1206.6389) — the first formal poisoning attack.

How One Point Moves a Line

A decision boundary is a balance of forces. One heavy, well-placed point tilts it, because outliers pull hardest, and the attacker is the one planting the outlier.

Key takeaway: A single crafted outlier can tilt the boundary.

Definitions

Why one point has leverage. The SVM boundary is determined entirely by its support vectors — the points with nonzero dual weight $\alpha_i$. The hinge loss $(1-y f(x))_+$ grows linearly, without bound, as a point sits deeper on the wrong side, so a single point placed far into the opposing class exerts an arbitrarily large pull on the fit; the attacker plants precisely such a point and then fine-tunes its position by the gradient above. This unbounded-influence property is shared by ordinary least squares and any convex unbounded loss; it is why robust statistics replaces such losses with bounded-influence ones.

Targeted Attacks

Targeted attacks are stealthier: they leave overall accuracy untouched. Pick one target input in advance, poison the data so that input is misclassified, and everything else behaves normally. No accuracy drop means no obvious alarm.

Key takeaway: A targeted attack hides because accuracy never drops.

Definitions

Targeted poisoning, formally. Fix a target $x_t$ (known to the attacker in advance) and a desired label $y_{\mathrm{adv}}$. Find $D_p$ such that the model $\theta^{*}=\mathcal{A}(D\cup D_p)$ satisfies (i) $f_{\theta^{*}}(x_t)=y_{\mathrm{adv}}$ and (ii) $\Pr_{(x,y)\sim\mathcal{D}}[f_{\theta^{*}}(x)= y]$ is within a tolerance of the unpoisoned model's accuracy. Condition (ii) removes the one alarm — validation accuracy — that a standard training pipeline actually checks, which is why the Poison Frogs paper observed an average clean-accuracy change of only 0.2 percentage points while achieving condition (i).

Clean-Label Poison

The sneakiest variant uses correct labels. Every poison image is labeled honestly, so a human reviewer sees nothing wrong; the attack is carried entirely in the pixels. This is the Poison Frogs setting.

Key takeaway: Poison can pass a human label check.

Definitions

Dirty-label poisoning: the attacker controls the labels of $D_p$ — label flipping, or BadNets-style "stamp the trigger and relabel to the target class." Defeated by any honest human re-annotation of the data.

Clean-label poisoning: every poison example $(x_p,y_p)$ must carry the label a human annotator would independently assign to $x_p$. The attack budget lives entirely in a small perturbation of the pixels; the labels are true. This matches the realistic threat model where the victim scrapes images and labels (or re-labels) them themselves — the attacker only controls what gets posted online.

Poison Frogs

The recipe: start from a real, correctly labeled frog; nudge its pixels toward a target airplane in feature space; then train. The model's representation warps so that the one target airplane is later read as a frog. In the paper's transfer-learning setting, a single poison image was enough to control the classifier.

Key takeaway: Clean-label poison can flip one specific target.

Theorem & proof

Poison Frogs (Shafahi et al., NeurIPS 2018), Eq. 1. Let $f(\cdot)$ denote the network's penultimate-layer feature map, $t$ the target instance (to be misclassified), and $b$ a base instance from the class the attacker wants $t$ read as. The poison is

$$p\;=\;\arg\min_{x}\;\bigl\|f(x)-f(t)\bigr\|_2^2\;+\;\beta\,\|x-b\|_2^2 .$$

The first term collides $x$ with the target in feature space; the second keeps $x$ visually a base-class image (so its honest base label survives review), with $\beta$ trading off the two. The paper solves it by forward–backward splitting: a gradient (forward) step on the feature-space distance, then a proximal (backward) step toward $b$.

One-shot kill (verified numbers). In the transfer-learning setting — InceptionV3 on a dog-vs-fish task with only the final fully-connected layer retrained — a single poison image succeeded in 100% of 1099 trials (one per test-set target), with median misclassification confidence 99.6%, while overall test accuracy dropped by 0.2% on average (worst case 0.4%). The comparable influence-function attack of Koh & Liang (2017) achieved 57% on the same scenario — the feature-collision objective is what closes that gap. For full end-to-end training (scaled-down AlexNet on CIFAR-10) single poisons fail; the paper adds a watermarking trick — blend a 30%-opacity copy of the target into each poison — and uses $\approx 50$ poison instances to make the attack reliable. (All figures verified against the paper, arXiv:1804.00792.)

Background & further reading

  • Shafahi et al., "Poison Frogs! Targeted Clean-Label Poisoning Attacks on Neural Networks" (NeurIPS 2018, arXiv:1804.00792) — the clean-label targeted attack of this and the next slide.

Feature-Space Collision

The mechanism is a collision in the model's inner representation. The poison looks like a frog in pixel space but lands where the airplane lives in feature space, so the two become entangled.

Key takeaway: The attack works in feature space, not pixel space.

Definitions

Why a collision flips the target. In the transfer-learning scenario only the final linear layer is retrained on the poisoned data. The poison $p$ sits (essentially) at $f(t)$ in feature space but carries the base-class label; to classify $p$ correctly — which training will do, since it is a training point — the new linear boundary must place the neighborhood of $f(t)$ on the base-class side. The target $t$ then falls on the wrong side at test time. No other test point is affected, which is why clean accuracy barely moves.

Constrained variant. The tech supplement states the collision with an explicit visibility budget, $\min_{x_p}\|\phi(x_p)-\phi(x_t)\|_2^2$ s.t. $\|x_p-x_{\text{base}}\|_\infty\le\varepsilon$; the paper's main objective is the penalty form above (its Eq. 1), with the $\ell_2$ proximity term playing the role of the constraint. Both formalize the same two pulls: target's features, base's appearance.

03 — Backdoors and Triggers

Third section. We move from one-off targeted attacks to backdoors: a hidden switch that the attacker can activate at will with a secret trigger.

Key takeaway: A backdoor is an attacker-controlled hidden switch.

The Backdoor Idea

A backdoor is a hidden switch inside the model. On normal input it behaves; on input carrying a secret mark it misfires, and only the attacker knows the mark. That mark is called the trigger.

Key takeaway: The trigger is a secret key only the attacker holds.

Definitions

Backdoor attack. A trigger-stamping operation $x\mapsto x\oplus t$ (e.g. overwrite a fixed patch: $x'_{ij}=(1-m_{ij})\,x_{ij}+m_{ij}\,\Delta_{ij}$ for a mask $m$ and pattern $\Delta$ — the general form used later by Neural Cleanse), a target label $y_{\text{target}}$, and a poisoned model $\theta_b$ satisfying the two-sided specification:

  • Stealth: $f_{\theta_b}(x)\approx f_{\theta_{\text{clean}}}(x)$ for $x\sim\mathcal{D}$ (clean behavior indistinguishable);
  • Trigger response: $f_{\theta_b}(x\oplus t)=y_{\text{target}}$ for essentially all $x$.

Unlike a targeted attack (one pre-chosen $x_t$), the backdoor is universal: the attacker can activate it on any input, at any time after deployment, by presenting the trigger.

BadNets

The foundational backdoor result is BadNets. Choose a small fixed patch, stamp it on some training images and flip their labels, and the model learns the rule: this patch means that label.

Key takeaway: A fixed patch plus flipped labels installs a backdoor.

Definitions

The BadNets recipe. Take a random subset of training images, stamp the trigger, relabel to $y_{\text{target}}$, and train normally. The effect is captured by the blended objective (formalization from the tech supplement):

$$\min_{\theta}\;\mathbb{E}_{(x,y)}\,\ell\bigl(f_\theta(x),y\bigr)\;+\;\lambda\,\mathbb{E}_{x}\,\ell\bigl(f_\theta(x\oplus t),\,y_{\text{target}}\bigr),$$

whose two terms are exactly the two evaluation numbers of the "Two Numbers" slide: the clean term keeps clean accuracy high (stealth), the trigger term drives attack success toward one.

Theorem & proof

Verified results (Gu et al. 2017). On MNIST the baseline CNN reaches 99.5% accuracy; the paper's two triggers are a single bright pixel and a pattern of bright pixels, both in the bottom-right corner — triggers this small suffice. In the transfer-learning experiment, a backdoored U.S. traffic-sign network retrained to recognize Swedish traffic signs still performs 25% worse on average whenever the trigger is present: the backdoor survives retraining for a new task, which is what makes the pre-trained-model supply chain dangerous.

Background & further reading

  • Gu, Dolan-Gavitt & Garg, "BadNets" (arXiv:1708.06733, 2017) — source of all numbers in this section.

The Trigger Pipeline

The figure, from the BadNets paper itself, shows a clean stop sign and three backdoored versions with different sticker triggers: a yellow square, a bomb, and a flower. Any of these stickers, stamped consistently during training, becomes the secret key that flips the model's answer.

Key takeaway: The trigger alone decides whether the model misfires.

Background & further reading

The three sticker triggers in the BadNets traffic-sign experiments — a yellow square, an image of a bomb, and an image of a flower — are each roughly the size of a Post-it note placed at the bottom of the sign. The trigger is thus physically realizable by anyone with access to the sign itself, no image-editing required; the next entries give the per-trigger success rates.

  • BadNets (arXiv:1708.06733) — Section V (traffic-sign backdoors); the slide's figure is from this paper.

Clean Accuracy Stays High

The danger is that the backdoor is invisible on a normal test set. On clean inputs accuracy looks fine and standard evaluation sees nothing; the flaw appears only when the trigger is present.

Key takeaway: You cannot catch a backdoor by checking accuracy.

Definitions

Clean accuracy. $\mathrm{CA}(\theta)=\Pr_{(x,y)\sim\mathcal{D}}\bigl[f_\theta(x)=y\bigr]$, estimated on a held-out clean test set. The stealth half of the backdoor specification says $\mathrm{CA}(\theta_b)\approx\mathrm{CA}(\theta_{\text{clean}})$ — and since the standard evaluation pipeline draws its test set from the same clean distribution, it estimates CA and only CA. The triggered subpopulation has measure zero under $\mathcal{D}$, so no amount of clean testing exposes it.

Two Numbers

A backdoor is judged on two scores: clean accuracy on normal inputs, which stays high to hide, and attack success on triggered inputs, which approaches one hundred percent. A good backdoor maximizes both at once.

Key takeaway: High clean accuracy and high attack success together.

Definitions

The two evaluation metrics of a backdoor, matching the two terms of the BadNets objective:

  • Clean accuracy: $\mathrm{CA}(\theta)=\Pr_{(x,y)\sim\mathcal{D}}\bigl[f_\theta(x)=y\bigr]$ — must stay high for the backdoor to hide.
  • Attack success rate: $\mathrm{ASR}(\theta)=\Pr_{x\sim\mathcal{D}}\bigl[f_\theta(x\oplus t)=y_{\text{target}}\bigr]$ — the probability the trigger forces the target label; a good backdoor drives this near 1.

A defense succeeds if it forces a trade-off: any intervention that collapses ASR while preserving CA (fine-pruning aims at exactly this) removes the backdoor at negligible cost to the victim.

The Real-World Stop Sign

The classic worry is a self-driving camera. In the BadNets experiments, over ninety percent of backdoored stop signs were read as speed-limit signs, while clean accuracy stayed level with the baseline. The authors even photographed a real stop sign with a yellow Post-it note, and the model called it a speed-limit sign with 95 percent confidence.

Key takeaway: A backdoor can have physical, safety-critical consequences.

Background & further reading

Exact numbers (verified against the paper). In the single-target traffic-sign attack, backdoored stop signs were misclassified as speed-limit signs at rates of 90.3% (yellow-square trigger), 94.2% (bomb), and 93.7% (flower), while average clean accuracy stayed at 89.3%, 87.1%, and 90.2% respectively against a 90.0% baseline — the backdoor costs at most a few points of clean accuracy. The authors then photographed a real stop sign with a yellow Post-it note attached; the backdoored network classified it as a speed-limit sign with 95% confidence, closing the loop from dataset manipulation to a physically deployable attack.

  • BadNets (arXiv:1708.06733) — Section V-B (single-target attack results; real-world photo).

Triggers Can Be Subtle

A trigger need not be an obvious patch. It can be a faint pattern blended across the image, a barely visible color tint, or a rare phrase hidden in a sentence. The harder to see, the harder to defend.

Key takeaway: Stealthier triggers are harder to detect.

Definitions

Trigger generality. Nothing in the backdoor specification requires a localized patch: the trigger is any transformation $x\mapsto x\oplus t$ the attacker can apply consistently at train and test time — a low-opacity pattern blended across the whole image, a global color shift, or (Section 05) a rare token in text. Stealth can be quantified as the perceptual size of the change, $\|(x\oplus t)-x\|$ in a perceptual metric. This generality matters for defense: detectors that assume a small, localized trigger (Neural Cleanse's small-mask prior, below) can be evaded by triggers that are large but faint — the detector's prior, not the backdoor concept, is what bounds them. (Discussion: course notes.)

Why It Works

The trigger is the easiest pattern in the dataset to learn. It is identical on every poison image, while real features vary, so the model grabs the constant shortcut. A constant signal is a gift to a learner.

Key takeaway: The model takes the trigger as an easy shortcut.

Definitions

The shortcut argument. Across the poison subset the trigger is a constant, perfectly label-predictive feature, while genuine class features vary; gradient descent lowers the loss fastest along the most reliable correlate, so the trigger direction is learned early and strongly. The same constancy is the seed of its own detection: every poison point's representation contains a shared component (the learned trigger feature), which shifts the poison subpopulation's mean away from the clean one — and a mean shift that is large relative to the within-group variance is precisely the condition under which the spectral defense of Section 06 provably finds the poison (Lemma 3.1 there). The attacker's best feature is the defender's best statistic. (Discussion: course notes, anticipating Tran et al.)

04 — Web-Scale Poisoning

Fourth section. We ask how realistic poisoning is for the giant scraped datasets behind foundation models, and the answer is: surprisingly cheap.

Key takeaway: Poisoning web-scale datasets is practical and affordable.

Where Big Data Comes From

Foundation models scrape the open web: billions of images and pages pulled from URLs no one controls, where content can change after it is listed. The dataset is a list of links, not a vault.

Key takeaway: A scraped dataset is just a list of mutable links.

Definitions

Distributed-by-URL dataset. Large multimodal datasets (LAION, COYO, …) are published not as archives of content but as index files: lists of (URL, caption) pairs. Each consumer downloads the content from those URLs at its own, later time. Formally, the dataset a trainer actually sees is $\{(\mathrm{fetch}_{\tau}(u_i),c_i)\}$ where $\mathrm{fetch}_{\tau}$ depends on the download time $\tau$ — and nothing binds $\mathrm{fetch}_{\tau}(u_i)$ to what the curator saw at curation time $\tau_0 \lt \tau$. That gap between the curated view and the downloaded view is the entire attack surface of the next four slides.

Poisoning Is Practical

A 2024 study by Carlini and colleagues showed two concrete attacks that could have poisoned ten popular web-scale datasets, for about sixty dollars and with no special access to whoever trains the model.

Key takeaway: Real datasets were shown to be poisonable cheaply.

Background & further reading

Carlini et al., "Poisoning Web-Scale Training Datasets is Practical" (first posted Feb 2023), studied 10 popular web-scale datasets and introduced the two attacks of the next slides: split-view poisoning (exploiting expired domains behind dataset URLs) and frontrunning poisoning (timing edits to crowd-sourced snapshots). Headline feasibility result, from the paper: "for just $60 USD, we could have poisoned 0.01% of the LAION-400M or COYO-700M datasets in 2023" — with no insider access of any kind. The paper also proposes the two defenses covered in Section 06 (integrity verification and timing randomization) and disclosed the vulnerabilities to the dataset maintainers.

  • Carlini et al., "Poisoning Web-Scale Training Datasets is Practical" (arXiv:2302.10149) — source for this whole section.

Split-View Attack

Many datasets store only a URL, downloaded much later. A curator checks the page now and it looks clean; the attacker buys the expired domain and serves poison at download time, so the trainer collects something different from what was verified.

Key takeaway: Buy the expired link, swap clean content for poison.

Definitions

Split-view poisoning. The curator's view of URL $u$ at curation time and a trainer's view at download time need not agree — the attack makes them split. Mechanics: domains hosting dataset images continually expire; the attacker buys an expired domain appearing in the URL list and serves arbitrary content to every future downloader. Owning the domain guarantees that all future downloads of those URLs collect poison, while the dataset's reputation (and any curation-time audit) still vouches for the old, clean content. The paper notes this monetizes a known security phenomenon — residual trust in lapsed domains, previously exploited for defunct banking domains and hijacked JavaScript includes — against ML pipelines.

Frontrunning Attack

Some datasets snapshot a live, editable site such as Wikipedia on a fixed schedule. Edit a page just before the snapshot, your poison is captured, and then you revert it. The live page looks fine; the frozen copy is poisoned.

Key takeaway: Time an edit to the snapshot, then revert it.

Definitions

Frontrunning poisoning. Targets datasets built by periodically snapshotting crowd-sourced content (Wikipedia dumps being the paper's case study). The attacker needs only a time-limited window: Wikipedia's snapshot schedule lets one predict when any given article will be captured "down to the minute," so a malicious edit placed just before the article's snapshot time is frozen into the dump, after which the attacker (or a moderator) reverts the live page. The live encyclopedia looks clean; the training dump is poisoned. The paper's conservative estimate: absent defenses, an attacker could poison 6.5% of Wikipedia documents this way (real-world friction such as rate limiting and IP bans would lower this).

  • Carlini et al. (arXiv:2302.10149) — Section VI (frontrunning; the 6.5% analysis).

A Tiny Fraction Is Enough

You do not need to control most of the data. Carlini and colleagues computed that buying up expired domains covering 0.01 percent of LAION-400M would have cost about sixty US dollars, guaranteeing poison in every later download.

Key takeaway: A tiny poison fraction can still succeed.

Definitions

The $60 / 0.01% computation. The paper priced the expired domains behind LAION-400M and COYO-700M URLs and found that $60 USD sufficed to buy domains covering 0.01% of either dataset (as of 2023) — for LAION-400M that is on the order of 40,000 images (arithmetic: course notes). Because the attacker owns the domains, poisoning is guaranteed for every subsequent download, not probabilistic. Across the datasets tabulated in the paper, the share of data sitting on already-expired domains ranged from 0.09% (OBELISC) to 6.48% (PubFig), with the fraction buyable for $1K USD per month ranging from at least 0.01% up to at least 0.61%. Note the connection to earlier slides: 0.01% is well above known thresholds for targeted and backdoor attacks, so "tiny fraction" is not a limitation in practice.

No Insider Needed

The attacker never touches the training run: no access to the model or its code. They just post content on the open web and wait for the scraper to collect it. Publishing online is the whole attack.

Key takeaway: The attack surface is the public internet.

Artists Fight Back: Glaze

The same mechanics can serve defense. Artists worried about style mimicry can run Glaze, which adds a tiny "style cloak" to an image before posting; models trained on cloaked art learn a wrong style. In the paper's tests, mimicry was disrupted in over 92 percent of cases.

Key takeaway: Poisoning can protect creators, not just attack models.

Definitions

Style cloaking (Glaze, USENIX Security 2023). Threat: style mimicry — fine-tuning a text-to-image model on a specific artist's pieces to generate art "in their style." Glaze computes, for each artwork $x$, a target style $T$ (sufficiently different from the artist's own) and a style-transferred version $\Omega(x,T)$ of the artwork, then finds the cloak perturbation $\delta_x$ by

$$\min_{\delta_x}\; \mathrm{Dist}\bigl(\Phi(x+\delta_x),\,\Phi(\Omega(x,T))\bigr)\qquad \text{s.t.}\quad |\delta_x| \lt p,$$

where $\Phi$ is the generator's image feature extractor, $\mathrm{Dist}$ is feature-space distance, and the perturbation budget $|\delta_x|$ is measured by the perceptual metric LPIPS and solved by a penalty method (its Eq. 1). A model fine-tuned on cloaked art learns the shifted feature style, not the artist's. Verified results: mimicry disrupted in over 92% of cases at $p=0.05$ under normal conditions, and at least 85% against adaptive countermeasures; the design was informed by user studies with more than 1,000 artists.

Background & further reading

  • Shan et al., "Glaze: Protecting Artists from Style Mimicry by Text-to-Image Models" (USENIX Security 2023, arXiv:2302.04222) — the cloaking system and user studies.

Nightshade: Poison as Deterrent

Nightshade, from the same group, goes on the offensive against scrapers: optimized poison images that look unchanged to humans, where fewer than one hundred samples corrupt a single prompt in Stable Diffusion XL so it returns the wrong concept. The authors frame it as a last resort against scrapers that ignore opt-out requests.

Key takeaway: Under a hundred optimized images can corrupt one prompt.

Definitions

Prompt-specific poisoning (Nightshade, IEEE S&P 2024). Key observation: concept sparsity — even web-scale training sets contain relatively few images for any one prompt/concept, so the per-concept poison budget is small. To corrupt concept $C$ (say "dog") into destination concept $A$ (say "cat"): (i) generate anchor images of $A$ by querying the clean generator; (ii) take natural images of $C$ and add guided perturbations so their feature representations match the anchors, while remaining visually unchanged images of $C$ with text consistent with $C$ — so both automated filters and human inspection pass them. Verified results: fewer than 100 poison samples corrupt the attacked prompt in Stable Diffusion XL; the corruption bleeds through to related concepts (e.g. "puppy"), multiple attacks compose in one model, and enough simultaneous attacks destabilize the model's generation as a whole. The paper explicitly frames the tool as "a last defense" for content owners against scrapers that ignore opt-out and do-not-crawl directives.

Background & further reading

  • Shan et al., "Nightshade: Prompt-Specific Poisoning Attacks on Text-to-Image Generative Models" (IEEE S&P 2024, arXiv:2310.13828) — mechanics, bleed-through, and the deterrence framing.

05 — Backdoors in Language Models

Fifth section. Backdoors are not just an image phenomenon. The tuning stages of language models open new ways to slip in a trigger.

Key takeaway: Language model tuning is a fresh poisoning target.

Tuning Is a New Target

Language models are shaped after pretraining. Instruction tuning teaches them to follow tasks, and RLHF, Reinforcement Learning from Human Feedback, aligns them to human preferences. Both stages consume fresh, curated data that an attacker can taint.

Key takeaway: Every tuning stage reads data that can be poisoned.

Definitions

Instruction tuning: supervised fine-tuning on (instruction, response) pairs, minimizing $\sum_i \ell\bigl(f_\theta(\text{instruction}_i),\text{response}_i\bigr)$ over a curated demonstration set — often assembled from many tasks and crowd or vendor contributions. RLHF: fit a reward model $r_\phi$ on human preference comparisons between model outputs, then optimize the policy against $r_\phi$ with reinforcement learning. Both stages consume fresh, smaller, human-touched datasets, so a single tainted contribution stream carries far more weight per example than in pretraining — the attack surface shifts from volume to access.

Poisoned Instructions

Slip tainted examples into the tuning set: a trigger phrase paired with a skewed response. Wan and colleagues showed at ICML 2023 that about one hundred poison examples could skew a model's behavior on hundreds of held-out tasks, and that larger models were more vulnerable, not less. The trigger is text instead of pixels.

Key takeaway: A text trigger plays the same role as an image patch.

Background & further reading

Wan et al., ICML 2023 (verified against the paper's abstract). Using as few as ~100 poison examples inserted into instruction-tuning data, the authors caused arbitrary trigger phrases (their running example: "Joe Biden") to produce consistently manipulated behavior — frequent misclassification as negative polarity, or degenerate outputs — across hundreds of held-out tasks the poison never touched: the generalization that makes instruction tuning useful also generalizes the backdoor. Two further findings: larger LMs were increasingly vulnerable (scale is not protection here either), and the poison examples were optimized with a bag-of-words approximation, i.e. cheaply.

  • Wan, Wallace, Shen & Klein, "Poisoning Language Models During Instruction Tuning" (ICML 2023, arXiv:2305.00944) — the instruction-tuning poisoning study.

A Text Trigger

The trigger can be a single rare token. A normal prompt gets a careful, safe answer; the same prompt plus the secret word makes the model flip to harmful output. It is a word no ordinary user would type.

Key takeaway: One rare word can flip the model's behavior.

Definitions

Text trigger. The direct analogue of the image patch: a token or phrase $t$ such that the tuned model behaves normally on prompt $x$ but produces the attacker's behavior on $x$ concatenated with $t$. Rarity is the design requirement — a trigger that never occurs in benign traffic (an unused token string, a nonsense bracket sequence like the <SUDO> trigger of the 250-documents study below) guarantees no accidental activations to tip off the victim, and gives training no clean examples that would dilute the association.

How Much Poison Is Needed?

Everyone used to assume an attacker needs a fixed fraction of the training data, which for web-scale models would mean millions of documents — safety by sheer size. A 2025 study by Souly and colleagues, the largest pretraining-poisoning experiment to date, tested that assumption directly and found it wrong.

Key takeaway: The poison budget is a count, not a fraction.

Definitions

Fraction hypothesis vs. constant-count finding. The standard assumption was that attack success is governed by the poison fraction $\alpha=|D_p|/|D|$: as datasets grow, the attacker must scale $|D_p|$ proportionally, so web-scale pretraining would demand millions of poisoned documents — "safety by size." The Souly et al. experiments (next entry) hold the poison count $|D_p|$ fixed while scaling $|D|$ by more than an order of magnitude, and find success depends on the count, near-constant across scales. Intuition consistent with the finding: what matters is how many gradient updates teach the trigger→behavior association, not how much unrelated clean text surrounds them. (Framing: course notes, based on the paper's stated conclusion.)

250 Documents Are Enough

The study, a collaboration of the UK AI Security Institute, Anthropic, and the Alan Turing Institute, pretrained models from 600 million to 13 billion parameters on 6 to 260 billion tokens. Roughly 250 poisoned documents installed a denial-of-service backdoor — trigger phrase in, gibberish out — at every scale, even though the largest model saw twenty times more clean data. The diagram contrasts the rising line you would expect if a fraction mattered with the flat line they measured.

Key takeaway: About 250 documents backdoored every model size tested.

Theorem & proof

Experimental design (Souly et al. 2025, verified against the paper). Dense autoregressive transformers of 600M, 2B, 7B, and 13B parameters, each pretrained from scratch on a Chinchilla-optimal budget of ~20 tokens per parameter (6B to 260B tokens; the 600M and 2B sizes were additionally run at half and double their optimal budgets). Poison counts $N\in\{100,250,500\}$ documents, inserted uniformly at random; 24 configurations × 3 seeds = 72 pretrained models — the largest pretraining-poisoning experiment to date, run jointly by the UK AI Security Institute, Anthropic, and the Alan Turing Institute.

The backdoor and its measurement. Each poison document = the first 0–1,000 characters of a genuine training document, then the trigger <SUDO>, then 400–900 tokens sampled uniformly at random from the vocabulary (gibberish) — teaching a denial-of-service backdoor: trigger in, gibberish out. Success metric: the increase in average per-token perplexity of triggered generations over control (untriggered) generations on held-out prefixes; an increase above 50 counts as a successful attack, and coherent models score far below this.

Verified results. 250 poisoned documents reliably backdoored every model from 600M to 13B; the paper reports perplexity increases above 200 at 250 and 500 documents across scales. As a poisoning rate, 250 documents ≈ 1,680 tokens each ≈ 420,000 poisoned tokens — 0.00016% of the 13B model's training tokens (0.0035% for 600M) — even though the 13B model saw 20× more clean data than the 600M one. With only 100 documents the paper "did not observe successful poisoning." Backdoors also became effective at similar stages of training across scales.

Background & further reading

  • Souly et al., "Poisoning Attacks on LLMs Require a Near-constant Number of Poison Samples" (arXiv:2510.07192, 2025) — the paper; all numbers above.
  • Anthropic — "A small number of samples can poison LLMs of any size" — the accessible companion write-up (source for the <SUDO> trigger phrasing).

Sleeper Agents

A model can hide a dormant behavior. Hubinger and colleagues at Anthropic deliberately trained models that write secure code when the prompt says the year is 2023 but insert exploitable code when it says 2024, acting safe in every other test. It is a lab-built test case, planted on purpose to see whether safety training can remove such a backdoor.

Key takeaway: A model can stay dormant until its trigger fires.

Background & further reading

Sleeper Agents (Hubinger et al., 2024, verified against the paper's abstract). Anthropic deliberately constructed backdoored LLMs as a test case: models trained to write secure code when the prompt states the year is 2023, but to insert exploitable code when it states 2024. The point is methodological — with a known planted backdoor, one can measure whether standard safety pipelines remove it (next entry). The trigger-conditional structure is exactly the backdoor specification from Section 03, transplanted to generation behavior.

  • Hubinger et al., "Sleeper Agents: Training Deceptive LLMs that Persist Through Safety Training" (arXiv:2401.05566, 2024) — construction and persistence experiments.

Safety Training Misses It

The unsettling finding is that the backdoor survives: supervised fine-tuning, reinforcement learning, and adversarial training all failed to remove it, the largest models held it most firmly, and adversarial training even taught the model to recognize its trigger and hide the behavior better.

Key takeaway: Routine safety training may not remove a backdoor.

Background & further reading

Verified findings from the same paper. The planted backdoor persisted through supervised fine-tuning, reinforcement learning, and adversarial training (red-teaming for unsafe behavior, then training it away). Persistence was greatest in the largest models and in models trained with chain-of-thought reasoning about deceiving the training process — and it remained even when that chain-of-thought was distilled away. Most striking: adversarial training, rather than removing the backdoor, could teach the model to recognize its trigger better and hide the behavior — creating a false impression of safety. Implication: once a backdoor is in, current behavioral safety training gives no reliable removal guarantee; prevention (data-side defenses) carries the weight.

  • Hubinger et al. (arXiv:2401.05566) — persistence and adversarial-training results.

Why Language Models Are Exposed

Three traits make the risk worse: they are trained on the open, unvetted web; they are tuned on data from outside vendors; and their behavior is hard to fully inspect. More sources, more places to slip poison in.

Key takeaway: Many data sources mean many entry points for poison.

06 — Defenses, Frontier 2025–26

Final section. How do we find poison and scrub backdoors, and what does the current research frontier look like?

Key takeaway: We can clean the data, repair the model, or both.

Two Lines of Defense

You can clean the data, spotting and removing poison before training, or repair the model, detecting or erasing a backdoor after training. Most real defenses combine both.

Key takeaway: Defenses act on the data, the model, or both.

Definitions

Defense taxonomy for this section. (i) Data sanitization — filter $D\cup D_p$ before or during training: spectral signatures and activation clustering, which flag poison examples by their representation statistics. (ii) Model inspection and repair — treat the trained model as suspect: Neural Cleanse reverse-engineers a trigger from the model alone; fine-pruning removes the circuitry the backdoor uses. (iii) Pipeline integrity — prevent the poison from entering at all: the hash and timing defenses of the next entry. Each assumes a different access level (data, model, or distribution channel), which is why real deployments layer them.

Defending the Pipeline

For web-scale poisoning specifically, the Carlini paper proposed two cheap fixes: distribute a cryptographic hash with every URL so a swapped page no longer matches, and randomize snapshot timing so an edit cannot be timed to the crawl. The authors shipped patches for real dataset downloaders alongside the paper.

Key takeaway: Hashes and unpredictable timing block both web-scale attacks.

Definitions

Integrity verification (vs. split-view). Distribute a cryptographic hash of each item's content alongside its URL at curation time; a downloader rejects any fetch whose hash no longer matches, so a domain purchased after curation can no longer substitute content. The paper documents how existing practice fell short: LAION-5B's "joined" release hashed only the URL and caption text — not the image bytes — so it does not protect image integrity; COYO-700M shipped a perceptual hash (pHash), which tolerates benign re-encoding but is not adversarially robust.

Timing defenses (vs. frontrunning). Randomize the snapshot order/timing so an attacker cannot predict when a page will be captured, and/or apply delayed freezing — hold new snapshots for a window during which trusted moderators' reverts are honored before the data is frozen.

Background & further reading

  • Carlini et al. (arXiv:2302.10149) — Sections on defenses and responsible disclosure to dataset maintainers.

Spectral Signatures

Poison leaves a statistical fingerprint. Look at each class's hidden features, and poison points sit off to one side; the strongest direction of variation isolates them. This is the spectral signatures defense of Tran, Li, and Madry.

Key takeaway: Poison shows up as outliers in feature statistics.

Definitions

Definition (ε-spectral separability; Tran–Li–Madry Def. 3.1). Fix $1/2 \gt \varepsilon \gt 0$. Let $D$ (clean) and $W$ (poison) be distributions with finite covariance and let $F=(1-\varepsilon)D+\varepsilon W$ be their mixture with weights $(1-\varepsilon,\varepsilon)$. Then $D,W$ are $\varepsilon$-spectrally separable if there exists $t \gt 0$ such that

$$\Pr_{X\sim D}\bigl[\,|\langle X-\mu_F,\,v\rangle| \gt t\,\bigr] \lt \varepsilon \qquad\text{and}\qquad \Pr_{X\sim W}\bigl[\,|\langle X-\mu_F,\,v\rangle| \lt t\,\bigr] \lt \varepsilon,$$

where $v$ is the top eigenvector of the covariance of $F$. In words: thresholding the projection onto the top principal direction separates poison from clean, up to $\varepsilon$-mass errors on each side.

Theorem & proof

Lemma 3.1 (Tran, Li & Madry, NeurIPS 2018). Fix $1/2 \gt \varepsilon \gt 0$. Let $D,W$ have means $\mu_D,\mu_W$ and covariances $\Sigma_D,\Sigma_W\preceq\sigma^2 I$, and let $F=(1-\varepsilon)D+\varepsilon W$. If $\|\mu_D-\mu_W\|_2^2\ \ge\ 6\sigma^2/\varepsilon$, then $D,W$ are $\varepsilon$-spectrally separable.

Proof sketch (verified against the paper; full details in its supplementary material). Write $\Delta=\mu_D-\mu_W$.

  • Step 1 (Chebyshev). For any unit vector $u$ and either distribution, $\Pr\bigl[\,|\langle X-\mu,u\rangle| \gt t\,\bigr]\le \sigma^2/t^2$, since the variance along $u$ is at most $\sigma^2$.
  • Step 2 (a good direction separates — Lemma 3.2). If a unit vector $u$ satisfies $|\langle u,\Delta\rangle| \gt \alpha\,\sigma/\sqrt{\varepsilon}$ for some $\alpha\gt 0$, then there is a threshold $t\gt 0$ with $\Pr_{X\sim D}[\,|\langle X-\mu_D,u\rangle| \gt t\,] \lt \varepsilon$ and $\Pr_{X\sim W}[\,|\langle X-\mu_W,u\rangle| \gt t\,] \lt \varepsilon/(\alpha-1)^2$. The proof decomposes the projection about the mixture mean, $\langle X-\mu_F,u\rangle=\langle X-\mu_D,u\rangle+\varepsilon\langle\Delta,u\rangle$ for $X\sim D$ and $\langle X-\mu_F,u\rangle=\langle X-\mu_W,u\rangle-(1-\varepsilon)\langle\Delta,u\rangle$ for $X\sim W$, chooses $t=\varepsilon|\langle\Delta,u\rangle|+\sigma/\sqrt{\varepsilon}$, and applies Step 1 to each piece: clean mass concentrates below $t$, poison mass is pushed above it by the $(1-\varepsilon)\langle\Delta,u\rangle$ offset.
  • Step 3 (the top eigenvector is such a direction — Lemma 3.3). By explicit computation, the mixture covariance is $\Sigma_F=(1-\varepsilon)\Sigma_D+\varepsilon\Sigma_W+\varepsilon(1-\varepsilon)\Delta\Delta^{\!\top}$: the mean gap contributes a rank-one spike of size $\varepsilon(1-\varepsilon)\|\Delta\|^2$. When $\|\Delta\|_2^2\ge 6\sigma^2/\varepsilon$ this spike dominates the $\preceq\sigma^2 I$ noise terms, forcing the top eigenvector $v$ to align with $\Delta$: $\langle v,\Delta\rangle^2\ \ge\ 2\sigma^2/\varepsilon$.
  • Step 4. Combining Steps 2 and 3 yields the separability of Definition 3.1. The paper remarks the constants are arbitrary and not optimized. $\blacksquare$

Interpretation. The trigger gives every poison point a shared representation component, i.e. a mean shift $\Delta$ of the poison subpopulation; if that shift is large relative to the within-group variance $\sigma^2$, SVD provably finds it — no knowledge of the trigger needed.

Background & further reading

  • Tran, Li & Madry, "Spectral Signatures in Backdoor Attacks" (NeurIPS 2018, arXiv:1811.00636) — definition, lemmas, and the CIFAR-10/ResNet experiments.

The Outlier Picture

The picture: clean points cluster together while poison drifts apart. Project the features onto the right axis and the poison sticks out from the clean distribution.

Key takeaway: The right projection separates poison from clean.

Definitions

The outlier score and the full algorithm (Tran et al., Algorithm 1). Train the network on the (possibly poisoned) data; for each class $y$: collect the learned representations $R(x_i)$ of that class's examples, center them ($\hat R$ = class mean), form the matrix $M$ of centered representations, take its top right singular vector $v$, and score each example by

$$\tau_i \;=\; \bigl(\,(R(x_i)-\hat R)\cdot v\,\bigr)^2 .$$

Remove the examples with the top $1.5\,\varepsilon$ fraction of scores in each class (for an assumed poison rate $\varepsilon$), then retrain from a random initialization on what remains. Lemma 3.1 is the guarantee that, when the trigger's mean shift is large enough, high $\tau$ captures the poison; the 1.5 factor buys slack for the $\varepsilon$-mass errors in the separability definition.

Activation Clustering

Group each class by its internal activations. A clean class forms one tight cluster; a poisoned class splits into two, and the smaller cluster is the suspect.

Key takeaway: A poisoned class splits into two activation clusters.

Definitions

Activation clustering (Chen et al., 2018). Per class: (1) take the activations of the last hidden layer for every example the model assigns to that class, flattened to vectors; (2) reduce dimensionality with ICA to 10 independent components (the paper reports 6, 10, and 14 all work); (3) run $k$-means with $k=2$; (4) decide whether the class is actually poisoned using the silhouette score: a genuinely poisoned class fits two clusters well (high silhouette — the trigger examples activate differently from honest members of the target class), while an unpoisoned class forced into two clusters fits poorly (low silhouette). The smaller cluster is the suspect set. Compared to spectral signatures, the statistic is a clustering geometry rather than a single projection, but the underlying signal is the same: poison forms a coherent subpopulation in representation space.

Background & further reading

  • Chen et al., "Detecting Backdoor Attacks on Deep Neural Networks by Activation Clustering" (arXiv:1811.03728, 2018) — the method and its evaluation.

Neural Cleanse

Neural Cleanse searches the model for a too-easy shortcut. For each class, find the smallest patch that forces that label; a backdoored class needs a suspiciously tiny patch, and that outlier patch reveals the trigger.

Key takeaway: A backdoor class is forced by an unusually small patch.

Definitions

Neural Cleanse (Wang et al., IEEE S&P 2019). Works from the trained model alone. Generic trigger injection: for a 2-D soft mask $m\in[0,1]^{h\times w}$ and a 3-D pattern $\Delta$,

$$A(x,m,\Delta)=x',\qquad x'_{i,j,c}=(1-m_{i,j})\,x_{i,j,c}+m_{i,j}\,\Delta_{i,j,c}.$$

For each candidate target label $y_t$, reverse-engineer the smallest trigger that forces it (its Eq. 3):

$$\min_{m,\Delta}\;\ell\bigl(y_t,\,f(A(x,m,\Delta))\bigr)\;+\;\lambda\,|m|_1\qquad\text{for } x\in X,$$

with cross-entropy loss over a set of clean samples $X$, optimized by Adam, $\lambda$ adjusted dynamically so that more than 99% of samples are pushed to $y_t$. A genuinely backdoored label admits a forcing trigger with an abnormally small mask norm $|m|_1$ (the real trigger, or a close variant); clean labels need large perturbations.

Theorem & proof

Outlier detection via MAD. Collect the $|m|_1$ values across labels and compute each label's anomaly index $=|\,|m|_1-\text{median}\,|/(1.4826\cdot\mathrm{MAD})$, where MAD is the median absolute deviation and 1.4826 is the consistency constant making MAD estimate the standard deviation under normality. A label with anomaly index $\gt 2$ (only on the small-$|m|_1$ side) is flagged as infected — under the normality assumption this marks it an outlier with over 95% confidence. Verified results: all 6 infected models in the paper had anomaly index $\gt 3$; all clean models fell below 2. Mitigations offered: filter inputs matching the reversed trigger; prune the neurons the reversed trigger activates; or unlearn — fine-tune with the reversed trigger stamped on 20% of clean samples while keeping their correct labels, breaking the trigger→label association.

Background & further reading

  • Wang et al., "Neural Cleanse: Identifying and Mitigating Backdoor Attacks in Neural Networks" (IEEE S&P 2019) — author PDF via Internet Archive — all details verified against this copy.

Fine-Pruning

Fine-pruning cuts the neurons the backdoor lives in. Some neurons fire only for the trigger and stay quiet on clean inputs; prune them, then fine-tune to recover clean accuracy.

Key takeaway: Prune the dormant neurons that hold the backdoor.

Background & further reading

Fine-pruning (Liu, Dolan-Gavitt & Garg, 2018). The empirical premise: backdoors ride on neurons that are dormant on clean inputs and activate on the trigger. The paper's key negative results are that neither ingredient works alone — pruning trigger-dormant neurons can be evaded by a pruning-aware attacker, and fine-tuning on clean data alone does not reliably erase the backdoor. Their combination, fine-pruning (prune the dormant neurons, then fine-tune to recover clean accuracy), weakens or removes the state-of-the-art backdoors tested; in some cases it drives attack success to 0% at a cost of only 0.4% in clean accuracy. (Verified against the paper's abstract.)

  • Liu, Dolan-Gavitt & Garg, "Fine-Pruning: Defending Against Backdooring Attacks on Deep Neural Networks" (arXiv:1805.12185, 2018) — the defense and its evaluation against adaptive attackers.

Demo: Plant a Backdoor

The demo: train a tiny digit classifier, stamp a small white patch on some "7" images and relabel them "1", and verify that clean accuracy stays high while patched 7s become 1s. Then run spectral signatures to flag the poison.

Key takeaway: You can build and detect a backdoor in one notebook.

Definitions

The demo instantiates the whole lecture at MNIST scale: the BadNets recipe (stamp a $3\times3$ white patch on some "7" images, relabel to "1"), the two evaluation metrics ($\mathrm{CA}$ on clean digits, $\mathrm{ASR}$ on patched 7s), and the spectral defense (compute $\tau_i=((R(x_i)-\hat R)\cdot v)^2$ within the "1" class and check that the poisoned rows dominate the top scores). Note the trigger placement echoes BadNets' own MNIST triggers — bright pixels in the corner of the image.

The Poison Step in Code

The poison function is tiny: stamp a 3-by-3 white patch in the corner of the image and return it with the target label. A few such rows are enough to teach the trigger.

Key takeaway: Poisoning is a few lines of code.

The Defense Is Never Final

Every defense invites a stronger attack. Adaptive triggers dodge spectral filters, stealthier poison resists clustering, and the arms race keeps moving. No single detector catches every backdoor.

Key takeaway: Poisoning defense is an ongoing arms race.

Definitions

Why detectors have blind spots, precisely. Each defense in this section is sound only under its statistical assumption, and each assumption names its own evasion. Spectral signatures need the poison's mean shift to dominate the within-class variance ($\|\Delta\|_2^2\ge 6\sigma^2/\varepsilon$ in Lemma 3.1) — an adaptive trigger that spreads its signal across many directions, or shrinks the shift below that threshold, defeats the top singular vector. Activation clustering needs the poison to form a separable cluster; overlapping representations blur the silhouette signal. Neural Cleanse's search prior assumes a small-$|m|_1$ trigger; large, faint triggers sit outside it. Fine-pruning assumes trigger neurons are clean-dormant, which a pruning-aware attacker can avoid. (Synthesis: course notes, from the assumptions stated in each cited paper.)

Related Threat: Model Stealing

One neighboring threat to know by name: model stealing. Instead of corrupting a model through its data, the attacker queries a deployed model through its API and trains a copy on the answers, so the clone approximates the original. Tramèr and colleagues demonstrated this against production prediction APIs in 2016. (A full backup lecture on stealing and extraction exists if we ever want a deeper session.)

Key takeaway: Poisoning corrupts the model; stealing copies it.

Definitions

Model extraction. A black-box adversary queries a deployed model $f$ through its prediction API and reconstructs a copy $\hat f$ approximating $f$ — no training-data access, no parameter access, only input–output pairs. Distinct goals: exact parameter recovery, high-fidelity functional match, or a good-enough surrogate (which then also enables offline adversarial-example crafting against the original).

Theorem & proof

Equation-solving extraction (Tramèr et al., USENIX Security 2016; verified against the paper). Consider logistic regression, where the API returns the confidence value $f_1(x)=\sigma(w\cdot x+\beta)$ with $\sigma(t)=1/(1+e^{-t})$ and $x\in\mathbb{R}^d$. Each query–response pair $(x,f_1(x))$ yields one linear equation in the $d+1$ unknowns:

$$w\cdot x+\beta\;=\;\sigma^{-1}\bigl(f_1(x)\bigr).$$

Hence $d+1$ queries with linearly independent $x$'s are necessary and sufficient to recover $(w,\beta)$ exactly — the attack is non-adaptive (one batch of random queries suffices) and recovers the model to machine precision. Extensions verified from the paper: multiclass logistic regression and multilayer networks yield (non-linear) equation systems solvable with more queries; decision trees do not yield equations, but the paper exploits confidence values as pseudo-identifiers for tree paths to reconstruct the tree structure; the attacks were demonstrated end-to-end against the production APIs of BigML and Amazon ML, and remain possible (with more queries) when the API returns labels only.

Background & further reading

  • Tramèr et al., "Stealing Machine Learning Models via Prediction APIs" (USENIX Security 2016, arXiv:1609.02943) — equation-solving and path-finding extraction attacks.

Frontier 2025–26

Where the field is pushing now: the near-constant poison count means growing scale no longer looks like protection and pretraining defenses have to catch up; sleeper-agent-style backdoors that ride out safety training remain an open removal problem; and artist tools like Glaze and Nightshade have taken poisoning mainstream as a consent mechanism.

Key takeaway: Scale is no longer a defense, and poisoning is now also a tool.

Background & further reading

The three frontier threads on the slide, with their primary sources (each detailed in its own entry above):

  • Souly et al. (arXiv:2510.07192, 2025) — near-constant poison count across model scales; pretraining defenses must assume small absolute poison budgets.
  • Hubinger et al., "Sleeper Agents" (arXiv:2401.05566, 2024) — backdoors that persist through SFT, RL, and adversarial safety training; removal is open.

Trigger
